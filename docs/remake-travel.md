# 百城布局与行军规则（v7）

v7为独立改编规则，不是原ROM行军算法复刻，也不是《三国志14》剧本导出。只影响新开的11份v7目录；50份已发布目录、身份哈希与旧存档规则保留。

## 江东至交州的沿海连接

吴至山阴沿用陆路，新增山阴—番禺、番禺—高凉、高凉—合浦三条海运连接，接既有合浦—交趾海路。山阴至番禺经东冶一带沿海中转，东冶仅为航路点；城市总数仍为100。保留既有7条城际海路，总计10条。棕色实线陆路接入海岸，海上线使用原图相近的黄色虚线，以现有海面掩码寻路避开陆地和岛屿，无航路编号或图外目的地。

《三国志·吕岱传》记226年率三千人浮海、经过合浦进军交趾，证明此区域存在实际军事海运。[原文](https://zh.wikisource.org/wiki/三國志/卷60#呂岱)。269年孙皓命李勖、徐存从建安海道赴合浦，但270年以道路不利退还；这条记录不能当作全程成功通航的证明。[原文](https://zh.wikisource.org/wiki/三國志/卷48#孫皓)。游戏中完整的江东沿海通道、具体分段及港口接驳是参考这些史料的玩法改编，不宣称每个年代均有固定航班或每个城址就是海港。

## 里程与时间

| 路况 | 设计速度 | 距离方法 |
|---|---:|---|
| 平地陆路 | 30公里/日 | 大圆距离×1.18绕行系数 |
| 山地陆路 | 15公里/日 | 大圆距离×1.45绕行系数 |
| 沙漠陆路 | 20公里/日 | 大圆距离×1.30绕行系数 |
| 海路 | 70公里/日 | 沿海经纬度航点逐段累加 |

海运的两端陆上接驳按平地速度计算，每条海运边再加2日上下船。陆路地形默认取相邻城的山地标签，河西沙漠等有显式覆盖；并非完整GIS道路或逐像素地形采样。上述速度、绕行及港口时间均为可调整游戏参数，不是史料测定值。

每条路线的天数向上取整；连程各段相加，再以`ceil(总日数/30)`折算到达月回合，至少1回合。因此12日和26日均在下个月到达，61日需3个月回合。月份仍按原有年度规则推进，不改用逐日战役；界面同时显示估算天数、需等待月数和预计到达年月。最快模式按总天数寻路，不按屏幕长度或最少路段数；仅陆路模式拒绝海边，也不会在台湾、海南或远海连接上虚构陆桥。

出征仍限直接相连的城；友城调动允许经连续本方城池多段行进。调动耗粮为每人每段5粮，出征耗粮为`max(1,总兵数//25)`，出发时收取，到达不重复扣粮。AI使用相同行军队列和到达规则。

## 在途、到达与异常

在途武将保留出发城名册及容量占位，界面注明“在途”；不能编兵、执行人事、再次出发或参加守城。如此可沿用原有容量、兵员与年度死亡账本，不能将其解释成武将仍在城内驻守。

月轮结算后，有到达事件则进入“行军到达”。点击“处理到达部队”按预计月份与行军编号依次处理。友城且有空位即入城；攻城在到达时读取当前守军，遇玩家参战暂停，接收战果后继续剩余到达。电脑之间沿用同一损兵与结算公式。月轮与战果回执继续防止重复扣款、重复推进年月。

- 友城满员：保留行军，每月重试一次，禁止超容量入城。
- 调动目的城或途经友城易主：取消调动，恢复出发城可用编制；不会瞬移到敌城或自动发动原本未授权的攻击。
- 攻击目的城已属本方：改作入城处理，满员则等待。
- 出发城失陷：在途编制与该城其他武将一起按战后撤离规则处理，取消对应行军。
- 武将途中达到年度寿命边界：沿用原年度清理，兵员归出发城预备兵；空队列删除。
- 多队同月到达：逐队处理；前一战导致后续部队出发城失陷时，后续失效事件不重复结算。

取消和退却暂不另计算返程时间，不模拟路上遭遇战、逐段补给、海上风向或天气。保存会保留在途路线、时间、编号、检查游标和战斗续行标记；篡改到达月、重复部队或非法路线即拒绝载入，并保留当前战役。
