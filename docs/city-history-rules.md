# 都市名・年代・帰属 / 城名、年代與歸屬

都市名はゲーム年月に応じて表示し、史実の勢力配置は新規シナリオの初期状態に適用します。原典で確認できる年と、本作で指定した月の境界を区別します。プレイ中の領土を史実の所有者へ強制的に戻すルールではありません。

## 鄂県・西平亭・建安県・高涼 / 鄂縣、西平亭、建安縣與高涼

- **鄂縣／武昌**。東漢江夏郡已有鄂縣，184年開局即顯示。184、188年按本作地方漢郡配置為中立。190至207年的開局隨劉表，208年後按孫權控制鄂縣配置，與夏口方向的江夏節點分開。《江表傳》另載劉備曾屯鄂縣樊口。208年赤壁開局配置有鄂長任職記載的胡綜。221年4月同一城改稱武昌、升為大城。221、225、227年保留孫權本據，234、238年配置陸遜，249年配置諸葛恪、呂岱。沿用鄂縣與江夏、蘄春之間的陸路和長江兩段，江夏至蘄春的船可沿共用主航道通過港口外側。[《後漢書》郡國志四](https://zh.wikisource.org/zh-hant/後漢書/卷112#江夏郡)、[《三國志》吳主傳](https://zh.wikisource.org/wiki/三國志/卷47)、[《三國志》胡綜傳](https://ctext.org/text.pl?if=gb&node=604605)、[《三國志》陸遜傳](https://zh.wikisource.org/wiki/三國志/卷58#陸遜)、[《三國志》諸葛恪傳](https://zh.wikisource.org/wiki/三國志/卷64#諸葛恪)
- **西平亭／西平**。早期採今西寧一帶的舊據點名「西平亭」。《武帝紀》214年記韓遂敗走西平，本作自214年初顯示「西平」。《通典》記建安中置郡，《水經注》記曹魏黃初中置，設郡年代有異說。215、217、219年的麴演依215年西平、金城諸將的記錄配置在西平在野。金城、姑臧方向沿用原陸路。[《三國志》武帝紀](https://zh.wikisource.org/wiki/三國志/卷01)、[《通典》西平郡](https://zh.wikisource.org/zh-hans/通典/卷174#西平郡)、[《水經注》卷二](https://www.shidianguji.com/book/NGJ89241199900895314051/chapter/1luvi0m35ksv8)
- **建安縣／建安**。建安初分侯官北鄉置縣，本作採地方沿革的196年並以1月開放。196年與保留王朗的197年假想開局按會稽歸王朗，198至202年按孫氏名義勢力配置。203年賀齊進兵建安設都尉府，現有劇本未以該年開局。260年孫吳分會稽南部置建安郡，本作於10月顯示郡名。早期經鄱陽接入東部豫章山道，參考賀齊軍經豫章屬縣餘汗的記載。新都、臨海開放後可沿既有道路行軍。[福建省民政廳建甌沿革](https://mzt.fj.gov.cn/ztzl/xczmxd/dmwh/202408/t20240826_6506583.htm)、[《讀史方輿紀要》卷九十七](https://zh.wikisource.org/wiki/讀史方輿紀要/卷九十七)、[《三國志》賀齊傳](https://ctext.org/text.pl?if=gb&node=604484)、[《三國志》孫休傳](https://zh.wikisource.org/wiki/三國志/卷48)
- **高涼**。原製圖文字曾把節點寫成安寧，實際地理座標與CHGIS的大八鎮高涼舊縣相同。孫吳另置的安寧縣在陽江西白沙，相距約24公里。沿用「高涼」城名，以合浦郡舊縣及其後續歸屬核對開局。錢博任高涼西部都尉有史證，221、225、227年駐防採區域配置。既有四條陸路及兩條含接岸陸段的海路為區域交通表示。[CHGIS高涼縣](https://tgaz.fudan.edu.cn/tgaz/placename/hvd_42300)、[CHGIS安寧縣](https://tgaz.fudan.edu.cn/tgaz/placename/hvd_42301)、[《宋書》州郡志](https://zh.wikisource.org/zh-hant/宋書/卷38#廣州)、[《三國志》呂岱傳](https://ctext.org/text.pl?if=gb&node=604506)

## 章陵、義陽

| 遊戲年月 / シナリオ年月 | 名稱與處理 |
| --- | --- |
| 221年12月以前 | 顯示「章陵」。劉表勢力存在的史實劇本，原則歸劉表；207年9月「三顧茅廬」依使用者指定保留劉備，是明列的開局例外。 |
| 208年8月起的歸屬界線 | 依使用者指定，以208年8月作劉琮降曹後的開局月界，歸曹操。這是遊戲約定；《武帝紀》將劉表卒與劉琮降曹分列八月、九月，不能將八月投降冒稱原典確月。 |
| 222年1月起 | 名稱改為「義陽」。222年改名採考證資料；1月為本作年界，並非另有明載的改名月。 |
| 240年1月以後的新開局 | 撤去義陽節點。進行中的既有戰役不刪城、不刪武將、不截斷路線，也不強制重設歸屬。240年採CHGIS所引考證的推定年，1月是遊戲年界；不稱原典明載該年月撤郡。 |

上述208年歸屬界線適用開局資料，並非在遊戲進行到該月時強制把玩家城池交給曹操。章陵/義陽是地圖上的固定區域節點；郡的省置與古城是否仍有居民分開理解。[《三國志》武帝紀](https://zh.wikisource.org/wiki/三國志/卷01)、[《宋書》州郡志二](https://zh.wikisource.org/wiki/宋書/卷36)、[CHGIS義陽郡考證](https://tgaz.fudan.edu.cn/tgaz/placename/hvd_34534)。

## 赤壁之戰的荊南四郡

208年10月開局把武陵、長沙、桂陽、零陵分別配置給金旋、韓玄、趙範、劉度，四人以可玩地方勢力表示。《先主傳》記錄劉備南征與四太守降服，支持人物與所領郡的對應；獨立勢力的呈現是本作遊戲分組，不等於史料宣稱四人各自建立了國家。[《三國志》先主傳](https://zh.wikisource.org/wiki/三國志/卷32)。

## 266年圖の照合で追加した11都市 / 依266年圖核查補入的11城

第一批新增合肥、廣陵、柴桑、西城、上庸、夷陵，均有漢代舊縣，29個劇本皆保留。220年上庸郡併入新城郡時，上庸縣仍作為同一城池。合肥與壽春分立，215年合淝事件移到合肥，張遼、樂進、李典駐守。219年開局申儀駐西城，申耽駐上庸，兩人歸劉備。襄樊事件仍由房陵、江陵分別出征。西城在郡治回遷後自264年1月顯示「魏興」。[《後漢書》郡國志四](https://zh.wikisource.org/zh-hant/後漢書/卷112)、[《後漢書》郡國志五](https://zh.wikisource.org/zh-hant/後漢書/卷113)、[《華陽國志》漢中志](https://zh.wikisource.org/zh-hant/華陽國志/卷二)。

夷陵在222年改稱西陵，本作自次年正月顯示。晉於280年三月平吳，同年復稱夷陵。復名確月未載，本作自平吳後的四月切換，沿用同一城池。[《三國志》吳主傳](https://ctext.org/text.pl?if=gb&node=603909)、[《宋書》州郡志三](https://zh.wikisource.org/zh-hant/宋書/卷37)、[《晉書》武帝紀](https://www.shidianguji.com/zh/book/LS0005/chapter/LS0005_26)。

第二批按城池建置開放昌黎（244年九月置縣）、平陽（247年五月置郡）、衡陽與湘東（257年二月）、建平（260年）。建平採孫吳所置之郡，原典只載年份，故以260年1月作本作年界。現有開局中，249年只開昌黎、平陽，263年才開齊五城。劇本開局已撤的城池亦不會在換月時依舊建置日期重新出現。[《三國志》齊王紀早稻田藏本](https://archive.wul.waseda.ac.jp/kosho/ri08/ri08_01735/ri08_01735_0053/ri08_01735_0053.pdf)、[《三國志》孫亮傳](https://www.shidianguji.com/zh/book/LS0004/chapter/1j7fnux22fnsn_304)、[《宋書》州郡志三](https://zh.wikisource.org/zh-hant/宋書/卷37)。

29個開局的歸屬、駐將和證據分列在[開局資料](../game/config/campaigns/city-expansion-openings.json)。史料有具體任職的駐將與依區域分配的守軍分開標記。早期無適當人選的城池開局名冊留空，假想劇本依各自設定。新增城的開局庫存和產出按鄰區普通城基線配置，屬本作平衡值。戰役中建置新城時，城池承接當前母城的實際歸屬與部分資源。

11個城標及路線用原版像素底圖上的同款圖標和線條。漢水、長江與湘水的新港口接入既有共用河段；上庸透過陸路接漢水，水路只覆蓋可表現的幹線。原圖中其他待核標記見[266年圖核查](city-gap-audit-266.md)。本輪新增了戰役目錄節點，存檔的目錄校驗要求使用本版新建戰役。

## 200年官渡開局與新增城歸屬複核

官渡開局取曹操東征劉備以前的局勢。劉備回小沛，以既有 `qiao`（小沛／譙郡的區域代理）作本據，關羽仍在下邳，兩城同屬劉備。梁習與路招保留曹操勢力和原帶兵，改駐濟陰、許縣。這兩處駐防是配合開局疆界的本作安排。合肥在這一開局是空城。建安五年稍後，嚴象被殺，劉馥才奉曹操任命入合肥建揚州治。202年開局仍為曹操，劉馥駐守。[《三國志》先主傳](https://www.shidianguji.com/zh/book/LS0004/chapter/1j7fnuw0vwny3_198)、[《三國志》關羽傳](https://zh.wikisource.org/wiki/三國志/卷36#關羽)、[《三國志》劉馥傳](https://ctext.org/text.pl?if=gb&node=602622)、[《資治通鑑》卷六十三](https://ancient-china-books.github.io/zizhitongjian/OEBPS/Text/6207.html)。

以目前23個史實開局複核西北、河北／山西、蜀吳原新增19城和266年圖兩批11城，合計690個城與開局的組合，包含年代未開放的節點。另查高涼的區域配置。六個假想劇本沿用各自前提。下列歸屬仍以區域情勢表示，保留可確定的史料界線。
