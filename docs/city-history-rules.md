# 都市名・年代・帰属 / 城名、年代與歸屬

都市名はゲーム年月に応じて表示し、史実の勢力配置は新規シナリオの初期状態に適用します。原典で確認できる年と、本作で指定した月の境界を区別します。プレイ中の領土を史実の所有者へ強制的に戻すルールではありません。

## 合浦・新都・巴東・新城・建寧・興古

| 地圖節點 | 年代與顯示 |
| --- | --- |
| 合浦／珠官 | 合浦郡沿用至227年末，228年起顯示「珠官」。[《三國志》吳主傳](https://zh.wikisource.org/wiki/三國志/卷47) |
| 新都 | 位置對應208年新設的新都郡治始新。此前是歙縣境內，沒有獨立縣治，因此史實開局與戰役進程均從208年開放。197年和201年的假想劇本保留原配置。[《三國志》賀齊傳](https://www.shidianguji.com/zh/book/LS0004/chapter/1kview8bnwn4c)、[CHGIS新都郡](https://tgaz.fudan.edu.cn/tgaz/placename/hvd_32221) |
| 魚復／巴東／固陵 | 使用魚復舊縣至200年。201至213年顯示「巴東」，劉備入蜀後的214至215年顯示舊縣「魚復」，216至220年顯示「固陵」，221年恢復「巴東」。[《華陽國志》巴志](https://ctext.org/wiki.pl?chapter=288254&if=en)、[CHGIS魚複縣](https://tgaz.fudan.edu.cn/tgaz/placename/hvd_44482) |

| 味縣／建寧、宛溫縣／興古 | 225年7月「征伐南蠻」開局仍用味縣和宛溫縣，10月改用建寧和興古。《水經注》通行本記興古郡治在宛溫。[《華陽國志》南中志](https://ctext.org/wiki.pl?chapter=174251&if=gb)、[《水經注》卷三十六](https://www.shidianguji.com/zh/book/NGJ8924119990165161591/chapter/1lvcsj4uf1w73) |

史料僅載年份時，以1月為本作界線。南中郡名改用秋後10月，對應《華陽國志》所載的南征平定後改制，與玩家戰果分開判定。新都在進行中的戰役依既有開城規則承接丹楊的實際歸屬及部分物資。未開城的史實開局中，原配置在新都的駐將與物資移至同勢力城池。

## 章陵、義陽

| 遊戲年月 / シナリオ年月 | 名稱與處理 |
| --- | --- |
| 221年12月以前 | 顯示「章陵」。劉表勢力存在的史實劇本，原則歸劉表；207年9月「三顧茅廬」依使用者指定保留劉備，是明列的開局例外。 |
| 208年8月起的歸屬界線 | 依使用者指定，以208年8月作劉琮降曹後的開局月界，歸曹操。這是遊戲約定；《武帝紀》將劉表卒與劉琮降曹分列八月、九月，不能將八月投降冒稱原典確月。 |
| 222年1月起 | 名稱改為「義陽」。222年改名採考證資料；1月為本作年界，並非另有明載的改名月。 |
| 240年1月以後的新開局 | 撤去義陽節點。進行中的既有戰役不刪城、不刪武將、不截斷路線，也不強制重設歸屬。240年採CHGIS所引考證的推定年，1月是遊戲年界；不稱原典明載該年月撤郡。 |

上述208年歸屬界線適用開局資料，並非在遊戲進行到該月時強制把玩家城池交給曹操。章陵/義陽是地圖上的固定區域節點；郡的省置與古城是否仍有居民分開理解。[《三國志》武帝紀](https://zh.wikisource.org/wiki/三國志/卷01)、[《宋書》州郡志二](https://zh.wikisource.org/wiki/宋書/卷36)、[CHGIS義陽郡考證](https://tgaz.fudan.edu.cn/tgaz/placename/hvd_34534)。

## 赤壁之戰的荊南四郡

208年10月開局把武陵、長沙、桂陽、零陵分別配置給金旋、韓玄、趙範、劉度，四人以可玩地方勢力表示。《先主傳》記錄劉備南征與四太守降服，支持人物與所領郡的對應；獨立勢力的呈現是本作遊戲分組，不等於史料宣稱四人各自建立了國家。[《三國志》先主傳](https://zh.wikisource.org/wiki/三國志/卷32)。

## 新增19城的逐劇本核查

[審計說明](city-ownership-audit-20261024.md)及[逐項JSON](city-ownership-audit-20261024.json)保留修正前基準，針對19個史實劇本逐一對照19城，共361項；6個IF共114項排除於真實歷史歸屬判斷之外。

武昌221年4月、臨海/臨川257年2月的設郡月份有原典；新興215年1月、建安260年10月、吳興266年12月等包含本作年/月界約定。西北早期地方實控、雁門的州域映射、188與194年的交接月份仍有資料缺口，不能把宏觀配置當作逐月逐城太守名冊。存檔使用目前資料集校驗，本輪劇本資料更新後請新建戰役。
