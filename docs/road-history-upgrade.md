# 道路史料核查與分階段修正

本次核查以修改前的29個劇本、267條已知連線（陸路210、內河46、海路11）為範圍。城池代表區域節點；河港與城市可以由陸路相接，不表示大河流過城池中心。有河流不等於能全年通行大軍船隊，首次存世遠征記載也不等於航道首次存在。

本輪生成後仍有267條已知連線：陸路212、內河44、海路11，內河共用47個河段。23條實際穿城的陸路父線編譯出連續城間路段；只在中間城池有效時中轉。城池不存在時，原路連通且不提供虛構補給。115個城池的座標、29篇的人物、勢力歸屬及開局資源與修改前逐欄比對保持一致。

山地走廊沿用山地每日15公里、1.45倍迂迴係數，平地每日30公里、1.18倍。整段歸為山道是目前粗粒度路網的保守抽象，不是聲稱每公里都是高山。詳細數值由目前繪製曲線與每段地理端點重新標定，文檔不保存容易過期的固定日數。玩家、AI、內政運輸均讀同一份編譯結果。

## 年代依據與不可越過的界線

- **譙—渦—淮**：209年曹操從譙作輕舟、入渦淮出肥有[《武帝紀》](https://zh.wikisource.org/wiki/三國志/卷01)依據；它指史實的譙，並非史實小沛。現有譙節點在219年前按使用者指定顯示「小沛」，城市說明仍須明示區域代理，不能為增加水路而暗中更名或移城。
- **河北渠網**：204年遏淇入白溝、206年平虜渠與泉州渠屬不同工程；自然河段的早期交通與竣工後運輸能力分開。未完成支流、渡口與年代核對的渠段，不直接套到184年。
- **成都—越巂**：[《三國志·張嶷傳》](https://zh.wikisource.org/wiki/三國志/卷43#張嶷)有旄牛舊道中斷、早期走安上險遠路、張嶷任內復通的記載。不能刪掉早期全部交通，也不能假造近道復通的某年某月。本輪只增加復通時段的史料註記，不假設239年或254年某月自動換線；精確分期改線待進一步核定。
- **東北濱海道、盧龍道**：[《武帝紀》](https://zh.wikisource.org/wiki/三國志/卷01)記207年秋七月濱海積水、田疇引軍出盧龍塞，[《田疇傳》](https://zh.wikisource.org/wiki/三國志/卷11#田疇)說明修復舊道。保留原有沿海陸路，另自207年7月提供山道選擇；這是修道的玩法界點，不表示此前完全沒有山區交通。不憑此事件另加任意洪水機率，也不套海上季風。
  本作只在有明確記載的207年7月停用沿海軍行，改取修復後盧龍山道；8月起恢復普通路網是按月處理的玩法邊界，並非聲稱史書證明該月已修復沿海道。其他年份不重複套用這次封路。
- **破岡瀆、靈渠及太湖水網**：需按當時航道、轉運與工程年代分段。尚未考定的中間線位不為了增加選項而直接連滿；現代大船或唐代擴建能力不作三國參數。

## 保持的玩法規則

城市位置、32×32城標和原版像素地圖保持。共用路段只繪製一次；實際行軍仍計走完全程的日數。

陰平道單向、平地基準2倍時間及三分之一存活；子午谷7至9月4倍時間、50%減員，其他月2倍時間、20%減員；海路順風120／逆風7.5公里每日和80至90%風暴減員均保留。這些數值是已確認的玩法，不是由史書實測所得。

耗糧按實際行軍日數持續結算，包括途中等待及押運武將返程。真正經過本方城池時可按現有規則補給；共用筆畫本身不產生免費補給。路線修改後重算日數及分段備糧，沿用現有斷糧減員、撤退與運輸隊接濟機制。

道路改動會變更劇本目錄身分。使用新道路請建立新戰役；本輪不增加舊目錄存檔的自動遷移或再次抽取風險的流程。

固定的8組行軍存檔對照仍保留。此次因目錄身分及真實路段ID更新而重建雜湊，更新前後每組各階段的亂數狀態與抽取次數、抵達兵力及總行軍天數逐項相同；新路線另以穿城敵軍阻斷、友城補給、缺城連通及年代邊界測試驗證。這不表示所有修正道路的耗時不變，例如壽春—譙的陸路由不合理繞行26日改為7日，譙—渦淮至壽春順流航行為6日，巴東—宜都沿山陸路由8日調整為20日；均為本作標定值。
