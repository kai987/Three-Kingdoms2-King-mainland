# 本地验证

| 检查 | 运行证据 |
| --- | --- |
| 分段口粮、货粮守恒、选路及预算 | 每类 1,000 组固定种子属性，加上实际交易、赴援、编队和往返的回放 |
| 完整路网 | 29 个剧本和上期 13,488 个方向月份键，匹配原方向和总日数，比较 4 种阵容 |
| 战斗 | 基准版与候选版各 210 场固定输入的真实战术对局，战场基础耗粮和经验一致 |
| 原生 Rust 和 WASM | Rust ABI 1，核对并重编既有 WASM 二进制，23,149 个参考向量通过 |
| 真正的 Pyodide | 314.0.7 挂载发布构建，检查 29 剧本预览、43 项真实请求、最低耗粮报价、正式扣粮和存档。与 CPU Python 响应、存档和 RNG 对照 |
| 桌面与触屏 | 调动、城市后勤、正式扣粮各一例，实际运粮救援与断粮原路撤退各两例 |
| 招募、有限市场、命令书、战果、旧档 | 本地测试详见包内 `checks/`，历史精确向量保持原值 |
| 各剧本开局核对 | 29 剧本、3,739 城池、9,165 名在职武将 |

战斗直接样本以戍守方和攻击方已有袋粮为输入。实战区别还由行军、押运和战场援军回放验证。经济和交战频率的长程结果见[长期观战](long-term-observer-results.md)。

清单记录用于观战的 A/B/C/D 提交及用于包交付的最终提交，数量和耗时取自本地运行结果。
