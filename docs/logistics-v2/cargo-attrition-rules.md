# 货粮途耗

只对运输队货物账户中当时仍有的粮食扣途耗。押运口粮先结算，货粮转入粮袋后作为账户转移，随后对余额扣途耗。原来险道和风暴的货损单列。普通随军粮、金、宝、预备兵的运输规则沿用原作逻辑。

| 交通 | 每日货粮基点 | 运输 100,000 粮 30 日后 |
|---|---:|---:|
| 平原 | 50 | 86,039 |
| 山地 | 100 | 73,970 |
| 沙漠 | 150 | 63,546 |
| 顺流 | 10 | 97,044 |
| 静水 | 15 | 95,597 |
| 逆流、海路 | 20 | 94,171 |
| 等待、登船 | 0 | 100,000 |

1 基点相当于 0.01%。当天每段基点乘经过的千分之一天数，结果相加得到加权日率。用 `divmod(当前货粮 × 加权日率 + 上日余数, 10,000,000)` 一次取整。旧余数在动身、停留、改道及返程时继续沿用，结束时只记录不足一粮的余数。

已加载的普通粮袋独立守恒。货账包含初发、粮袋回补、转入押运口粮、路线损耗、天气损耗、交付、返还、无归属城时废弃，以及账末货粮。读取存档会按实际行军日重放货损，核对付款时间、日序和余数。救急发运量按预计抵达数反推，仍受可用货量和现有运载上限限制。
