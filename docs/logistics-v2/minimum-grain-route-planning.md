# 最低耗粮路线

`minimum_grain` 复用实际地图、方向和历史开放日。调动须到己方城，途中沿既有己方、中立、同盟通行条件，补给只取己方节点。出征保持原有相邻限制，运输继续应用保存的海路和险道权限。风险预览不会提前抽取随机数，也不以预计伤亡降低成本。

搜索从目标反推剩余口粮成本下界，再按照预计口粮与实际货量的逐日途耗寻找合法路径。候选保留节点、实际天数、粮袋付费余份、现有补给能力、货物余额及途耗余份。等价状态可以删除重复访问的方案。总粮相同依次比较日期、风险、节点数和路线 ID。玩家预览和实际指令使用相同搜索入口，确认前按当时库存重新检查。

搜索排除重复绕城，最多展开 2,048 个候选。普通前提是在承诺货粮之外安排押运人员的粮袋。行程中预算受扰时，运输仍可依既有粮袋和应急货粮转账处理。超过搜索上限或者没有可供补给的路径时，界面显示没有找到可供补给的路线。该上限及不规划途中购粮的前提约束全局最优性。沿用现行整条路线锁定出发月的天数与季风报价。
