# 天氣擴展介面

目前由原路網決定出發月、季風、高風險山道和安全權限。`logistics_rules.plan` 接收已報價的路段並產生整數時間分段。`estimate_cargo(..., rates=...)` 和 `weight(..., rates=...)` 允許以另一張表重放假設情境。生產預設值為 `MARCH_SUPPLY_PERCENT` 和 `CARGO_GRAIN_LOSS_BPS`。

後續可由日期、路段、流域與海拔提供季節因子。先凍結出發／逐日天氣的取值時點，再把時間、口糧、貨損和通行性各自作為報價輸入。立規時要為新增參數提供中性缺省、存檔規則版本、Python／Rust／WASM一致的格式和可重放的險情流水。暫停、冰封和除雪若改變可通行性，需同步校驗返回中部隊和改道。

本次運行實驗使用與組別一致的固定規則。高壓倍率對照屬於獨立的後續試驗。地圖、季風和戰術天氣仍走現有規則。
