# 後勤規則與存檔

新戰役寫入 `extension.logistics_rules_version = 2`。存檔沒有該鍵代表 V1。農業和市場以獨立版本判斷，已是農業 V2 的舊檔亦可繼續使用原後勤費率。讀檔保留原糧量、已用糧、風險結果和日期。普通與緊湊存檔解碼後使用同一套狀態驗證。

V2 行軍日糧帳保存實際日數、收據、備糧和不足明細，逐日驗算。貨糧途耗記錄到對應日與旅程，重複扣出、少登帳或擅改餘數均會失效。戰場與行軍互相交割的不足一點糧維持同一精度。提前結束的援軍返程保存已走過的物理分段及剩餘付費份額。

舊存檔可直接從原版開始的普通存檔或緊湊存檔載入，繼續走原流程。單純預覽或查詢不重寫後勤版本。要使用 V2，請建立新戰役。
