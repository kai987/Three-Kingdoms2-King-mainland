# 戰略儲糧與調糧

| 城市定位 | 儲糧軟目標 |
| --- | ---: |
| 普通後方 | 3 個月固定支出 |
| 前線 | 6 個月固定支出 |
| 邊塞據點 | 6 個月固定支出 |
| 已配置糧倉 | 12 個月固定支出 |

前線和邊塞取自劇本既有分類。大型糧倉可用劇本鍵 `logistics_granary_cities` 配置，預設留空。城市規模與糧倉配置相互獨立。軟目標影響採購、供應與募兵規劃。出征依獨立的實際安全預算判斷。

調糧按已付出的物資、在途預估送達和各期口糧結算檢查。補給方需保留本地需要，並預付押運粮；有已派送的來粮時減少新需求。路線先比較趕不趕得上缺口，再比較實際可送達的糧、時間和既有安全權限。已在途的糧只在實際卸貨後入庫。緊急援粮沿既有請援的席位、同盟和外交判定。

都市情報及前線支援面板提供官倉、人口與駐軍相關支出、月淨收支、未計收入的存糧月數、負收支時的耗盡時間、已承諾行軍與運輸糧、在途預估、可用市場量及新增 100 預備兵的月口糧。
