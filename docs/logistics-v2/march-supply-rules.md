# 军事后勤 V2 行军口粮

新战役写入独立的 `logistics_rules_version = 2`。未标记的存档在之后的行军中继续使用自己的历史规则。行军账的 schema 标识余份精度，紧凑存档头也保留物流版本。

每日基础人数为现存士兵、随行武将每人折算 100 人及运输中的预备兵之和。每 50 人日耗 1 粮，乘以当天实际经过路段的时间加权倍率。日内采用千分之一日为时间单位，统一口粮分母为 5,000,000，结转上次已经支付的余份，只补够当前口粮所需的整粮。跨城补给、周期边界和合法返回共用同一账。入战保留精确余份，战斗日使用基础费率。

| 交通 | 总倍率 |
|---|---:|
| 平原 | 125% |
| 山地、沙漠 | 150% |
| 顺流 | 105% |
| 静水 | 110% |
| 逆流 | 115% |
| 海路和登船 | 110% |
| 城池节点等待 | 100% |

河流按原始距离除以航速作时间权重，在原有整数水程内分配，反向时按实际经过顺序读取河段。已有接岸几何按长度拆分整段接岸时间，登船仍按照原路线规则计时。季风和险道使用既有天数与风险。等待发生在路段内时继续按路段费率处理。援军只沿已走过的部分回撤，战术回撤保持原规则的经过天数，按相反方向结算河段费率。

固定 10,000 兵和一名武将时，平原 10 天要 2,525 粮，山地 20 天要 6,060 粮。平原接驳 2 天、登船 1 天、顺流 3 天、逆流 4 天共 2,293 粮。
