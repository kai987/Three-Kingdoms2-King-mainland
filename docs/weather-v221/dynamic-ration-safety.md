# 剩余口粮和合法供给

出发预算包括实际去程及返程行军需求，并按总预算加 10% 安全余量。到达节点后以剩余工作量、实在兵力、最新天气和上次未结清的口粮余份重新评估。已在返程的任务只计算剩余返程。尚未交割的普通任务，在界面及出发报价中也列入可估算的返程需求。

城池能提供的粮来自实际库存，先保留下一个本地固定口粮账期及必要工资，扣除现有资源承诺后，经原补给入口交割。接下来可使用真实随队货粮，以货舱扣除和粮袋增加的一对收据记录。完全冰封会产生时限未知的预算，先计入未来十日的可审查等待量，保持每日口粮扣除。

用于复算的逐日粮袋从 `rations_before` 加入 `supply`、扣除 `paid`。当天货舱从 `cargo_before` 扣除 `route_loss`、`incident_loss` 与 `cargo_to_bag`。行军和交割之间的操作另在货粮及任务事件流水记录。
