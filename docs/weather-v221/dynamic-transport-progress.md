# 动态运输进度

每个正常路线日等于 644,000 工作单位。日结算在当前物理路段应用当天的移动及口粮费率。每条日流水应满足 `start_work - moved = end_work`。到达城池界面和真正交付分开记录，货物到达后的押运人员依然保留为活动队伍，直到返抵或依法结束。

本旬派遣创建行程，逐日行军推进真实位置及账本，城池到达结算权威交割，补给校验和合法改道在实际节点处理。同一条路的返程后缀被重复要求时，保留已有的进度、历史口粮、货粮余数和已发生风险。确需改道时，历史行程保留在运单中，新路线从当前实际节点开始。

逐日记录原始预计日、当前预计日、真实到达节点、连续无进度天数和冰封河段。3、10、30 日适合用于看板和排查；长时间合法冰封允许等待到实际通航。
