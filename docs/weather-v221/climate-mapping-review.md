# 气候区复核

游戏地图目录包含 158 城、11 个气候区、59 个物理河段，其中 15 条河段具有正向冰封敏感度。本轮以原目录、路线 ID 和配置映射复核。陆路和海路以原图端点间等距采样结合实际地图地形。河段仍使用目录中的物理段 ID。

`climate-mapping-review.csv` 保存城池、优先路线的各物理分段及已有河段。抽查辽东及辽西、金城—朔方、东郡—清河、弘农—河东、清河—平原，秦岭和武都—阴平，以及越嶲、云南和建宁。水陆替代仅取实际地图路线，气候流仍适用原配对。

目前物理目录未覆盖部分辽水与汾水水路。它们作为候选地理工作保留，须独立验证地图几何、历史依据和气候对照。
