# 性能实测

长期缓存只保存路段工作拆分、地形、地理及物理河段，以及纯函数费率组合。费率键包含地形、公开降雪、积雪路况、河段冰态和规则档位。路线报价沿用通行图缓存，当前城池归属、外交权限和实际库存参与其自身更新。活动运队的真实位置、粮账和承诺随每笔记账更新。

## 缓存与观测的同局对照

221 年 7 月剧本，种子 2026，策略 212，规则 221，六个月、18 旬。每次使用同一 Rust 后端和同一确认命令序列。关闭缓存时换用相同的费率、分段预测和货损纯函数计算。四种组合的 19 份紧凑存档校验点完全相同，覆盖出发、实际行军、季节变化和随机数状态。墙钟受并发长局影响。

| 方式 | 无缓存 CPU 秒／旬 | 有缓存 CPU 秒／旬 |
|---|---:|---:|
| 原引擎回合，无观测 | 0.5409 | 0.5338 |
| 详细观测 | 0.5934 | 0.5927 |

样本的 CPU 降幅为 1.32%（无观测）和 0.11%（详细观测）。详见 `checks/performance-cache-observer.json`，其中有原测量、各缓存命中统计、分位数和状态校验值。五年各局相同观测配置另见 `performance-comparison.csv`。本地 Chromium 和 Pyodide Worker 逐旬计时为 2.488、2.149、2.508 秒，测试时同机有并发观战。提速 20% 为候选门槛，目前短样本没有达到。
