# 266年の晋・呉対峙図と都市の照合 / 266年晉吳對峙圖城池核查

依使用者提供的《晉、吳對峙圖（266年）》逐區比對本作地圖、城名規則與最新史實開局。核查基準有29個劇本，目錄共115個城市節點。最晚的開局為263年5月，當時開放113城。此時義陽已從新開局移除，吳興仍未開放。現有資料可核對[城市目錄](../game/config/campaigns/shared.json)、[劇本清單](../game/config/campaigns/index.json)、[263年開局](../game/data/campaigns/263-05.json)及[年代城名](../game/config/city-name-rules.json)。

下列46項是圖上尚無獨立對應的地點或標記，包含候選城、軍事據點、需要拆分的同名郡及年代待核項。以舊縣建城時可以沿用舊縣名，後來的分郡、改名和郡治遷移各有自己的界線。圖示顏色只用於核對晚期局勢，各劇本仍需分別核對當年控制者。

## 已有對應與需要更正的沿革

- **同址名稱。** 圖中的左馮翊、右扶風、武威、遼東、薊、鄴、晉陽、渤海、東郡、宛、巴郡、吳郡、會稽等，都能在現有節點對上。圖中的壽春對應本作的九江郡節點。現有安平節點的里程座標在衡水南部，可按安平國治信都的區域代理處理，先確認具體舊城址再決定是否另加點。圖中的廩丘和本作濮陽有獨立城址，兩者不合併。[《後漢書·郡國志》](https://zh.wikisource.org/wiki/後漢書/卷111)、[《宋書·州郡志一》](https://zh.wikisource.org/wiki/宋書/卷35)
- **合浦。** 現有節點228年改稱珠官後沒有恢復舊名。《宋書》記孫亮在位期間（252–258）復稱合浦，未載確年或月份。249年開局仍用珠官，263年開局應用合浦。若要設定連續戰役的單一切換月，可用孫亮退位後的首個整月作保守界線，明記為本作設定。[《宋書·州郡志四》](https://zh.wikisource.org/wiki/宋書/卷38)
- **晚期節點。** 武昌221年、臨海和臨川257年、建安260年、吳興266年已各有建置規則。新都、巴東、建寧、興古與房陵／新城也已有年代配置。雲南在本作有節點，225年蜀在舊縣設同名郡，適合補充沿革詳情。[現有城市年代規則](city-history-rules.md)、[《華陽國志·南中志》](https://zh.wikisource.org/wiki/華陽國志/卷四)
- **交州歸屬。** 交趾、九真、日南在263年開局均已有，遊戲配置為呂興起事勢力。後來入魏、晉而吳於271年反攻復取，可用來考證晚期歸屬。日南另有《宋書》所載吳省、晉282年復立的行政變化，劇本應分別處理地區控制與設郡。圖上夷洲沒有城池圓點，現有夷洲仍是本作海外節點。[《晉書·陶璜傳》](https://zh.wikisource.org/wiki/晉書/卷057#陶璜)、[《宋書·州郡志四》](https://zh.wikisource.org/wiki/宋書/卷38)
- **武昌與建業。** 兩城已有。孫皓265年九月徙都武昌，266年十二月還都建業，屬都城變更；若設266年史實開局，開局月份會影響首都。[《三國志·孫皓傳》](https://zh.wikisource.org/wiki/三國志/卷48)

## 補城順序

1. 先補城址清楚、能接入既有戰事的舊縣。合肥與壽春分開，廣陵補長江北岸，西城、上庸、房陵各有落點，夷陵／西陵與宜都分開，柴桑補江夏到江東之間的江段。219年襄樊開局已有房陵方向的事件出征線，拆分路網後需驗證原有兩路仍能抵達。
2. 再補後期建置。昌黎依244年九月置縣、平陽按247年五月分郡、衡陽和湘東按257年二月、吳建平按260年。已存在的漢縣可先以舊名出現。每批核對當期城主、駐將、物資及道路。連續戰役的分城承接當前母城的歸屬與部分資源，史實歸屬另外落在開局資料。
3. 同名跨境節點及郡治有爭議的項目，先查實地位置與當期控制，再定地圖坐標和路線。長江與漢水共用既有水路段，舊路在中間城市尚未開放時仍連通。每個新增可玩節點需同時檢查戰場、玩家與AI通行、開局名冊及存檔相容性。

本文保留擴城前的核查基準。首兩批11城及合浦復名的實裝細節見[城市年代規則](city-history-rules.md)。
