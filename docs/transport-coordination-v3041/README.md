# V3.0.4.1 势力运输统筹

新战役可以在开局设置中启用「AI 輸送統籌 V3.0.4.1」。规则版本为 3041，正式默认关闭。基础排序与效率排序由实验配置分别运行。已有战役通过存档自身的规则版本继续执行。

每次实际发运由运输、市场、粮仓或既有中转命令结算。统筹器以势力为单位比较渠道和共享成本，使用当前可用的押运人员、粮金、来源城位置和命令书。候选读取的数值在发运前再次核对。
