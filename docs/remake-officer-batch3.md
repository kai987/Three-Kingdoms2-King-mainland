# 第三批人物评分与九年代战役

本批在原148人版的基础上继续配置120人的德，完整人物为268人，余下732人仍待评。1000份独立身份、体力、适性和武知来源均保留。旧目录按原字节留存，新目录为`game/data/eras-v3/`，不绕过旧存档的哈希校验。

## 评分尺度与资料边界

`game/config/officer-batch3.json`逐人保存四维、理由、史料卷次、页面哈希、材料层次、置信度和对照人物。仍按恤民35%、公正30%、操守20%、信义15%加权，范围10—99；先依据本人的事迹作四维判断，再与已有档位比较，不复制对照人物的分值、不用魅力换算。

例如田畴对照田豫：守旧主、收养流民、拒爵禄分别支持信义、恤民、操守，得到91，与田豫90比较校准。仓慈在敦煌抑豪强、平徭役、通商的记载使恤民、公正较高，德92，对照董和89。高顺清白不受馈遗、奉职忠谏得到83；吕布反复杀主、改盟和治军失序得到33。武力与名气没有参与德的换算。

这些数值是参考史料的生涯综合游戏评分，不是史书中的客观量值。材料较薄的张角、丁原、韩馥、张超、曹昂、曹冲、马岱、张任、陈到、姚伷等注明低置信初评；不能将四维都称作已经独立证实。对陈宫、高顺、曹昂、张任、姚伷等标明正文与裴注的层次，陆凯奏疏、孔融政治罪状、司马孚的后出传记也保留来源限制。演义人物未因为缺少史料而批量获得默认德；阿会喃仍单独保留原版基线。

来源参考《三国志》《后汉书》《晋书》的公版文字，页面地址逐人保存。武、知和多数生卒、出仕年份仍是此前第三方SAN14转写，尚未全部认证为历史事实。

## 势力与驻城修订

`game/config/campaign-generation-v3.json`将原来源、有效势力与修订理由分开：

- 184年把来源中的汉官军集团合并为汉廷，不提前将刘焉当作已割据益州的君主。
- 190年张鲁按刘焉部相关军团安排，不提前建立独立汉中国家；来源的孔伷尚未启用。
- 194年孙策部归袁术，保留原来源分组，不提前成为江东独立政权；严白虎仍待配置。
- 200年张绣及其来源部属（包括贾诩）改归曹方，依据其199年再降曹操的记载。
- 207年四郡太守、249年司马懿和曹爽仍按前版的宏观政治集团规则合并；不把游戏分组当成独立历史国家。

固定96城并不含所有县城。190年张超的广陵代理到东海、194年刘备的小沛代理到谯郡；兖州争夺以东郡吕布和陈留曹操表示。它们有明确的玩法代理标记，不能视为精确的历史行政归属。

`game/config/era-postings-v3.json`继续补充区域提示：刘馥207年在合肥对应九江节点，九江归曹方；文聘的江夏北部魏方守区代理到义阳，避免把他配置到代表吴侧夏口的江夏节点；陆胤249年在交州对应交趾，太史慈200年建昌对应豫章。仓慈的敦煌在图外，暂由武威代理并注明差别。黄权改投前后、李恢南中、霍弋建宁、杜畿河东等也分别配置。

其他缺乏确切驻地的人，仍按注明的生涯区域或势力地域安排，不能称为已全部考证的驻军分布。地方军团、郡级政治归属与驻军营地有区别；本批只改善有依据的部分。

190年袁绍来源名单25人，而当前固定地图只给渤海一个20人节点。额外5人记录为`pending_capacity`、城市为空，不进入运行名册，不变成在野，也不通过增造领土解决。后续须补充有依据的席位安排或后备机制。待配置人物同样纳入规划容量检查，每座城市的规划与实际名册均不得超过20人。

## 运行与再构建

```sh
python3 -B game/build_campaigns.py
python3 -I -S -B game/serve.py --port 8878
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -p 'test_remake_*.py' -q
```

构建离线读取已保存的资料及本批设计，不读取ROM、不请求网络。旧`game/build_eras.py`继续精确重建v2，新增构建器只写v3目录与本批配置审计。运行人物共享现有招募、转属、单挑、计略、AI和兵员账本；没有单独的演示人物或虚拟战斗分支。

新人物到出仕年后在配置地以在野出现；不会在玩家已经改变历史后强制改投原历史势力，也不会复活已退出的人。原空属性人物仍不自动进入战局。旧版存档按原目录身份读取，失败切换和读取不会覆盖进度。

本批验证重点为75种开局、120份独立评分与对照、出生/出仕/卒年、20人容量、同名身份、17目录存档、历史修订及新人物参与招募和战斗。长期模型推进与浏览器截图另存为本地证据；验证不等于全部史实驻城、全人物德或玩法平衡已经完成。
