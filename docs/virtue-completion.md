# 千人德值配置（v5，2026-10-21）

用户规则：继续设定德，没有详尽史料则设为60。保留已发布269人的配置，本轮16人按核对过的古籍事迹给出独立游戏评分，余715人暂用60，全部1000条人物记录五项必要属性齐全。

“默认60”表示本轮尚未完成足够详细的逐人史料核对，不表示不存在传记，也不表示史料评价为60。默认条目没有虚构四维或古籍来源，记录用户授权、日期、政策编号与后续可复核状态。德不是可由史料客观测量的数值；参考史料的分数同样属于作者设计。

## 配置、重建与存档

- `game/config/virtue-completion.json`：16份逐人评分、715个明确的稳定人物ID及授权默认政策。
- `expansion/officers/data/virtue-completion-audit.json`：全部1000人的德、保留/新增标记与来源类型。
- `game/build_virtue_completion.py`：离线生成11个v5目录，无网络抓取或隐藏兜底评分。
- `game/data/main-scenarios-v5/`：新开战役使用的完整属性版本。

已发布28份目录字节保持原样，存档继续校验所属目录的SHA256。加上11份v5，共39份目录可读取。旧战局保留其旧属性；要使用扩充人物，选择新开v5战役。UI默认只显示11个当前本篇，旧版本在“显示旧版战役”中可选。不把旧存档静默迁移到新数值。

默认60会参与招募、劝降、籠絡及AI/继承选择的既有公式，未改变这些公式。新加入的人数可能影响难度和平衡，仍需游戏试玩调优。
