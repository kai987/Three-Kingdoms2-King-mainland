## 配置来源与限制

官方网页只用于确认目录、年月与事件纲要，没有取得《三国志14》的原始剧本导出。本作的96城疆界、资源、君主节点与驻城是独立改编；七个既有年代保留来源身份和既有修订，184年新本篇改用官方2月，原3月旧目录不变。

新增191/208/219/238四篇不会直接改年份复用附近人物表。`build_main_scenarios.py`逐人执行：

1. 先用稳定人物ID查询显式复核的转属/排除项。
2. 其余只有前后快照在籍势力一致，或在野状态和地点一致，才作为**有标记的推定**使用。前后相同不证明中间从未转属。
3. 转属时间、地点或状态不能确认的保留`unreviewed/pending_history`，从开局和未来自动出现位置中排除；缺德者同样不入场。
4. 出生、出仕、卒年继续使用有来源的游戏年表。卒年开局是否仍在世单独记录，不宣称确定死亡月份。

重点边界：191袁绍取得冀州，董卓君主节点迁长安；208刘表不再作为君主，刘备使用江夏战区节点，荆南未提前划归刘备；219汉中归刘备，关羽仍在荆州，王平已归蜀；武都、阴平在219归魏、238归蜀，未提前229年归属变化；238曹叡在位、公孙渊掌辽东、姜维已入蜀，公孙恭被囚而不作为可用部将，诸葛亮不复活。

新配置仍有宏观军团、图外代理及史实细节待考。208未接入荆南四太守，少数历史小势力与人物仍待补齐，不能把中立节点解释成当时没有郡守。后续须逐人复核推定项、补全德与驻城，才能称为完整历史开局。人物页能检查推定/复核标记，实际游戏进程不强制复现史实转属、历史战果或原版事件链。

公孙渊使用卷08正文行为进行低置信游戏德评分22，参照已配置董卓档位校准。理由、四维、稳定ID与来源独立存于`main-scenario-profile.json`，其余已发布人物不重打分。

## 容量和存档

新版11份目录通过`rules.city_officer_capacity=30`驱动名册校验、招募、劝降、调动、AI和守军战后撤离。出战上限维持10，未把单挑20合、战场总20槽等无关数字改成30。

17份旧目录保持字节不变，旧存档按20人规则读取；新版使用`mainlandYEAR-MM-v4`身份，拒绝跨目录哈希混用。界面默认只列11个新本篇，勾选旧版选项可查看历史目录。

## 画面依据

原机截图参考：`analysis/runtime/replayed/city-commands.png`与`officer-list.png`。保留浅粉底、黑色信息字、方框菜单与鲜明像素地图，使用GNU Unifont的16像素字形，许可证随字体保存。采用已有原版设计和地图，未用生成图重画原素材。

Web适配保留1440桌面左右分区和390宽触屏纵向布局，主标题32像素、正文16像素；城标及地图保持既有文件哈希。只有选中城显示方框，势力以城标下的小色条标识。真实菜单、表格和表单均可操作，并非截图覆盖。

这是原版视觉风格的Web界面，尚未逐像素重现256×240所有场景，普通攻击/单挑仍以可操作列表呈现，原战斗动画与音频未接入。

## 验证方式

自动测试覆盖102个新开局、28目录存档、30/31人边界、劝降、调动、AI招募、战后逃往第30席与出战10/11边界，并离线重建核对旧目录字节不变。30人满城与撤离使用明确受控夹具，不冒称自然战役已聚集30人。

浏览器另外检查11篇真实选择、招募与转属对话框、编兵/出征/攻击/计略/单挑/战后/电脑/存取，以及1440×1000和390×844显示。浏览器结果只能证明本作Web流程，不是原模拟器验证。长线人物平衡、完整历史驻军与所有历史事件未完成。

点击锚点改读当前渲染使用的`cities.displayArtX/Y`，横向裁剪136像素；旧`iconLayout`存在早期坐标，不能继续作为点击位置。新目录与前端共同使用`assets/city-positions.json`，旧存档原始目录不改。地图PNG的像素、城标与城池位置均未改动。`build_map_anchors.py`可从批准的v42配置离线重建。
