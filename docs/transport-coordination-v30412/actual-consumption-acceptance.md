# 实际扣粮与补给归因

从正式换旬、日行军和仓库入账入口读取已发生的写入。城市观察记录含检查点、所属势力、人口、现役、预备兵、原始扣粮刻度、应付粮、实付粮、缺口以及扣前扣后余额。行军按天记录真实领粮、余粮、当日欠粮和饥损。

城市总欠粮等于应付减实付。实付比例只在应付为正时计算。居民和驻军共用同一口粮扣账。部分支付时公布两个类别各自可能支付的上下界，并保留总实付的精确值。

固定目标使用《原检查点 SHA-256、原所属势力、城市、首次扣粮刻度》匹配。城池易主而无法对照时，单列该记录。两侧的应付、实付、人口和兵力始终保留。应付减少的改善单列，以免把驻军移动或人口变化解释成运输收益。

## 实际粮食流入

本地市场、普通运输、区域采购、战略粮仓、实际生产和其他收入分别记录。混合仓库对每一渠道计算可以证明的消费下界。每笔非城市口粮支出优先假设用了该渠道粮食，每笔城市口粮支出优先假设使用仓库里的其他粮。其余必须来自该渠道的粮食才计为可证金额。全渠道的共同下界用同一算法计算一次。

旧实体口径继续只计原始期限前的真实运队到货。折顶货粮以原始首次缺口为上限。市场补粮及实际消费另列，份额不能兼作实体货粮。实际账未能证明的渠道归因保留未确认。

## 资源与效率

城市金粮入账、市场库存、实际命令书收据、运队发运及终点、人员占用和调度承诺分别核对。独立复放保存精确起点和各旬日期。运输效率按实际净到货和相应成本计算，完结人员和运位周期依据真实返程及可复用时点。尚未返程的周期保留单独一项。没有分母的效率留空。
