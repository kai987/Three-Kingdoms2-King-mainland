# 寶庫、太守、賞賜與運寶

本階段把「寶」作為城池資源，和金錢、兵糧、預備兵分開保存；不是武器、坐騎或具名道具清單。以下數值是本作的初始平衡設定，不稱為已還原的原版公式。玩家與AI使用同一個資源、勢力命令書及賞賜服務。

原作的「寶」資源、尋訪取得、可運輸、每份賣100金，以及賞賜參考太守德值的方向，參考[南夢宮原版說明書掃描，第26–27頁](https://cdn-ak.f.st-hatena.com/images/fotolife/j/jackallsasaki/20260802/20260802002840.jpg)（[掃描目錄](https://gamemanual.midnightmeattrain.com/entry/三国志Ⅱ_覇王の大陸)）。本作的0–99上限、初始數量、搜尋費用與精確忠誠公式是明列的重製版設計，並非說明書已證明的原版數字。

## 城池寶庫與太守

每城的寶為整數0–99。新戰役的通常都市、大都市、巨大都市，分別以2、4、6份寶開始；無主城為0。都市易主時，現存寶隨城移交，不按新勢力或新規模重置。新設城池從母城實際庫存分出四分之一，整數向下取整，不另外生成寶。

太守負責本城的賞賜。可手動指定在場、健康的本方武將，或選自動：君主在城時優先，其餘按德、知、目前體力、穩定人物ID選任。行軍、押運或參戰者不能遠端擔任在場執行者；原任太守不再可用時，自動改選可用人選。任免本身不耗命令書，但仍由確認操作生效。

## 搜尋、賣寶與賞賜

搜尋、賣寶及賞賜每次有效確認各使用勢力共用命令書1本。執行者必須在本城、健康且未在途或參戰；同城與同一人可重複執行合法操作，賞賜以太守為執行者。地方文吏與歷史武將遵循同樣規則。發放、扣書及免費管理操作見[命令書規則](command-books.md)。

| 操作 | 費用／數量 | 結果 |
| --- | --- | --- |
| 搜尋寶 | 金錢20 | 成功率`clamp(20 + floor(知/3) + floor(德/5), 15, 80)%`；只在正式確認時抽一次亂數，成功增加1份寶，失敗也付費及耗命令書 |
| 賣寶 | 每次1–99份，不超過本城庫存 | 每份換金錢100；金錢上限不足時拒絕整筆操作 |
| 賞金 | 每次1–100金，不超過庫存 | 忠增加`min(100−目前忠, max(1, ceil(金額×(50+太守德)/3000)))` |
| 賞寶 | 每次1份 | 忠增加`min(100−目前忠, 5 + floor(太守德/20))` |

賞賜對象必須是本城在場的本方非君主武將，忠未滿100；不能隔空賞賜在途部隊，也不對君主顯示的`--`進行加值。忠滿100、庫存不足或輸入非法時，整筆拒絕，不扣資源、不耗命令書、不抽亂數。畫面在確認前顯示預計忠誠變化，輸入框依可用庫存及單次上限修正數量。

玩家的全勢力自動賞賜預設關閉，可自行啟用；AI勢力預設啟用，使用同樣的方針與實際資源。方針包含目標忠、每旬全勢力總賞金預算（初始100金）、各城保留金錢與寶，以及優先使用賞金或賞寶。優先忠較低者，同值依德、知、人物ID排序；可在同城持續處理合法對象，直到共用命令書、金錢預算或可用資源不足，不因城市或執行者已工作而略過。手動行動優先，不額外替AI生成資源，也不增加賞賜亂數。

AI在原有人事、軍務和運輸等工作後，可使用剩餘的勢力共用命令書處理寶庫：金錢低於保留量且寶超過保留量時，僅賣出補足所需的份數；否則寶少於2、金錢足以保留最低金錢再支付20時，才選本城知較高的可用武將搜尋。每次仍支付同樣費用、扣1本命令書，搜尋只用一次亂數。這是AI的選擇策略，不會替玩家自動開啟搜尋或賣寶；玩家僅在明確啟用自動賞賜時按所設預算消費。

## 寶必須由運輸隊實際送達

在「前線支援」中的「運送寶」選擇本方目的城、數量並確認。最大值按本城現存寶及單隊99上限計算。押運人員與原有運輸一樣，保留委任官及守軍，在途者不能再次派遣，同來源同時最多一隊；出發確認使用勢力命令書1本。自動前線支援的既有保留量、目標量及運輸方針不會自動搬走寶。

寶在出發時從本城扣除，計入真實在途貨物，抵達本方城後才入庫。運輸沿已知道路或方針允許的水路行軍，口糧另計；途中補給、等待耗糧、斷糧及實際返程規則與其他運輸相同，不提供瞬間轉帳。未知航路不會因運寶而自動探索。

目的城收不下整隊寶時，先帶貨等待；下一旬仍超過99則沿實際路線帶回。回程收貨城也滿庫時，繼續保留貨物等待空間，不截去溢出部分。押運武將卸貨後自動返回原城；若原城已失，按既有規則尋找實際可達的本方城。

既有風暴或險道風險對寶使用與金錢、兵糧相同的生存比例，向下取整，沿用該次事件的亂數，不另抽一次；實際差額登記為損失。勢力消滅、沒有本方可接收城池而棄置運輸隊時，也只登記尚在該隊的寶。天候、交貨及返程重複檢查不會重扣或重發。

寶的守恆式為：

`所有城池現存寶 + 所有在途寶 + 已賞寶 + 已賣寶 + 已損失寶 = 開局寶 + 搜尋所得寶`

城與運輸隊之間的交接只改位置，不增加右側來源。存檔檢查城池0–99邊界、貨物增減鏈、實際路程與全局守恆。本版使用`tk2-treasury-v1`與`tk2-logistics-v3`，更新後請建立新戰役；不替舊版存檔補造寶庫。

## 日本語

「宝」は都市ごとに0〜99を保管する資源です。通常都市は2、大都市は4、巨大都市は6、無主都市は0から始まります。都市の所属変更で在庫を作り直しません。固有の武器や馬とは別の仕組みです。

都市の「宝庫」で探索・売却・褒賞と太守の任命を行います。探索は資金20を使い、成功時に宝1を得ます。売却は宝1につき資金100です。賞金は1〜100金、賞宝は1個を使い、太守の徳によって対象武将の忠誠上昇量が変わります。忠誠の上限は100、君主は対象外です。探索・売却・褒賞は確定ごとに勢力共通の命令書1冊を使います。健康で在籍し、行軍・参戦中でない同じ武将も繰り返し実行できます。太守任命と方針設定は無料で、閲覧や取消では資源や乱数は変わりません。[命令書の規則](command-books.md)を参照してください。

自動褒賞は勢力共通の方針です。プレイヤーは初期無効で、自分で有効にできます。AIは初期有効ですが、同じ実行条件と実際の資源を使い、追加資金は受け取りません。目標忠誠、1旬の全勢力合計の賞金予算（初期100金）、都市の保持量、資金・宝の優先順位を設定します。

AIはほかの業務後に余った勢力共通の命令書で、資金不足時に保持量を超える宝を必要な分だけ売り、または宝が2個未満かつ保持資金と探索費を確保できるときに探索します。費用・行動・探索の乱数は通常の命令と同じです。プレイヤーの探索・売却を勝手に自動化しません。

「前線支援」→「宝の輸送」では、目的都市と数量を選び、実際の護送隊で送れます。到着してから入庫し、護送武将は荷下ろし後に帰還します。兵糧は往復・待機中も消費します。目的都市が満杯なら待機し、次の旬も受け入れ不能なら持ち帰ります。帰還先も満杯なら貨物を保持したまま待機します。暴風雨などでは既存の貨物と同じ割合で損失を記録し、追加の乱数は使いません。通常の自動前線支援は宝を自動輸送しません。

都市と輸送中の在庫、探索、使用、売却、損失を通じて総数を検証します。新しい保存形式を使うため、更新後は新規戦役から開始してください。
