# 207-09 保留种子的返程风险

种子 2034、策略 211、天气 221 和运输应急 222 的五年 S3 运行中，219 号运队造成该局全部 199 名运队饥损。该队是常规运队，出发于魏，目的地南阳。该样本可在 `observed/holdout/w221/S3/211/2034/60/207-09/` 核对。

| 战役日 | 实际结算 |
| --- | --- |
| 1180 | 出发，10,000 名护卫，货粮 33,075，独立口粮 12,221 |
| 1210 | 南阳实收 29,475 粮，剩余返程口粮 6,387 |
| 1235 | 返程中口粮归零，饥损 100 名 |
| 1236 | 到达魏，饥损 99 名 |
| 1240 | 归队，原有护卫剩余 9,801 名 |

读者可以用 `convoy-events.csv` 核实发运和收货，用 `transport-progress-daily.csv.gz` 查看粮袋，用 `convoy-resolution-daily.csv.gz` 对照饥损发生日。该队成功交付货粮并归队，人员安全仍需另看实际护卫损失。记录支持“返程最后两日口粮不足”的判断。战局中的其他运输和将兵调度也已改变，因此该单支运队的结果不能直接归因于某一项新增粮仓参数。
