# 存档、Runtime 与界面

战役的 `strategic_granary_rules_version` 为 302 时启用粮仓。新战役的 `strategic_granary_options` 可独立设置 `proactive`、`winter` 和 `relay`。普通新战役开关默认为关闭。旧存档缺省关闭，不附带粮仓状态。V3.0.1 的区域市场、自动商业、天气和运输应急分别保留自己已有的存档开关。

普通及紧凑档保存当前储备标签、未发运承诺、实体运输链接、已审核接收历史及在途中转。紧凑档头包含版本，压缩内容仍保存同一个完整战役状态。读档只做对应的状态、仓容和凭证校验。未装船或尚未交付的数量只有相应的逻辑用途。

由「都市情報」进入「戰略糧倉／戦略備蓄」。界面包括官仓和各用途、九旬逐行预览、风险到货、冬季目标、中转和活动运单。确认发运显示一张命令书和来源城。面板随现有语言选择切换繁中和日文。浏览器 Worker 和本地 HTTP 使用同一个 Session 报价入口。报价同时校验战役 revision，过期报价在再次提交时要求重新确认。

浏览器验收提交的含量由有效受控存档提供。静态页面用浏览器文件导入入口读入，正常发运与扣减由实际 Runtime 结算，截图之后推进真实战略旬。日文窄屏使用 Chromium 的触摸视口模拟。
