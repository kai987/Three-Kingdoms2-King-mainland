# 裝備、初始配置與來源界線

本階段將武器、防具的實際持有資料與人物的基礎能力分開。武、知、德、體力上限不因換裝永久改寫；裝備的攻防與重量應在武將詳情、都市情報和武器屋各自顯示。人物圖像、演義兵器名稱、實際裝備ID與單挑結算須能對應，但演義覆蓋不能冒充FC原版初始值。

以下指令只驗證轉錄與來源一致，不修改檔案：

```sh
python3 -B - <<'PY'
import hashlib, json
from pathlib import Path
p = Path('game/config/references/original-equipment-v1.json')
e = json.loads(p.read_text())
raw = Path(e['source_file']).read_bytes()
assert hashlib.sha256(raw).hexdigest() == e['source_file_sha256']
s = json.loads(raw)
rows = [dict(person_id=r['person_id'], source_row_id=r['source_row_id'],
    source_name=r['name'], weapon_label=r['weapon_label'],
    weapon_id=e['weapon_aliases'][r['weapon_label']], armor_label=r['armor_label'],
    armor_id=e['armor_aliases'][r['armor_label']],
    basis='cnblogs_original_equipment_transcription')
    for r in s['records'] if r.get('person_id')]
assert rows == e['records'] and len(rows) == 223
encoded = (json.dumps(rows, ensure_ascii=False, separators=(',', ':'))+'\n').encode()
assert hashlib.sha256(encoded).hexdigest() == e['factual_records_sha256']
print('223 source equipment bindings verified')

```

| 攻方＼守方 | 劍 | 刀 | 矛 |
| --- | --- | --- | --- |
| 劍 | 70% | 75% | 60% |
| 刀 | 55% | 60% | 70% |
| 矛 | 80% | 50% | 60% |

官方能確認的是「重量影響先手」，不是「只把重量從攻擊力扣掉」。2007年程式分析作者另說明先後與開局體力、武力、雙裝重量、每次行動及亂數有關，但沒有在能核到的段落公布完整計算。

[2021年原作者的機制介紹](https://www.toutiao.com/zixun/7517429529301223476/)及[另一篇署名分析的轉載](https://read01.com/jE0RQ0L.html)提出`(體+武)/10−武器防具重量和+隨機20…30`作先手權重。這可作本作的可解釋參考，不能推導出原ROM的整數捨入順序、所有行動的逐次修正或完全相同的亂數消耗。

也有攻略稱防具重量會提高撤退耗體力的風險；本次未找到可信的精確幾率、扣量與取樣算法。若本作增加這些效果，須記錄為本作可調參數，不能宣稱全部按原版機器碼還原。名將新增兵器、弓及雙兵器的三類對應與數值，也須與FC原32物品表區分。

## 本作實際採用的計算

以下是目前Web戰役的明示規則，**不是宣稱完整重現FC機器碼**。`//`向下取整，攻守武力差為負時也如此；檢視、預覽、切語言及讀檔不抽亂數。

令`M`為武、`H`為目前體力、`WP/WW`為武器強度／重量、`AP/AW`為防具強度／重量：

- 武器重量攻擊折減`P=max(0,(8×WW−M+9)//10)`；初始短劍ID0的P另設0。
- 攻擊修正`max(−6,(WP−3)//3−P)`；防禦修正`max(0,(AP−2)//3)`。這是接續Web單挑尺度的換算，原始強度與換算後修正會分開顯示。
- 總重量`T=WW+AW`；負重`B=max(0,T−M//10)`。負重造成命中扣`3×B`個百分點，回避扣`2×B`個百分點。
- 本輪先手權重`(H+M)//10−T+20+R`，R為0–10整數；同式、同亂數服務用於雙方；權重相同時由挑戰者先手。
- 攻方對守方命中率：上表類型基準`+(攻武−守武)//4−3×攻方負重+2×守方負重`，限制於10%–95%。守方負重越高越難回避。弓與新增雙兵器的三類歸併屬本作適配。
- 單挑退卻及部隊戰敗／撤退結算的額外耗體力概率`min(100,5×T)%`；觸發時耗`1+max(0,T−8)//4`體力，否則不扣，最低保留體力1，不因此直接死亡。沒有找到這套概率與扣量的原版公式，故明確列作本作設定。

本作的攻防修正不改普通部隊對陣的傷害式；它們用於單挑。初始裝備、唯一物持有人、個人備用裝備與已處理的單挑取得收據跟隨戰役保存。換裝保留原裝備到該武將的備用欄，可按同一城市與武將行動規則重新配備，不退款、不重發初始品、不複製同一唯一物。

特殊取得按戰前實際君主身份及人物ID判斷。確定取得不額外抽亂數，30%／50%只抽一次，無資格或已被其他人持有時不抽；同一戰鬥、敗者及物品只處理一次。命中、先手與退卻使用本作可重播亂數，並由玩家／AI共同呼叫，不能把先看預覽當作重抽。

## 日本語

元の能力と装備を分けて表示します。武器・防具を替えても出典の武・知・徳・体力上限は書き換えません。Namcoの説明書44–47ページでは、一騎討ちの攻防に装備が働くこと、軽い武器が先手を取りやすいことを確認できます。正確な重量、命中、逃走時の消耗式までは載っていません。本作では総重量と武から負荷を出し、命中・回避・先手・一騎討ちからの離脱と部隊の敗退・撤退精算時の体力に同じ式を適用します。具体式は上の「本作實際採用的計算」に公開し、原作の確定値と混同しません。

元の武将表で人物IDが確認済みの223人は、明示した字形表で初期武器・防具を変換します。未対応14人を名前の似方で結び付けません。劉備の長剣、関羽の偃月刀などのFC初期値と、演義に基づく本作の専用武器は別に記録します。登用・所属変更・相続・移動・ロードで初期装備を再配布しません。

特殊装備は旧攻略の条件を参考にし、倚天30%、竜牙50%を採用する表と、異なる割合の後年記事を区別しています。聖者の衣の条件も「知90」「知と徳90」「徳90」の記述があり、本作で採用する徳90は公式説明書で確定した条件ではありません。戦闘中の店を都市画面にまとめる場合、撃破をHP1の敗走と扱う場合、重量の式や追加専用武器を設計する場合は、本作の適応として明記します。プレイヤーとAIで取得条件や唯一性、費用を変えません。
