# 一般計略の成功判定：B7BEと共通ルール

現行の戦術マップにある一般14計略を、原版で確認した距離・知差・等級差・最終バイト判定へ接続する段階の契約です。**籠絡ID8と十面埋伏ID11、旧非グリッド内部モデル、各計略の損害・持続・成長は今回の変更対象外**です。今回の実行時回帰・ブラウザー・長期検証の結果は、末尾の受入欄で別に管理します。

## 本作が共用する算式

施計者と最初に選んだ対象の知を`I/T`、現在の経験から同期された等級コードを`L/U`、可視マスのChebyshev距離を`d=max(|dx|,|dy|)`とします。知は本作の0–99、等級コードは0–7です。原packedYは16以上から1を引きます。本作は最初からメタデータ行15を除いた可視座標なので、合法マス同士では同じ距離になります。

```
d >= 6: 成功率0、成功判定の抽選なし
知差 = max(I - T, 0)
等級差 = 2 × max(L - U, 0)
距離補正byte = [15, 10, 5, 0, 251, 246][d]
最終byte = (距離補正byte + 知差 + 等級差 + 10) & 255
最終byteのbit7が1なら0にする
成功率 = min(95, max(5, 最終byte))
成功 = SeedRng.next() % 100 < 成功率
```

加算は無制限整数のclampに置き換えません。各原ADCはcarryをクリアして足し、最後のbyteだけの符号を調べます。例えば知差99・2倍等級差14・距離1なら`10+99+14+10=133`でbit7が立ち、成功率は5%です。127は95%、128は5%になる境界を保持します。知と等級が同じなら距離0–5の成功率は25/20/15/10/5/5%。これは旧`clamp(60+(知差//2),10,95)`と異なります。

空間・習得・APの資格判定は先に行います。通常、6マス以上の対象は資格段階で拒否され、APも乱数も変わりません。純粋な成功門も距離6以上では0を返し、成功乱数を要求しません。範囲内の合法な正式施計は既存の機動力を払い、既定の所選対象状態解除を行ってから判定します。失敗しても払ったAPや先行解除を戻しません。複数対象の計略も成功門は最初の対象で一度だけで、成功後の水格持続値や損害の抽選は各効果の既存契約に従います。

## 意図的に保つ違い

| 項目 | 原版 | 本作 |
| --- | --- | --- |
| 操作者補正 | 人間は常に+10。controller3のAIはLEVEL index0/1/2で+5/+10/+20 | プレイヤーとAIの共有条件として、簡単・普通・困難すべて+10。原AIだけの難度補正は採用しない |
| 成功乱数 | 固定置換表のbyteを100未満まで棄却。NMIでも状態が進む | 既存SeedRngの`next()%100`。原乱数列・棄却回数・NMI時刻の再現を目標にしない |
| 等級・知 | 原人物byte2とbyte11高位 | 既存プロフィールの知と同期tier。SAN14由来の固定基礎能力や永久成長方針を変えない |
| 読込と互換 | 原機の保存・UI | 保存形式・既存RNG状態を変えず、進行中の座標、AP、糧、条件を保持。旧非グリッド内部モデルは従来式を残す |

原256cursorの一定条件では、成功に使える1標本を得るためのE87A呼出が1–11回でした。本作の正式な一般成功抽選1回と同じ基礎乱数消費数とは呼びません。プレビュー、閲覧、言語変更、保存・読込、AI候補比較は0回です。籠絡の専用門、十面埋伏の無判定、火箭の成功後百分率、虚兵・連環・奇門の効果と日界順序はこの変更でまとめて再設計しません。

## 繁體中文摘要

本輪只接現代戰術格局的14個一般成功門，不改籠絡8、無成功抽樣的十面埋伏11及舊非格狀內部模型。距離用可見格Chebyshev，知差和等級差只取正值；完成8位元加算後才判負號，再限制5–95%。距離6以上不抽成功亂數。玩家與AI三難度一律採原玩家+10，不搬原AI獨有的+5/+10/+20；原置換表棄卻／NMI與本作SeedRng取模的差異明列為保留設計。傷害、持續、固定能力、成長和原有付AP／所選狀態先清順序不一起重做。原CPU研究與本作驗收分開計數：本輪凍結源碼的2,882項雙後端回歸、27組源碼檢查、10筆實際desktop／touch、29劇本各3旬與116次跨後端存讀皆通過；後期seed3兩後端各完成正式72旬與一次真實繼位。初次舊機率／距離及事件數預期失敗的紀錄保留，修正測試的舊機率／距離假設及交鋒中單挑／兵士戰的公開撤退流程後，完整重跑受影響範圍。到265年5月仍在進行，並非統一／滅亡終局，也不代表14計自然全覆蓋或early／middle與其他seed矩陣完成。
