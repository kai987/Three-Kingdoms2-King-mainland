# 策略与存档兼容

策略版本 211 写入普通和紧凑存档的现有 AI 策略字段。早于 21 的旧档与标记 21 的旧档保留各自策略。农业、市场、粮的缩放和行军费率各按原标记解释。

在途运队只有发运时已经按 211 生成了接济计划，才使用保护与会合流程。读取旧运单沿其原有口粮账和运输进度，市场库存及已发计划也从原档恢复。新恢复账记录已发生的损失与实际拨兵。

E4、F1、F2、F3 开关属于观战工具上下文，普通新战役启用两项改动。实际组别写入 run.json。

6 份用户提供的旧官渡存档使用同一个早期剧本 SHA。可用相同 SHA 的归档剧本续跑，当前地图版本的官渡会按原规则提示不兼容。验收包只收录校验值、对应提交与续跑结果。
