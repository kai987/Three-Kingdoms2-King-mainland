# 在途军队接济

手动送粮和委任运输调用同一个发运与校验入口。候选需要本方行军部队、可执行的命令书、可用押运武将、合法会合点和安全接收地点。出发时一次扣除装载货粮与押运口粮。人工可以选择预览允许的货粮数量，执行前重新检查费用、人选和实际地点。

每日口粮服务处理行军、途耗和会合。运队实际剩余口粮、实存货粮、现有路线和天气共同决定交付量。货粮只会写入真实处于同城的部队料袋。任务完成或目标失效后沿当前合法路线归营，剩余货粮和实存口粮交接到最终抵达的城市。
