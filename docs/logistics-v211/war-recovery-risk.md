# 战争恢复评估

记录最近 12 旬已经结算的战斗、行军和运队损失。正常配兵按本城抵销既有恢复需求。恢复目标考虑武将编制余量与可持续供养上限。新出征以现役兵的 20% 为预计损失，参与主动进攻的择机判断。

本城预备兵可以直接填补实际需求，受守城和其它战线约束。只给待重新募兵人数报价粮与金，使用实际军备官或现有手动费率。库粮先扣固定支出、安全储粮、继续驻防及有效计划预留。已启运的友方粮或金按到货期进入预测。月度稳定余额取本城常规收支，单次到货只计一次。

| 恢复期 | 候选主动进攻权重 |
| --- | ---: |
| ≤ 1 个月 | 100% |
| >1 至 3 个月 | 90% |
| >3 至 6 个月 | 70% |
| >6 个月 | 50% |
| 尚无可靠来源 | 35% |

实际收益分和恢复准备分参与同一个策略选择。若主动扩张理由不足，AI 使用原有前线调粮、增援、募兵、购粮和内政流程。现有历史战事、已有投入的盟军战线和针对实际进犯路线的反击可按原硬预算继续，规划分数不会扣款。
