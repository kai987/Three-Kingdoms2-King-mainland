# 押运口粮与货粮守恒

计算人数为实装现役兵、每名武将折算的 100 人，以及适用时在途预备兵。以现有粮食刻度和分段日费率累加。节点等待日使用基础费率。返程重新寻路，顺水去与逆水回各按实际分段报价。前一段的进位余份参与下一段。一趟 30 日平原、无等待和备用粮时，1 名武将分别携 0、100、500、1,000、3,000、5,000、10,000 兵，对应 75、150、450、825、2,325、3,825、7,575 粮。

候选的等待缓冲为 3 日，另计抵达时间差与正常结算边界。全程预算为去程、等待、返程与一次向上取整的 10% 备用。安全终点优先原城，也可以是能够收容的当前城市或有合法道路的安全友城。

交割前按现有兵力和季节重算返程及到处理节点的等待。料袋里的返程粮留在押运队，必要时从货粮留出缺额。货粮转入口粮仍走既有转账接口。换程关闭旧账，继承口粮余份，沿用原运单货粮和路线损耗余数。已扣粮和历日消耗以实际游戏回执核算。

| 账户 | 平衡关系 |
| --- | --- |
| 交付货粮 | 发运及后来入账等于交付、返还、转入口粮、途耗、天气损耗、明确遗失及剩余之和 |
| 押运料袋 | 实装及补入等于吃掉、转回货粮、进城返仓及剩余之和 |
