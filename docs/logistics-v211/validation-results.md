# 验证方法与报告

E4 使用策略 21。F1 单开军队接济。F2 单开战争恢复。F3 启用两项。先执行 184-02／2026、190-01／2027、208-10／2026、207-09／2027 四个重点对照。基准复采与旧档同源核查见 baseline-replay-parity.json。各候选版本与参数见 parameter-experiments.csv。

正式五年组按七个剧本、三个种子验证 E4/F3 的 21 个配对。二十年组另计。不同组策略可改变实际事件顺序与 RNG，配对锁定开局、引擎经济与军事规则、随机种子、难度及寿命。

测试日志区分最早失败、历史行为对照、修复后重点复测和最终完整相关批次。普通和紧凑格式以状态校验值和真实粮账检查后再续跑。验收包的 data/validation-manifest.json 记录工具链、完整回归和报告状态。

## 独立参数试跑

在四个先行剧本另跑一套恢复权重，把无可靠收入与六个月以上的候选权重分别从 35% 和 50% 改为 55% 和 60%。平均交战从 145.50 增至 222.25，平均粮缺口从 56,955 降至 33,005，连续受阻九旬的势力旬从 28.25 降至 1.00。小势力存续从 12/47 降为 9/47，行军部队饥损从 56,695 增至 67,216。四局结果保留在 looser-recovery-comparison.csv 和独立流水中。正式默认沿用已完成长程与全矩阵的候选。

未参与调参的 208-10／种子 2029 也做了独立配对。运队饥损从 12,892 降至零，交战从 161 降到 91，累计粮缺口从 96,965 升到 121,036。该样本未计入 21 对总体。
