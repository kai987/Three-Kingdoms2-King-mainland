# 已知边界与下一阶段

- 真实路线、月度库存、城市易主和海路天气可能改变会合日。返路完全失效且没有安全收容点时，押运队仍可能被迫等待或受损。
- 战略恢复依靠可执行的本地补兵与在途物资。远方库存须先走合法的发运流程。现阶段有限库存不能当成长期供应合同。
- 任务量减少时，同时核对交付次数、总量、目标行军饥损及未满足救援。运队低饥损只是评价的其中一项。
- 若后续增加积雪、季节河流或风暴，要保持行动 RNG 与预估分开，保留可版本化费率，补齐路线重验、改道与账目回放用例。进入下一阶段前先看五年、二十年的真实平衡和完整技术回归。

本轮仍需关注大型势力蓄积现役及预备兵、长期受阻增加、军队接济总量减少和二十年累计缺口。加入天气系统前需要重新验证这几项，尤其要确认只调援军安全与补充评分时，战事仍处于预定活跃区间。
