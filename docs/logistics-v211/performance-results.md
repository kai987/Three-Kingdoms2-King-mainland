# 回合性能与复用范围

每个运输委任批复用本势力的行军索引和会合预测。合法候选成批走现有原生寻路。返城报价按来源、会合点、季节与收容条件缓存。实际发运立即更新批内承诺。同旬新的外交、势力归属、路况与人员变化进入下一次独立计算。当前扣账在执行点重验。

战争恢复只在军事硬预算至少有一项可行时生成快照。多列组合复用该快照中的损失、预备兵与战线。常规视图沿用会话结果缓存。

performance-comparison.csv 区分 CPU、每旬墙钟均值与最慢值、进程峰值和路径调用。历史 E4 未采集的 CPU 读数标明缺失。组别战事数量、物理机并发和日志量都会影响耗时。独立后端回放另列 CPU 与墙钟。

| 五年观战 | 平均每旬墙钟 | 最慢旬 | 平均实跑 |
| --- | ---: | ---: | ---: |
| E4 含四局同源复采 | 0.979 秒 | 11.248 秒 | 179.5 秒 |
| F3 | 0.783 秒 | 3.612 秒 | 144.0 秒 |

这些是不同真实战况下的应用耗时。两组交战数量明显不同，以上差值不能当成单一寻路函数的加速率。已经验证相同指令下 Python 与 Rust 的规范化状态相同。
