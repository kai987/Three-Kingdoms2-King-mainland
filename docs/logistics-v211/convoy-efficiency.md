# 接济效率及武将挑选

用预计净交付粮除以实际装货粮与押运口粮的总和。净交付推算采用分段途耗，海路按风险允许的保守值预估。发运候选先看截止时间、缺口和净交付，再比较投入、人选兵力及路线。

候选以 70% 为优先、50% 为常规、30% 为最低偏好。50% 以下需要更紧急的真实目标，低于 30% 还须覆盖有意义的实际缺口。兵力按 0–500、501–1,000、1,001–3,000、3,001–5,000 和 5,001 以上比较。超过 5,000 兵须满足更严格的紧急与净交付条件。健康、留守武将和最低守备沿用现有资格与安全检查。

评估时同时看观察期内成功交付、同批已结束运单成功率、净交付总量、货粮和押运开销、接济后仍发生的行军缺粮。
