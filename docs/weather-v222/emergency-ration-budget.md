# 出发与撤离口粮

正常发运保留完整去回程预算和 10% 安全量。接济加计到实际会合窗口的等待粮。出发时实际扣除自用口粮和货粮，供方库存低于保留量和资源承诺时归为不可发运。出发的规则入口仍是 `logistics.dispatch`。

已经在途的队伍到真实节点后单独审查。整段口粮包括去下一节点的移动、必要等待和应急安全量，单位人数直接来自现役押运兵、运输中的预备兵和仍在队中的人员。每名武将或地方文吏按 100 人折算。口粮余份进入整数预算。实际粮袋和可依法转出的货粮才是随队可用粮。

继续等待明显有短缺风险时，可以在够付移动和必要等待的前提下放弃建议余量。采用该例外会在撤离记录中标明。未来可能领到的粮用于判断能否分段继续，接收地点交割时才变成当前可用粮。
