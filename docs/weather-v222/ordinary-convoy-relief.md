# 普通运输接济

在没有短程自救方案、存在可恢复通路且当前实际节点允许会合时，可以从本方另一城派接济运队。目标可以运粮、金、宝物或预备兵，也可以由无现役兵的武将或地方文吏执行。队伍没有货粮仍可以请求接济。

派遣沿用命令书、押运资格、留守人数、城池资源承诺、去回程口粮及等待预算。报价偏好轻装和 70%、50%、30% 的现有效率档。缺粮迫切且能解除显著缺口时可接受较低效率。可用的自动派遣发生在势力已有运送委任任务中。手动接口沿用 `dispatch_transport`，传入实际会合城与 `target_convoy`。

接济队和目标队在同一天抵达同一真实合法节点，由共享交割流程登记。结算前重新评估需求与返程保护量，实际到货从接济队货舱扣除、进入目标队粮袋。城池粮仓不承担这笔外援。目标移动、失效、路权中断或超时后将释放有效会合承诺，已派出者继续以实际节点评估返程或撤离。
