# 区域经济 V3.0 准备

本轮技术回归通过。实际撤离、接济交割、返抵、收容和历年移交均有收据，38 局的逐队粮账与人员账没有未核实差额。受困队伍仍会受到路权、冰封、接收容量和粮袋不足的约束。

**按任务设定的长期运输安全条件，当前尚不能确认达到 V3.0 的启动门槛。** 五年配对中策略 212 的运队饥损明显下降，二十年对照有三组饥损增加，其中两组增幅在 50 人以内，赤壁策略 212 增加 2,290 人。二十年平均安全结束率下降 0.16 个百分点，实际安全接收人员占比提高 0.25 个百分点。需优先解释赤壁策略 212 后期的高损失，再判定长期安全。

五年样本容量只足以评价已选配对。策略 212 的五年饥损仍高于 200 人参考值，冬季补给距离无天气目标仍有缺口。长期运队饥损是本轮暂缓判定的主要原因。天气和运输应急继续使用独立开关。
