# 结案与物资

抵达只是物理位置，货物卸载表示交割，人员安全结束表示经过接收才离开在途队列。原城返抵、友城收容和势力投降既有规则引发的结算在观测中分别记录。只有前两种用于实际安全结束统计。发生历史既有的无友城退出时保留真实失败分类。

粮袋和货舱保持独立。粮袋余额先从旧行程记回货舱，再按新路线实际需求装袋，货粮转入口粮有成对凭证。货舱里的金、粮、预备兵和宝物继续分别计量。安全接收时由合法节点校验城市容量、收容武将及地方文吏，并将剩余口粮和货物记入相应账簿。同一任务只能结案一次。

零现役并不消除预备兵、人员和货物。只剩人员且能实际收入本方时可办理收容。没有合法退路或接收人时，诊断记录会随着真实状态更新。3、10、30 日为复查阈值，未完成任务可持续跨过阈值。
