# 观测数据字典

单局路径为 `observed/{I3/J1/J2/J3}-{211/212}/{seed}/{months}/{scenario}/`。数值来自实际回合的只读流水。空单元表示该事件无对应值，零表示有记录且没有发生相应扣账或人数变化。每次需要多个事件的数据以 `convoy_id`、`owner`、`tick` 和根需求 ID 连接。根需求 ID 仅在单局内唯一。

| 文件 | 行单位与用途 |
|---|---|
| `emergency-transport-decisions.csv` | 实际节点审查及原因，包含手头粮、全程预算、局部预算、候选点、可提取粮。 |
| `emergency-evacuation-plans.csv` | 实际建立的撤离路径、天数、备粮及是否分段。 |
| `convoy-relief-requests.csv` | 同一根需求的尝试、拒绝、派遣与取消。预计到货字段属于报价。 |
| `convoy-relief-deliveries.csv` | 接济队确实交割给目标队的实际粮与受保护返程量。 |
| `convoy-ledger.csv.gz` | 货舱变更前后余额，含风险、口粮、预备兵减员、卸货和接济。 |
| `transport-progress-daily.csv.gz` | 每日实际工作量、口粮、货粮变化以及冰封情况。 |
| `convoy-resolution-daily.csv.gz` | 每日连续待解、无行动、阻塞、距交割和现役、预备兵、人员与饥损分项。 |
| `convoy-terminal-events.csv` | 实际终止收据及同一时点的人员和物资，战略日为真正入账的日界线。 |
| `convoy-survival.csv` | 独立发运队伍的期末或实际结束状态、分别核实的损失与存活。 |
| `unresolved-convoy-cases.csv` | 观察期末仍在途，单独标识长时间危险等待。 |
| `run.json` | 真实运行状态、源代码身份、原始种子、规则、用时、观测行数。 |
| `exports/cargo-ledger-checks.csv` | 货舱流水、净货粮、预备兵入库和接济交割的独立复算。 |
| `exports/settlement-boundary-reconciliation.csv` | 最后一日行军后、观察截止前实际入库的预备兵，与期末运输持仓逐队核对的差异。 |
| `exports/archived-I3-identity.csv` | 同源重采的 I3 资料和已归档原有资料的逐文件比对，缺少匹配原局另行标注。 |

独立发运数为任务状态和安全结束的分母。已结束口径另列，期末仍在途视为右删失。历史口径按返抵收据计数。人员安全结束另要求各原有人员类别确实有幸存者或已有预备兵依法交割。结算日期按实际旬界换算，逐日行军数据仍按发生耗粮的服务日标记。人员安全按实际现役、预备兵及实存或入库计数。人员按每次发运统计人次，多次随队的同一人员会分别计数。武将和地方文吏独列。已经物理抵达但剩余工作量为零时，如果尚不能交割、受领或离开，仍计入未解决等待。重复计算报价不刷新最后有效行动日。

期末仍在执行的运队使用游戏的最终行程状态和末笔真实货舱收据，修正最后一日推进后发生的入库。生存表单列已确认的无友城预备兵损失。若人数还有未能凭已知收据解释的差额，记录在 `personnel_unreconciled` 字段。

军事补给按首次请求发生在 11 月至次年 3 月定为冬季。及时粮除以实测需求量，另列旧期限口径。对照围绕同剧本、同种子、同 AI 策略进行，每份配对单独验证区域天气、降雪和河段冰情。
