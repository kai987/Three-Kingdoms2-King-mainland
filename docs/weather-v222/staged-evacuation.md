# 分段撤离

路线从行程的物理节点出发。系统分别搜索较快、较省口粮和较低风险的路线，检验方向、地形、外交、敌我归属、冰封和既有海路与险路权限。无法合法进入的节点不会出现在目的地集合。已经困在敌城的队伍可以沿开通的实际路线离开。现有同盟协议允许通行，授予的通行权不改变粮仓、官籍或驻军归属。

通常保留负担得起的原城返程。若已抵达可接收友城且继续返程无足够口粮，可依法结束。若完整合法路线成本过高，可以先到有真实余粮的中转城。候选中转点必须用当前可用粮抵达，中转城当下的可调余粮也须足以支撑后续合法接收。到达后按照当时库存重新评估，同一相同返程后缀继续沿用原行程。

当产权、路权、冰态、补给或可接收条件发生变化时重新报价。中转历史用于避免在同一条件下往返重复尝试。每日仍按真实进度、天气、口粮和损失推进。完整报价在战略结算边界执行，批量图复用仅限该边界。资源和接收余量每次重新读取。
