# 验证结果

## 重点五年观战

26 局由三组 212 专项与两种策略的五组配对组成。三组专项中与 212 五组配对相同的 I3、J3 背景局只执行一次。五组配对为 207 年 9 月／2028、208 年 10 月／2026、184 年 2 月／2026、263 年 5 月／2026 和 190 年 1 月／2031。下表为每种策略配对五局的算术均值。

| 指标 | 211 I3 → J3 | 212 I3 → J3 |
|---|---:|---:|
| 运队缺粮损失 | 6 → 6 | 2,461.4 → 499.6 |
| 期末长期危险运队总数 | 0 → 0 | 2 → 1 |
| 实际安全结束率（全部发运） | 94.77% → 93.77% | 92.56% → 93.39% |
| 城市缺粮城旬 | 125.6 → 93.0 | 70.4 → 95.6 |
| 累计缺粮 | 65,510.8 → 49,859.0 | 31,762.8 → 46,223.4 |
| 交战次数 | 139.4 → 150.0 | 234.8 → 233.2 |
| 实际净送达粮 | 977,621.0 → 935,185.6 | 821,815.6 → 810,790.6 |
| 普通行军缺粮损失 | 80,199.6 → 82,023.6 | 63,438.8 → 64,464.0 |
| 冬季军事及时粮率 | 61.58% → 68.61% | 81.97% → 86.76% |

策略 212 的三局专项中，I3 平均运队饥损 4,102.3。J1、J2、J3 均为 832.7。J1 和 J2 实际执行的撤离与战局一致，在这三局中没有合法可发运的普通运队接济。J3 的收容和终止管理仍然改变了部分后续调度、缺粮和冬季及时率。在全部五年 J3 局，策略 211 与 212 分别实际产生 18、23 个撤离新行程。需要向其他城请求普通运队接济的分段和交割另外通过实际结算夹具验证。

在 207 年 9 月、2028 种子、策略 212 的完整配对中，I3 的 10,000 人全为原运队 77 的损失，J3 全局运队饥损为 191。原始检查点继续回放时，金城的无路和缺粮条件仍然真实存在。208 年 10 月的运队 2 和 184 年 2 月的运队 45 在对应五年重跑中损失仍为 1,307 和 1,000。这些样本全部计入统计。

策略 212 的五年配对仍高于每局 200 人目标。冬季粮率改善是相对于同气候、同剧本及同种子 I3 的结果。历史 21 局无天气矩阵的阈值有不同样本范围。

## 独立种子

207 年 9 月的种子 2034 另跑了四局。两种策略的 I3、J3 都没有发生运队缺粮减员。211 缺粮城旬为 160 → 170，冬季军事及时粮率为 85.37% → 86.13%。212 缺粮城旬为 28 → 26，冬季军事及时粮率两组均为 87.15%。这些结果按独立样本统计。

接济夹具中向南郡的实际发运扣 1 本命令书、172 粮，其中 114 粮装作货粮、58 粮装入口粮袋。第 12 日两支队伍实际会合，65 粮从接济队货舱转入目标队粮袋。历史、期末持仓和结案收据分别核实，单独证据在 `checks/fixture-relief-proof.json`。

## 回归证据

- `checks/emergency-fixtures-final.log` 含路线、资源承诺、迟到接济、单层依赖、待援和无援、收容幂等性、30 日冰封、旧档和旁观只读专项。属性循环分别覆盖 1,000 组预算、1,000 组依赖与 1,000 组入库。
- `checks/full-suite-final.log` 及各分片日志给出相同项目规范下全部 Python 与 Rust 后端回归。
- `checks/cargo.log`、`checks/march-build.log` 和 `checks/wasm.log` 核对原生 Rust、ABI 和 24,689 组参考向量；`checks/js-final.log` 使用 CI 的 Node 24 运行。
- `checks/browser-emergency.log` 使用独立 Chromium 上下文测试桌面和移动视口。通过新战役选项开启 222，导出存档确认天气未被同时启用，再读取受困运队检查点并验证繁中、日文、明确未知到达日和页面错误。截图附在 `checks`。
- 六份早期官渡文件在 V2.2.1 和 V2.2.2 均以原有剧本不兼容提示拒绝。可兼容剧本和规则的旧档、新普通档和紧凑档在回归中另有实际读取。
- `simulation-manifest.json` 列出每局而非任务席位总数、源代码身份、完成状态、天气种子与缺失项。验收包中各成员 SHA-256 可独立复验。
