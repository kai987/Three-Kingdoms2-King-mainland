# 朱崖・夷洲の史料と本作の島嶼拠点

朱崖と夷洲は、現在の29本すべての開始時に**島嶼地域（中立）**として扱います。遠征の記事や同名の郡の設置を、そのまま地図上の島全域の占領月へ置き換えません。中立は無人島を意味せず、確認できない初期守将や勢力駐軍を創作しないための表示です。

この変更は歴史説明の追加です。開始時の所有者、人物配置、資源、都市規模は変えず、暦の進行による呉への強制移管もしません。プレイヤーやAIが実際に占領・駐屯した後は、その戦況に従います。

## 朱崖：徐聞の郡と海南島を区別する

| 史料の時点 | 確認できる内容 | 本作で断定しないこと |
| --- | --- | --- |
| 239年（赤烏二年） | 『元和郡県図志』の後世に伝わる逸文に、徐聞で朱崖郡を設けたという年記がある | 設郡月、海南島全域の占領月、島上の恒久的な守将配置 |
| 242年7月（赤烏五年） | 『三國志』呉主伝は聶友・陸凱の珠崖・儋耳への派兵を記す | 出征した月と占領を完了した月の同一視 |
| 赤烏年間（月不明） | 『三國志』陸凱伝に儋耳太守の任と朱崖征討の功績がある | 伝文だけから任官月や継続的支配の範囲を確定すること |

『宋書』州郡志には徐聞が以前朱崖に属し、晋の平呉後に合浦へ移された沿革もあります。本作の朱崖は海南島方面の代理拠点です。雷州半島の徐聞にある郡治と、海南島を表す地図の座標は同一ではありません。

239年の逸文は後世の輯佚・伝本で、同じ段には住民が服属せず土地も保持しなかった趣旨の記述と文の重複があります。伝承の精度を区別し、月を補いません。また、『三國志』の242年の記事と組み合わせても「239年某月、または242年7月に本作の海南拠点が呉へ帰属した」とは確定できません。

出典：『三國志』[巻47・呉主伝](https://zh.wikisource.org/zh-hant/三國志/卷47)、[巻61・陸凱伝](https://zh.wikisource.org/zh-hant/三國志/卷61)、『宋書』[巻38・州郡志](https://zh.wikisource.org/zh-hant/宋書/卷38)、[『元和郡県図志』逸文の伝本](https://www.shidianguji.com/zh/book/CADAL02035716/chapter/1l7kl9gv9e0qe)。

## 夷洲：遠征と持続的な行政支配を区別する

『三國志』呉主伝は、230年（黄龍二年）正月に衛温・諸葛直を渡海させ、夷洲・亶洲を求めたと記します。夷洲から数千人を連れ帰ったことと、翌231年二月に両将が命令違反と無功により処刑されたことも記します。これは出航と事後処分の時点であり、設郡・守将配置や島の持続的支配を証明する年月ではありません。[出典：『三國志』巻47](https://zh.wikisource.org/zh-hant/三國志/卷47)

本作は夷洲を台湾方面へ対応付けていますが、これは限られた地図での作者の設定です。古代地名と現在の島・行政境界を無条件に同一視しません。230年1月にも231年2月にも、既存の中立拠点を自動で呉領に変更しません。

## 画面とデータ

都市情報の冒頭に両言語の短い説明を表示し、詳細欄では史料の年月、資料の限界、地図の対応関係を確認できます。開幕前の都市プレビューにも同じ資料を渡します。履歴は地図と戦況の説明であり、占領や人物生成を実行するイベントではありません。

共有の編集元は `game/config/campaigns/shared.json` の `city_history.zhuya` と `city_history.yizhou` です。184年・188年の独立した履歴差分も説明を継承し、既存の開始時所属根拠は保存します。`chronology` は原典の出来事、`occupation_date: null` は本作拠点の確定した占領月がないことを表します。

## 追加DLCが選択欄に見当たらないとき

現在の選択欄は**史実23本／仮想6本、計29本**です。追加した「呂布討伐戦」（198年3月）、「河北争乱」（202年6月）、「潼関の戦い」（211年7月）、「合肥の戦い」（215年8月）は、いずれも史実のグループにあります。「入蜀争奪戦」は212年12月の独立したシナリオへ改めました。[追加シナリオの資料](dlc-scenarios.md)、[23本の勢力・境界都市レビュー](scenario-history-audit-20261025.md)

旧25本版のローカルサービスを `http://127.0.0.1:8878/` で起動したままの場合、そのプロセスは起動時に読んだ25本を保持します。ページの再読み込みだけでは、サーバー側の一覧は更新されません。保存を確認してから最新版のサービスを起動するか、既存の戦役を中断したくない場合は別ポートで起動してください。

```sh
python3 -I -S -B game/serve.py --port 8879
```

その場合は `http://127.0.0.1:8879/` を開き、史実グループの4本と合計29本を確認します。[オンライン版](https://kai987.github.io/Three-Kingdoms2-King-mainland/)は最新の配信を再読み込みし、追加データは新規戦役から利用してください。既存の戦役を、説明データだけを理由に自動で置き換えることはありません。
