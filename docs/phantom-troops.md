# 虚兵：移動封鎖と戦場の日界

本段階の対象は、座標と機動力を持つ現行戦術戦闘（`extended.tactical`）の**虚兵・計略ID2だけ**である。原版で確認した移動封鎖、攻守別の計数、日界更新、解除の順序を専用状態で扱う。連環・奇門遁甲・偽撃転殺や旧`stunned`／`guard`の意味を、この変更でまとめて置き換えない。実装・回帰試験の合格状況は、各実行結果で別途確認する。

## 原版の根拠と適応の境界

使用者が所持する固定ROMのSHA-256は`26c8d921ff5c208191f136480bcd8d7e89c2e4ed40a0ac7b51482bcb52fe2b82`。研究アーカイブ`Three-Kingdoms2-Research-Archive/2026-10-22-web-cleanup`の復元コードと原命令を照合した。詳しい呼出経路・独立6502観察の前提は[状態監査](original-tactic-status-audit.md)に記録している。受制御RAMを用いた原CPUの呼出境界観察であり、原版の自然な一戦を全操作再現したという意味ではない。

| 項目 | 確認した原入口・資料 | 本段階の扱い |
| --- | --- | --- |
| 虚兵の成功後書込み | physical12 `B155`、`source/recovered/tactical_effects.py:83–115` | 攻方からは3、守方からは2。持続値の追加抽選なし |
| プレイヤーの移動制限 | physical12 `A162/A167`と`A1AC` | 移動だけを拒否。虚兵だけで攻撃・施計を禁止しない |
| AIの移動制限 | physical8 `A705`付近、`source/recovered/tactical_decisions.py:168` | 同じ移動資格を使用 |
| 攻守・日界 | physical25 `B7D9–B858`、physical13 `DD31–DD71`、physical12 `BDC0–BE7D` | 攻方先手。守方終了後だけ一日進める |
| 日界の低状態処理 | physical9 `CD78→CE40` | 戦期・食糧による終了を先に判定し、継続時だけ残数を1減らす |
| 普通接敵の目標解除 | プレイヤーとAIが共有するphysical12 `A3D2/A3E6`。AIは`BFDC→C000 JMP A3D2` | 実際に攻撃される隊だけ解除。自発的な攻撃で自身を解除しない |
| 施計確認時の解除 | プレイヤー`AA55`、通常AI`C09A` | 成否判定前に実際の作用目標を解除 |

一般計略成功門`B7BE`の環境欄位`050F/6F02`の完全な対応は、なお未確定である。成功率まで原版を復刻したとはせず、虚兵は既存の本作モデルを維持する。

```text
成功率 = clamp(60 + floor((施放者の知 − 目標の知) / 2), 10, 95)
成功   = SeedRng.next() % 100 < 成功率
```

合法な虚兵の実施で成功判定を一度抽選し、成功後の2／3計数には乱数を使わない。原機の乱数列や棄却抽選を再現せず、既存の`SeedRng`と剰余抽選を使う明示的な適応である。プレビュー、候補評価、状態参照、移動拒否は抽選しない。学習条件・射程・目標の森林／山地条件・4機動力の費用は、既存の共通資格と支払処理に従う。

## 効果と日界

成功すると対象隊は戦術地図で移動できなくなる。兵を減らす効果、次の攻撃を自動失敗させる効果、追加の機動力税ではない。合法な相隣攻撃や計略は引き続き可能であり、他の独立状態・通常の資格制限はそのまま適用する。

| 施放側 | 書込み直後 | 更新の読み方 |
| --- | --- | --- |
| 攻方 | 残数3 | 攻方終了→守方への切替では減らない |
| 守方 | 残数2 | その守方終了直後の日界で1減ってから攻方へ戻る |

攻方→守方→次の日の攻方、という戦闘の順序で処理する。両側が一日分の行動を終えるたび、戦闘糧と30日の戦期終了を先に判定する。終了していれば虚兵の時計は進めない。食糧サービスが残存する小口の食糧信用分も含めて判定するため、表示袋数が0という理由だけで終了扱いにしない。

継続していれば残数を1減らし、0になった隊の記録を除く。同じ日界の再呼出しでは二重に減らさず、複数日を飛ばした更新は不正な手順として拒否する。**残数は日界の走査回数で、相手が操作できない固定回合数ではない。** 途中の攻撃・施計による解除もあるため、表示も「移動封鎖の残数」として扱う。

## 解除・再施放・単挑

- 普通接敵が正式に実行されたとき、被攻撃隊の虚兵を兵士戦への移行前に解除する。発起側の虚兵はそのまま残る。単に隊を選択する、接近経路を調べる、取り消す、資格不足で拒否される操作では解除しない。
- 別の計略が実施されると、成否判定前に実際の作用目標の虚兵を解除する。このため、その計略が失敗しても旧虚兵は既に解除されている場合がある。虚兵の再施放も、成功すれば新しい2／3を上書きし、加算・重複しない。
- 十面埋伏ID11の実際の対象は施放者自身である。旧UIが渡していた敵隊引数を解除先に使わない。
- 帰順時は対象の虚兵を解除し、死亡・戦場離脱・名簿からの除去も残存参照を取り除く。戦場に残った発起者は、攻撃や通常の存活結果だけでは解除しない。
- 本作の戦術地図から直接選ぶ**単挑ショートカットは普通接敵ではない**。単挑の開始・拒否だけで、どちらかの虚兵を解除しない。単挑の結果で実際に部隊が除去された場合は、通常の除去処理に従う。

ID11には原版の非対称がある。原プレイヤーは`A9C4→AA03`で自身を目標に設定し、`AA55`で自分の状態を解除する。一方、原AIは`C004→C1AF→B02B/B42A`の捷径で`C09A`を通らず、どちらの状態も解除しない。本作では使用者の指定する**プレイヤーとAIの同一規則**を優先し、共通の施計サービスで両者とも実際の自身を解除する。これは原プレイヤー側に合わせた明示的適応であり、原AIの完全再現ではない。設伏の既存の簡略効果・費用・時計を追加変更する根拠にはしない。

## 保存形式と旧状態の互換性

[専用サービス](../source/remake/battle_conditions.py)は、任意の`extended.conditions`だけを管理する。

```json
{
  "schema": "tk2-battle-conditions-v1",
  "day": 4,
  "units": {
    "人物ID": {"kind": "phantom", "remaining": 2}
  }
}
```

`day`は最後にこの帳簿を同期した戦闘日、人物キーは戦闘の実際の人物参照を文字列化した値である。歴史武将と生成文吏の双方を扱い、相手の現在の陣営を永久に固定する値ではない。型・完全なフィールド集合・人物の存在と生存・残数1〜3・日数の整合を検査する。生存する隊は最大20隊で、未知の状態名や余分なフィールドを受け入れない。

`conditions`がない旧戦局は、参照・プレビュー・保存検査だけで新帳簿を作らない。**現行戦術戦闘で虚兵が新たに成功した時点**で、その戦闘日から初めて作る。`support.stunned`の出所は旧虚兵・連環・偽撃転殺などを区別できないため、旧値を新しい虚兵と推定して変換しない。旧`stunned`／`guard`とその既存動作は保持し、連環・奇門の持続効果もこの段階では変更しない。新しい虚兵の解除が、別の旧フラグまで勝手に消すこともない。

帳簿が一度できた後は、全隊の効果がなくなっても空の`units`と同期日を保存できる。読込で現在位置、兵数、機動力、乱数を再発行しない。新しい`conditions`があるのに保存済み戦術座標が欠けているデータは、真正の旧形式として自動補完せず拒否する。これにより破損した現行戦局が旧配置へ静かに戻ることを避ける。

AIはプレイヤーと同じ移動禁止・合法な攻撃と施計・支払・日界・解除を使う。候補の利益評価は、本作の移動封鎖価値と残存戦期を使う推定であり、原版AIの判断順位を復刻したという主張ではない。既に封鎖された対象への重複施計を高く評価せず、相隣隊の反撃を「虚兵で消せる」とは数えない。

## 繁體中文摘要

本輪只替現行逐格戰鬥的**虛兵ID2**接入獨立狀態；連環、奇門、偽擊轉殺及舊`stunned`／`guard`不改。成功後攻方施放寫3、守方寫2，限制移動而不額外禁止合法攻擊與施計；只在守方結束、兵糧及30日戰期仍允許繼續時減1。這是剩餘日界掃描次數，不是固定幾回合不能操作。

普通接敵清被攻隊，不清主動進攻者；實際施計先清作用目標，再判成敗。十面埋伏的作用目標是自己：原AI捷徑本來不清，本作明示統一為玩家與AI都清自身，不誤清舊UI傳入的敵隊。戰術地圖直接發起單挑是本作快捷操作，不當成普通接敵解除虛兵。歸順及真正退場另按對應清理處理。

一般成功門`B7BE`的環境映射仍未完整證實，保留本作知差成功率及`SeedRng.next()%100`，虛兵不另抽持續值。新狀態以可選`tk2-battle-conditions-v1`帳簿保存；舊戰局缺欄位就保持缺欄位，不把來源不明的舊擾亂旗標猜成新虛兵，也不在讀檔時補兵、補機動力或重抽亂數。此文件說明來源與接入契約，不代替執行時測試結果。
