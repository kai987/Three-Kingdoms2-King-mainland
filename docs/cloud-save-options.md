# 存檔方式與雲端接入

目前遊戲提供瀏覽器本機保存，以及下載／匯入JSON存檔；尚未啟用遠端雲端儲存。保存內容包括原劇本、目錄SHA、完整戰役、亂數狀態和校驗值。舊目錄保留後，舊存檔仍按原規則恢復。

可接入兩種雲端方式，待選擇儲存方式與目的地後實作：

| 方式 | 使用方式 | 需要確定 |
| --- | --- | --- |
| 帳號式雲端存檔 | 遊戲內登入，列出私人存檔並跨裝置讀寫 | 儲存專案、登入方式與存檔槽位 |
| iCloud／OneDrive等同步資料夾 | 本機服務將存檔寫入指定同步資料夾，由既有服務同步 | 使用的雲端服務與資料夾位置 |

帳號式可使用[Supabase Auth與使用者資料隔離](https://supabase.com/docs/guides/auth/managing-user-data)。每個帳號的存檔應以RLS隔離；前端只使用公開的publishable key，不放管理密鑰。存檔內容應保存為原始文字／檔案，保留舊版小數表示；不能重新產生checksum來掩蓋資料變更。載入時仍交給既有戰役驗證器核對版本、目錄與兵員守恆。

同步應另處理同名槽位衝突、網路失敗及較舊裝置覆蓋較新進度。寫入同步資料夾只代表本機檔案保存成功，不能直接宣稱遠端雲端已完成同步。

本次只查詢了可用服務；沒有建立雲端專案、資料表或上傳玩家存檔。瀏覽器存取已先修正為原始JSON文字傳輸，並驗證舊版行軍存檔的校驗相容。
