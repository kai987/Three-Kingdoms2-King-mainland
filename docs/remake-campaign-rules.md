# 目前戰役規則

25 個劇本共用目前規則，最多 115 城、每城 99 名在籍武將、每方出戰 10 人、每將最多 999 兵。人物總庫 1,023 人，按劇本日期與明列 IF 差異安排在籍、在野、未來登場或排除。

武、知參考逐人SAN14遊戲數值，原始100依本作尺度轉成99，保留來源值。德採「已核對姓名身分的原版ROM值優先」：220名對應原版人物保留原版德；其餘803名採史料參考的遊戲評分，史料不足依使用者指定設為60。體力、適性、忠誠、兵力、裝備及經驗採本作規則，不把數值當作歷史測量。原版「經」顯示為原始經驗除以50向下取整，0–999；原始值範圍0–49999，登場初始化為0並由遊戲行動累積。欄位來源、214筆修正及待核身分見[武將屬性來源](officer-attribute-sources.md)。

城市初始錢、糧、預備兵與月收入依城市規模、區域及開局年代配置；開始後由實際行動與月結決定，不按史實日期強制重設存量。建城時繼承母城當時的實際勢力並分割存量，不憑空複製資源。

每回合固定為1旬10日，每月30日，上旬1日、中旬11日、下旬21日。各勢力每旬依序行動；進入下一旬時重置行動。月收入、體力恢復及按月事件僅進入下月上旬時結算；年度事件僅跨年執行。行軍抵達所需回合為 `ceil(路程日數 / 10)`，例如21日要3旬，20日不能提前抵達。

招募與勸降會扣費並消耗行動，使用人物德、忠誠等規則判定；轉屬不能讓人物同時出現在兩處。勝敗、退卻、戰後接收與繼承均由實際戰局結算。每次指令與讀檔均驗證兵員總帳、名冊唯一性、目前年代與亂數狀態。

行軍使用距離、地形、海陸路線、季節及季風；風暴在完整航程結算一次，預覽不抽亂數。新海路只在探索成功到達後顯示。詳見[行軍規則](hazardous-travel.md)。

目前 AI 與事件畫面的精確範圍見 [AI 與事件](ai-and-events.md)。歷史歸城參考、有限生涯推定與本作區域配置分開記錄；配置齊全不代表逐人逐月的歷史駐軍已全部確證。
