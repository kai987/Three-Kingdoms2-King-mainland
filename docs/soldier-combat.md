# 兵士戰與原版算式

普通接敵與城砦接敵都先進入兵士戰：確認長蛇、雁行、錐行、魚鱗之一，再對主將與每一隊步、弓、騎獨立下達前進、後退、待機或包圍。每將上限1000人，每100人一隊，末隊保留餘數；主將另佔一格。這是使用者指定的千人上限與逐隊操作擴充，不能寫成原版每將999人的限制。野戰無城牆，攻城使用原版雙城門的18個阻擋格。

## 可重查的原版數值

原版攻基位於physical15 `C991–CA1E`；弓隊近接為physical14 `A84D–A870`、遠射為`A871–A8CE`，人數與目標兵種修正為`A8F2–A99F`。獨立6502執行見[凍結輸入輸出](../tools/siege-original/soldier-rules-reference.json)，含126組攻基、2080組傷害；只保存數值、來源區段與runner雜湊，遊戲不讀ROM、不執行舊機器碼。

攻基是 `floor(武 × 係數 / 100) + 9 − 0至8的亂數`，係數如下：

| 武 | 係數 |
| --- | ---: |
| 1–64 | 45 |
| 65–79 | 50 |
| 80–86 | 55 |
| 87–91 | 60 |
| 92–96 | 65 |
| 97–99 | 70 |

弓隊貼身以攻基60%計算，遠射以70%計算；主將出手才加其實際兵器威力。接著按當前隊伍人數／主將體力換算權重：

| 當前人數／體力 | 權重 |
| --- | ---: |
| 1–14 | 20% |
| 15–34 | 40% |
| 35–59 | 50% |
| 60–79 | 70% |
| 80–89 | 85% |
| 90–99 | 95% |
| 100 | 100% |

每步取整。攻擊騎隊的結果是 `floor(傷害/2) + floor(傷害/4)`；攻擊主將則先除2，再扣其防具威力，最低可為0。兵器不會加到所有兵卒，防具也不會替整軍抵傷。失去全部人數的兵槽不再行動。

本作明示的差異：沿用共享種子亂數流，以`next()%9`取攻基亂數，在**第一次真正交鋒**為雙方各抽一次並持久保存；選陣、改指令及看預覽不抽亂數。原版算式後保留先前確定的訓練度修正`clamp(100 + floor((訓練度−70)/3), 80, 110)%`及守護減半。這些後置修正、亂數來源、三面包圍且敵將體力不高於30的確定性降伏、200巡退出保護均為本作規則，不冒稱原版機率或原版亂數序列。原射擊強化等未接入的原狀態位也不包含在零強化基準樣本內。

## 原版動畫

原核心的OAM／CHR捕捉新增步、弓、騎、將各兩個**不同的行走姿勢**，及原箭矢、近戰命中閃光，均精確放大4倍。原近戰使用靜止兵圖、兵前閃光`BE15`與受擊目標閃爍`A6D0`；不將走路姿勢冒稱另畫的揮刀姿勢。原箭矢由`BE76`投射。

完整截幀、調色板、OAM座標、翻轉位、每片CHR與透明索引保留於[素材清單](../game/assets/siege-original/index.json)和[捕捉依據](../game/assets/siege-original/animation-provenance.json)。畫面是在隔離測試快照中讓雙軍前進，僅改4個原命令位元組；不是自然進行的戰役、沒有修改ROM或玩家存檔。灰／紅兩軍使用原版對應調色板，透明以原圖樣索引判定，不按RGB把灰甲抹掉。

一次推進只結算一次。回應的暫時`presentation`保存該巡實際起終位置、射擊、兵損；即使最後一巡已返回大地圖，仍能播放最後一擊。動畫不抽亂數、不再次造成傷害，不進入戰役存檔。進行中的子戰鬥則保存逐隊指令、兵數、位置及攻基，可原樣讀回。舊版只有兵種分組指令的攻城存檔仍可載入及繼續。
