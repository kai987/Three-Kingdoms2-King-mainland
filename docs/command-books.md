# 命令書：勢力共用的戰略行動額度

命令書由整個勢力共用。只要本旬仍有餘額，就能把全部命令書投入同一座城，也可以分散到多城；城市已執行過命令不再單獨封鎖下一項操作。在籍、健康且未在途的武將可繼續執行符合條件的命令，仍須支付實際資源，並遵守招募冷卻、登用對象、唯一裝備、城池容量等各項限制。

玩家與AI使用同一份額度及扣款服務。查看、預覽、取消、切換語言和讀取存檔不會重新發書，也不因介面操作抽取遊戲亂數。戰場移動、接敵攻擊、計略與單挑使用獨立的[戰術機動力規則](battle-tactics.md)，不消耗戰略命令書；戰場餘額可在其上限內結轉到次日，與本頁的旬界不結轉不同。

## 原版可以確認的規則

Namco原說明書[第10頁「命令書」的公開掃描](https://cdn-ak.f.st-hatena.com/images/fotolife/j/jackallsasaki/20260802/20260802002804.jpg)明確說明：命令書是君主的共用額度，在數量範圍內可以向同一城反覆下令，數量隨領城數變化。原版全部君主行動一巡是一個月。

使用者提供的《三國志2 超級版》ROM與既有研究的SHA-256一致。原程式在每個君主回合按領城數讀取physical bank25、CPU `$A0E4`（檔案位置`0x320F4`）的表，直接覆寫剩餘命令書，不把上回合餘額相加。這是實際查表，不是以城數線性估算的公式。

| 領城數 | 回合發放命令書 |
| ---: | ---: |
| 0 | 0 |
| 1–3 | 3 |
| 4 | 4 |
| 5 | 5 |
| 6–8 | 7 |
| 9–12 | 8 |
| 13–16 | 9 |
| 17–19 | 10 |
| 20–23 | 11 |
| 24–27 | 12 |
| 28–30 | 13 |

原版共用的具體命令確認程序`$D5BD`在接受命令後扣1本，取消分支不扣。僅進入「城／軍隊／倉／町」分類不扣書；米糧交易、賣寶、治療／求學及裝備購買各有自己的確認扣書點，不能解讀成進店扣1本後無限購買。

[說明書第25頁](https://cdn-ak.f.st-hatena.com/images/fotolife/j/jackallsasaki/20260802/20260802002836.jpg)明列任命太守不耗命令書。同頁的配兵說明要求：只分配現有預備兵時，從「徵兵」選擇僱用0人再進行分配。原機既有冷啟動回放也確實在同城連續確認三次徵募／配兵，命令書由3降至0；第一次實際徵募數被上限保留為0，仍扣1本後分配預備兵。後續分配步驟沒有再扣第二本。

同將反覆內政的結論來自已恢復的國造り路徑：讀取執行者知值並更新城市與金錢，沒有寫入本作舊設計的「武將本旬只可行動一次」鎖。本次未另啟動模擬器製作同一內政執行者的連續原機回放，不把這項源碼證據說成新增的實戰錄影。

31項原始數值、ROM指紋、掃描URL與圖片指紋、既有恢復源碼位置與原機回放證據收錄於[命令書來源表](../game/config/references/original-command-books-v1.json)。原ROM及玩家的模擬器狀態未修改，也不放入Web發布包。

## 本作如何適配

本作保留已確定的**1回合＝1旬＝10日**。每旬重新依勢力領城數發放命令書，未用餘額不結轉；原版的恢復周期是一個月，改用旬是本作適配。當旬額度在旬界確定，不能靠途中換城或讀檔重新領取。

地圖有115城，超過原表的30城範圍時，沿用最高13本的上限。這是擴充地圖的封頂規則，不宣稱原ROM存在115城公式。只有有主且屬於該勢力的城池計入；無主城不產生命令書。

| 本作操作 | 命令書 | 來源與處理 |
| --- | ---: | --- |
| 徵募、獨立配兵確認 | 1 | 原版「徵兵＋分配」為同一付費流程；本作獨立配兵對應僱用0人的流程。若配兵只是已支付徵募命令的一個內嵌步驟，不再重扣。 |
| 登用、勸誘、地方文吏招募、開發、防災、賞賜、搜寶 | 1 | 每項有效確認使用勢力共用額度；招募等結果遭拒仍屬已執行命令。擴充服務沿用同一付費方式。 |
| 治療、求學、米糧交易、賣寶、購買裝備 | 1 | 每次具體服務確認扣1本，另付實際金錢或物資。 |
| 出陣、武將移動、運輸隊出發 | 1 | 一次出發命令扣1；之後按現有規則行軍、耗糧、補給及返程。 |
| 任命太守 | 0 | 原版說明書明列免費。 |
| 查看情報、預覽、取消、政策設定、檔案及雲端存取 | 0 | 保留本作現代介面的控制方式，不聲稱與原版每個同名選單完全一致。 |

自動內政、設施與運輸的主動命令也扣同一勢力的命令書，額度耗盡便停止額外付費工作；委任後的持續商農收入、旬末訓練與自動配兵不另扣書。不能因逐城掃描而重新取得城市行動，也不替AI額外發書。部隊在途、交戰、缺資源、無合適對象或輸入無效時仍由操作本身拒絕；拒絕的交易不扣書。命令書餘額與已執行命令一同保存，讀檔不會補滿。新版存檔使用格式2，必須帶有完整帳本與旬界領城清單；刪去帳本、帳本不平衡或城數與清單不符均拒絕。只有目前資料集的格式1舊檔可依已行動城市保守計入已用命令書，再匯出為格式2；已有帳本不走舊檔補帳。本機、自動恢復點與雲端槽位均接受這兩種格式；雲端仍原文保存，遊戲載入時再驗證完整帳本。

## 日本語

命令書は勢力全体で共有します。残数の範囲内なら同じ都市へ続けて命令でき、別々の都市へ振り分けることもできます。健康で在籍し、行軍中ではない武将は各命令の条件に従って再び働けます。都市や武将が一度働いただけで、残りの命令書をその都市に使えなくなる方式を改めます。

原作は君主の月ごとの手番で、領有都市数を表に当てはめて残数を置き換えます。本作は既定の10日＝1旬を維持し、旬の境界で再配布します。未使用分は持ち越さず、拡張地図で30都市を超えた場合も上限13冊です。この旬制と拡張地図の上限は本作の適応です。

内政・人事・施設の取引・出陣・移動・輸送等の確定命令は原則1冊です。編制だけを行う場合も1冊で、原作の「0人を徴兵して控え兵を配分する」手順に対応します。すでに払った徴兵処理の一部として配分する場合には重ねて払いません。太守任命は原作説明書どおり無料です。閲覧、取消、方針設定、セーブ／ロード等の本作の操作も無料です。プレイヤーとAIの残数・資源・実行条件を共通にし、画面を開くことやセーブの読込だけで命令書を補充しません。
