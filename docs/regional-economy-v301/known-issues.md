# 已知问题

- 动态价格改变早期市场成本，进而改变一些战局和供粮。赤壁五年无天气配置的城市缺粮指标相对基线恶化。区域采购缓解了部分价格试验的恶化，仍超过警戒线。
- 自动商业在四个标准 R3 五年观战中没有实际订单。受控用例已覆盖真实采购、运输、盈利出售及到货后行情下跌取消自动成交。多剧本自动商业能否缓解价格失衡仍需后续验证。
- 启用冬季天气后凭当前合法路权和天气重新报价。日后易主、冰封变化和战局可能使返程不可行。1706 是这类问题的专项回归，保留真实陪同兵损与终结凭证。
- 区域市场只连通同一势力的实际城市，盟友求援继续沿用既有规则。市场金钱流入和流出有明确流水，游戏经济仍保留已有的货币注入来源。
- 首轮矩阵的原始探针未记录官仓正常生产和加成的逐笔贷记。赤壁专门配对重放验证了新版探针及其不改变既有结果。市场和实体运输在全矩阵均按实际流水审计。
