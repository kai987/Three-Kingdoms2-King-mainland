# 库存价格

库存价格修正以旬初商品粮库存 (Q) 除以当月一次供应 (S) 决定。档位边界使用整数乘法比较。

| (Q / S) | 市场状态 | 买卖共同修正 |
| --- | --- | ---: |
| 小于 25% | 严重短缺 | +4 金 |
| 25% 至低于 50% | 紧缺 | +3 金 |
| 50% 至低于 100% | 偏紧 | +1 金 |
| 100% 至低于 200% | 正常 | 0 金 |
| 200% 至低于 250% | 充裕 | −1 金 |
| 250% 及以上 | 大量富余 | −2 金 |

买卖各自叠加当前町基础价、既有季节修正和库存修正。卖价限制在 1–99 金。买价限制在卖价加 1 至 100 金。显示单位为每 1,000 粮的金量。同城即时价差至多为负 1 金／千粮。

案例按町 2、1 月、月供应 10,000 粮计算。库存 2,000 对应买／卖 14／12，15,000 对应 10／8，27,000 对应 8／6。完整边界向量见 `market-price-cases.csv`。
