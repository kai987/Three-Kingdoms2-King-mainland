# 存档兼容

| 设置 | 行为 |
| --- | --- |
| 原存档或默认新战役 | 区域市场关闭 |
| `regional_market_rules_version=301` | 区域库存报价、真实采购和手动贸易 |
| `regional_trade_automation=true` | 在 301 的基础上启用自动贸易 |
| 内部 R1 试验 | 仅动态价格 |

普通存档、紧凑存档均保存版本、旬初库存快照、当月额度、历史成交摘要、订单与在途货粮的关联。读档继续使用已保存的快照及真实市场余额。已完成订单保留最近 96 条，活动订单及对应在途凭证持续追踪。市镇升级和换月继续走正常入口，读档只校验载入的数据。
