# 区域经济 V3.0.1

新战役可以单独启用区域市场。城市可从本方其他城市的市场购买商品粮，支付本地金钱并派出真实运队。商业订单到货后可按目标市场现价出售。自动商业贸易有独立开关，两项实验默认关闭。
