# 到岸成本

每千粮预计到岸价为 ((G_	ext{buy}+C_	ext{extra}P_	ext{ref}/1000+G_	ext{extra})1000/Q_	ext{net})。引擎以整数运算返回到岸价的百分之一金单位。净到货为零的候选没有到岸价。

- (G_	ext{buy}) 是采购城实际支付的整数金。非整批购粮向上取整。
- (C_	ext{extra}) 是独立支给护卫及返程的预期口粮。机会成本以目标城购入参考价 (P_	ext{ref}) 折算。
- (Q_	ext{net}) 为可送达官仓的预计净粮。货粮途耗反映在这个数量中。
- (G_	ext{extra}) 接入可核算的额外金费用，本轮所用运输入口仅要求口粮。
- 预览同时列出含安全余量的实际备粮和经济比较使用的预计消耗。购买的货粮若进入粮袋，其后实际消耗从独立粮成本中扣除。

支付 80 金，额外用粮 500，参考价 10 金／千粮，净得 9,000 粮，结果为 9.44 金／千粮。这个结果是比较指标，实际付款仍为 80 金。
