# 区域市场联系

市场候选沿用现有运输网络。每条路按方向报价，往返权限和两程时间分别核对。市场筛选会排除没有活动城市、非本方市场、无可行返程、无编制人员和超出运输条件的候选。现有盟友救济使用既有外交渠道。

`regional-market-network.csv` 列出各剧本使用的有向基础连接、可用方向、方式、地形、距离与各月份的日数范围。实际采购日志列出走过的路、路线政策下的报价、载货量、护送口粮和预计抵达。有向基础表表示地图连接。当前天气、归属和境内通行由实际引擎在报价时校验。

区域市场的报价只为有需求或手动指定的目的城生成。同一目的地和运输权限组合复用已有的方向批量路径。如果出队或所有权发生变化，下次规划重新读取当前城池。
