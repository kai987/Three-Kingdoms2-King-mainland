# AI 区域经济

区域采购接在本方官仓调粮、盟友求援之后，随后仍可本地紧急购粮。策划器沿用已承诺行动、实际在途、固定粮费和月份生产的九旬预测，先看最早会发生的缺口。城池进入短期缺粮时，能够及时执行的本地采购优先。到货太晚的远程订单只在其粮食仍能覆盖未来的实际缺口时考虑。

候选来源的同旬实际余额、预计自用粮和护送资格都会被重新读取。农业输出、商业采购、军事消费、交通联系和战略储粮得分可重叠。农业产粮、可输出库存、当前市场、现金、固定驻军消耗与已报价的路线形成分数。到达及时性、真实到岸价、净到货量和天数相同的方案，才使用相应的农业或商业得分打破平局。战略储粮仍由目前的粮仓目标驱动。

本轮直接贸易主要处理本方已有需求。提前计划的战略储备、冬季军粮和防御开支继续通过现有预算和运输执行。自动商业贸易位于救济和委任行动后，并在出现实际粮食预警时暂停。
