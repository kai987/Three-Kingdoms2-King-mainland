# 追加シナリオの資料と配置

『三國志14』の[公式シナリオ紹介](https://www.gamecity.com.tw/sangokushi14/scenario.html)を参照し、198年3月「呂布討伐戦」、202年6月「河北争乱」、211年7月「潼関の戦い」、215年8月「合肥の戦い」を追加します。全29本を選択欄の「史実」23本と「仮想」6本にまとめます。DLC・通常版・追加本編といった発売区分は、選択欄の分類には使いません。

「潼関の戦い」は211年7月、「入蜀争奪戦」は212年12月の独立したシナリオです。入蜀争奪戦は以前の211年7月から改め、『資治通鑑』の建安十七年十二月、張松・楊懐・高沛の死と劉備の涪城進出後を採ります。具体的な開幕の旬日はゲーム上の区切りです。公式ページの紹介文は日付と物語の参照資料であり、本作の全都市・全武将の配置を公式データの完全な転記とはしていません。[全23史実シナリオのレビュー](scenario-history-audit-20261025.md)に全都市の所属、勢力間の接続、人物の変更と資料の限界を記録します。

## 人物と史料の扱い

202年は郭図・辛評・辛毘・王修を袁譚側、審配・陳琳・牽招らを袁尚側、焦触と袁氏配下の張南を袁熙側に置きます。同名の蜀将・張南は別人として扱います。張郃・許攸の曹操への帰属、既に没した顔良・文醜・田豊・沮授の不在も区別します。各人物の能力値と安定した `person_id` を維持し、所属や駐屯先の差分をシナリオ側に記録します。

215年の張遼・李典・楽進は合肥の守将として記録します。地図には合肥の独立した節点がないため、寿春（九江）を淮南防衛線の代理拠点として配置します。史実の駐屯地を寿春と認定したものではありません。張魯の残存勢力についても、宕渠での在野配置と都市の領有を区別します。

公孫康の没年は原典から210年と断定できません。今回の212年12月を含め、該当する年代のシナリオでは公孫康を遼東の当主とし、退場の境界を220年に設定します。これは本作の推定であり、史実の没年を220年と確定するものではありません。楊松など演義由来の人物についても、原典の実在・戦死月を確認済みと表示しません。軍閥の州単位の支配、客軍、山間部の残存勢力を一都市一所属の地図へ落とす際の限界は、上表のとおりです。

既存の[追加19都市×史実19シナリオのレビュー](city-ownership-audit-20261024.md)は、前回の361項目を保存した記録です。その件数・対象年月を書き換えず、現在の全23史実シナリオは[2026年10月25日の決定表と照合記録](scenario-history-audit-20261025.md)に分けます。これは地域配置のレビューであり、逐月の全太守名簿やSAN14公式データの完全移植ではありません。仮想6本の領土はそれぞれの物語に従い、史実の帰属へ一律に置き換えません。

## データ更新後の開始

追加シナリオとその初期配置を遊ぶには、新しい戦役を開始してください。セーブは対応するカタログとSHAを検証します。検証方法と実行結果の範囲は[ゲームの検証](testing.md)、都市の成立・改称・廃止とユーザー指定の月界は[都市の年代規則](city-history-rules.md)を参照してください。
