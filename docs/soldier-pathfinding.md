# 兵士戰的繞障與退卻

本次修正16×10兵士子戰場的路徑閉環，野戰與攻城、玩家與AI使用同一個實作。原有陣形、兵種、人數、出手次序、射線、傷害及200巡保底不重新設定。

## 已重現的受阻情況

舊移動每次只嘗試朝目標靠近的橫、縱兩格，沒有搜尋必須暫時遠離目標的路線。不是程式無限迴圈，但有可達的路卻會一直待在原格，最後依賴200巡退出。

專用測試先以目前戰役規則執行配兵、出陣及抵達，再由受控巨觀接敵位置進入真實的`attack → siege_form → siege_orders → siege_step`命令鏈。長蛇陣重現保留對方的預設AI命令，退卻等隔離用例讓對方固定待機，以免傷害干擾路徑觀察；沒有另造城牆或新增兵槽。

- 長蛇陣、攻方600兵：主將`a0`在`(1,5)`，友軍`a5`在`(3,5)`待機。只令主將前進，舊版到`(2,5)`便永遠受阻；現在會繞過友軍，友軍不被穿越或強制移動。
- 原版固定城防、守方480兵：弓隊`d5`原在`(9,2)`。令該隊後退，舊版到`(10,2)`被原城牆`(11,2)`擋住；現在會改走門口及空格，到達本方邊界後按原流程退出，保留剩餘人數。

上述座標為零起算的格子位置。受控巨觀接敵佈置不是自然歷史戰役的操作錄影；兵士部署、逐隊指令、行動、驗證與存讀使用實際服務。

## 目前的尋路規則

每次應移動一格時，按當下活著且尚未退出的兵槽重新做有界廣度搜尋。敵我兵槽都阻擋移動，不能穿過任何一方；死亡或已退出的槽不占路。攻城使用原18個城牆格，城內方反向時鏡像；野戰沒有這些城牆。所有候選格都必須在16×10邊界內。

前進及包圍仍朝敵方主將行動。目標格有人時，以可達且未被占據的上下左右接觸格為終點；不搜尋穿過目標的路。已在接觸格就不再移動：前進沿用現有接敵攻擊，包圍沿用不攻擊及其既定降伏判定。

後退尋找本方邊界的可達空格，直線可通時仍直接後退；原來那一行被牆或兵槽擋住，可以換行繞行，或使用另一個空的邊界格。到邊界後仍由原有的逐槽退場／主將退出流程處理，沒有直接刪兵或傳送出場。

每步費用相同，因此選最短合法格數。平手先試舊版朝目標靠近的方向，距離較大的座標軸優先，同距離時橫向先；再試其餘的上、左、右、下。這個搜尋及平手順序是**本作確定性的適配**，不是聲稱已還原原機的迂迴演算法。不可達時保持位置，200巡保底繼續有效，不穿牆解圍。

步、弓每巡一次移動或攻擊，騎、將兩次的既有順序不變；搜尋一次只落下一格，多步仍由原輪巡逐步執行。每步重新查占位，前一槽的移動、傷亡及退出可以在後續槽立即釋放道路，不保存會過時的路徑快取。

## 射擊、原版證據及存檔

弓隊前進仍先按原有射線判斷：正交2–4格，先遇兵槽遮擋，城牆不擋箭；有合法射擊先射擊，否則才移動。待機仍只在近接時攻擊。本次不替弓兵新增遠距離、穿兵射擊、自由選靶或另一套AI指令策略。

原陣形、固定城防、18個城牆及其來源見[原版素材清單](../game/assets/siege-original/index.json)；原攻基與傷害的獨立6502輸入輸出見[兵士數值參考](../tools/siege-original/soldier-rules-reference.json)，規則區分詳見[兵士戰說明](soldier-combat.md)。這些原版表與算式沒有因尋路修正而改動。

路徑搜尋及預覽不抽亂數，也不扣額外機動力、命令書或糧。實際接敵的既有攻基／傷害亂數照常執行；解除舊阻塞後，真正發生的接敵順序可能改變，並不承諾受阻舊路線的整場戰果雜湊不變。同一存檔、相同命令與種子則仍可精確重播。行走回執繼續保存每步起訖座標，原動畫依回執播放；沒有新增存檔欄位。

專用測試涵蓋真實命令重現、友軍與城牆繞行、先遠離目標、敵格不能進入、野戰與攻城分別處理、受阻退出格、全包圍保持、玩家與AI共用前進／包圍核心，以及繞行途中存讀後狀態、回執及亂數一致。
