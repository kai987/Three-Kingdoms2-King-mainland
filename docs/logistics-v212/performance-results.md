# 性能

| 五年矩阵中每局指标的均值 | F3 | G4a |
| --- | ---: | ---: |
| 每旬引擎 CPU 秒 | 0.599 | 0.682 |
| 每旬实际耗时秒 | 0.628 | 0.854 |
| 进程峰值内存 MiB | 481.4 | 493.3 |

两组观战使用同一台机器、相同剧本和 Rust 车马引擎。不同阶段的并发调度会影响实际耗时，CPU 时间更适合比较。同一局因为交战次数和部队任务不同也会改变真实工作量。记录见 data/performance-comparison.csv。

由同一势力的单旬快照复用已有经济预算。候选当前人员筛选、真实路线矩阵和往返路径各使用既有缓冲。出发资格和城内实际余额在提交时重查。已结束的军队不再产生新补给需求。报告含人员扫描次数、检查人次、路径查询、战后恢复评估和新占城评估。资源承诺函数的逐次调用数、现代浏览器帧耗时未单独采集。
