# 军队补给覆盖率

每支部队按实际行军日和粮袋中可用余额检查下一合法粮点前的缺口。相同部队的持续缺口以军队 ID 和新发生的序号识别，复报不产生新需求。实测剩余缺口增加时登记增加量，路线变动可以修订期限。城内接济、同城运队交割和其他真实粮袋收入，仅就首次尚未满足的需求入账。

有效粮量为已结束且有实际缺口的原始量及有效增加量。取消和观察截止仍未结束的需求单列。及时覆盖率为期限内已交割并用于有效需求的粮量，除以有效需求总量。完全及时、部分及时、迟到交付和最终未满足分别统计。报价的阻塞原因来自实际候选筛选。同一城市也可能对同一支军队重新报价。未成交需求的主因是观测到的主要障碍，单靠它无法排除其他合格路线或粮源。

另列去除「首次记录当日由本城直接结清」后的需求覆盖率，以衡量跨日和外部救济。行军饥损每万人使用原始发运时已承诺带队兵力。
