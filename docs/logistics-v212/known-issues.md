# 未达目标与观测限制

G4a 五年平均交战 233.24 次，高于上限 220。小势力存续率 19.54%，与约 30% 的目标存在差距。普通运队成功率和关闭窗口的实际交付比例下降。独立补给指标中，剔除当日城内直接领粮后的及时覆盖率为 24.59%，外部接济仍有改善空间。

节点备粮实测以沿途本方城池库存和市场成交为主。21 局中记录了 6,524 次预留、6,402 次节点交割和 1,262 次准备性采购。独立轻装调配和近途转调各记录 1 次。大量较早的 F3 空闲押运拒绝出于留员下限，不能靠重配所有后方部队来消除。

有些受阻原因发生在来源城报价期间。涉及多支部队与多个时间窗口时，单条报价不能证明某支军队没有其他合法方案。G3 的四局按相同参数重新采集节点补给和人员收据。占领预算只在 G4a 启用。
