# 后勤人员安排

策略 212 在势力开始常规支出前检查有迫切补给需求的行军队列。优先尝试集合城和相邻的实际可调粮城市，按真实可用库存与部队窗口排序。防御吃紧、运输权限不足以及已承诺参与战争的武将仍受原有限制。后方有当前需求、粮食充足并超过本城应留人数时，可暂时让一名现成的轻装人员不参加委任编兵。无轻装候选且真实补给机会仍在时，再评估合法调配。

轻装调整先确定所有受影响的现役兵去向。押运者调整至 500 人，剩余兵员按可行条件放入当地预备兵池或编给同城合格武将。预算、守军、容量、武将资格和运输往返率全部通过后才扣编兵和运输的命令书。原编兵服务统一写入，出发记录直接检查实装粮与货粮。

附近可用的轻装人员可以走合法短陆路调往有持续救济需求的中转城市。已经有在途人员调动、预计短线不成立或后方只剩紧张人手时会跳过。这个后备动作仍走普通武将移动入口。自动保留轻装人手随需求变化，运输后无需设置永久职位。
