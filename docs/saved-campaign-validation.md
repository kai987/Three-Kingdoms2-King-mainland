# 実セーブからの定向公開命令検証

既存の[自然観測](natural-checkpoints.md)だけでは連環・奇門の持続状態と天下統一に未到達でした。同じ長期方針を反復する前に、実際の保存・人物・資源・公開命令の条件を調べます。ゲーム規則、相手AI、乱数、人物、所有権を変更して到達状態を作りません。

## 起点と方針の区別

`tools/campaign-checkpoints/replay_saved.py`は新しい定向検証legを開始します。元ReplayのPython呼出位置を復元する自動resumeではありません。読み込みで`new`・内政・旬終了・乱数呼出を挿入せず、元の完全saveをそのまま検証し、新legの命令数とhashだけを0から数えます。過去の輸送receiptを新legの実績へ加算しません。

起点のraw save、元報告、canonical/raw SHA、catalog SHA、元命令index、選定理由と方針scriptを併せて残します。正しいchecksumは自然な来歴の証明にはならず、小型fixtureによる工具回帰は自然戦役の証拠へ数えません。途中の経験・所属telemetryだけを読み込めるsaveとして扱いません。元の自然方針、元の記録済み次命令、新しい定向方針は別の区間です。

## 同じ実命令列の再検証

定向playerが実際に受理された命令を、`commands.jsonl`へ記録します。選択を終えた列を同じ起点からPython/Rustの観測on/off計4legで実行し、各命令の状態hash・phase・turn・主RNGのstate/drawsを元列と照合します。最後の完全saveと命令transcriptも比較します。観測された中間saveの次命令は、既存観測器と同じfresh二backend probeで別に検査します。単に同じ列を入力しただけの比較ではありません。

```sh
python3 -B tools/campaign-checkpoints/replay_saved.py \
  --scenario 217-07 --start-save /tmp/evidence/origin.save.json \
  --journal /tmp/evidence/commands.jsonl \
  --provenance /tmp/evidence/provenance.json \
  --turns 12 --max-commands 2000 --max-seconds 300 \
  --output-dir /tmp/evidence-replayed
```

来歴JSONには空でない`origin`、`selection_policy`、`classification`を必須とします。出力先はリポジトリ外の新規／空directoryで、既存証拠を上書きしません。各legの実時間・命令数・旬差を制限し、時間切れはincomplete、境界の不一致はfailedです。途中停止でも最後の実save・命令列を残します。日界中のraw turn差と、完了した都市段階の旬数を分けます。

すでに有効な効果を持つ起点自体は、読み込みだけで新しい観測数へ加算しません。最初の命令後から通常観測するため、元起点の次命令の証明が必要な場合は、元記録の境界照合を別に記録します。実戦の勝利は`finished`＋`victory`＋全active都市（無主城を含む）の自勢力所有でのみ確認し、工具のpassedを統一勝利へ読み替えません。

## 今回の原因分析

- 217年自然戦局の実finalは221年7月、魏70/111城です。司馬懿は4518経験で連環習得済みですが兵0でした。十分な公開配兵・本物の水上対象・距離・APが必要で、初期配置に水上の敵がいるとは限りません。
- 同finalの諸葛亮は2029経験で**呉・零陵**です。魏・汶山という途中telemetryを最終起点へ転用できません。227年finalでは587経験で魏・葭萌、playerは蜀です。所属やplayerを書き換えて施計しません。
- 奇門は諸葛亮本人のtier6／10000経験が必要です。学校は知、訓練は都市訓練度を上げ、経験の近道ではありません。実戦決着の通常経験は一人あたり最大1000なので、2029からでも少なくとも8回の実決着が必要です。この下限は8回で必ず到達する予測ではありません。
- 263年の旧統一案は270年の戦闘中24/114城、歴史武将15人に低下しました。217年finalには健常な歴史武将109人、兵糧586056、予備兵183751がありますが、前線は欠員で、既存募兵優先処理が人事・輸送より先に命令書を使います。別の人事優先観測を行い、即座の統一を保証しません。

自然な既存方針の11分類と、新しい定向経路の分類を混ぜて全項目達成とは報告しません。天下統一、奇門の習得・実使用・持続状態・次命令、終局UIはそれぞれ別の受入項目です。

人事案では実命令書156冊が勧誘99回・登用57回に使われ、固定資金費用は13320でした。実新加入78人、元魏から他勢力へ7人で差引71人増です。武将不足の前線は8→6へ減りましたが、忠70未満は6→14へ増え、獲得人材の維持と既存兵力の集結が次の課題です。全冊を人事が使ったため、この順序だけでは募兵・輸送の均衡を確保できません。資金・兵糧・予備兵の所有分の差は都市喪失や収入等も含むため、全量を人事費と扱いません。

連環案の467回の`siege_withdraw`は、隣接敵の未消費APによる再接敵から離脱する戦闘回避方針の繰返しであり、連環の試行数や兵士戦完走数ではありません。記録した38個の移動／待機判断では敵の水上人数は最大1で、水上隣接対は0でした。到達しなかった項目を結果から隠したり、同じ列を再照合した回数だけ戦果を増やしたりしません。

自然な旧方針の分類和集合は依然9/11で、正の連環・奇門状態と実戦統一／終局画面は未確認です。ゲーム／相手AI／乱数の源は旧候補と同一です。
