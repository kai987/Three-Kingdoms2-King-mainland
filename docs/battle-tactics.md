# 戰場移動、接敵與機動力

戰略地圖的命令書與戰場的機動力是兩套額度。原作的戰場先在限定區域部署，攻方先行動；雙方各完成一次操作階段才經過1個戰場日。一次操作階段可連續下多個合法命令，也可以提早待機換方。這與戰略階段的1旬10日分開。

## 軍種、旗標與讀檔

戰術大地圖的平／山／水是武將的有效軍種，與接敵後按原武／等級表拆出的步、弓、騎兵槽分開。221名已閉合本機ROM身分使用原12位元組記錄的`(byte11 >> 2) & 3`，另9人採已核對轉錄；其餘822人使用有來源標籤的推定或本作配置。ROM與公開轉錄不一致時採固定本機ROM並保留異同，不把未命名編碼3當免費軍種。完整來源與各類人數見[軍種政策](troop-types.md)。

旗標是原16×16圖形及精確4倍圖集，不使用字型仿畫平山水或隊數。軍種metadata為唯讀版本規則：保留原始profile、目前座標、已存機動力、亂數及既定行軍報價，之後的戰術移動查表與旗標採有效軍種。查看、換語言、存讀不重抽軍種，也不按當前勢力或所在地臨時換兵種。

## 可確認的原版規則

Namco官方說明書[第32–33頁](https://cdn-ak.f.st-hatena.com/images/fotolife/j/jackallsasaki/20260802/20260802002854.jpg)明列：機動力由本方參戰兵數決定，在額度內可以連續使用命令；未用餘額可累加至次日，但有上限。因此同一將可以先移動再攻擊，也可在額度足夠時再下合法命令，不能以「本輪已行動一次」代替整方的額度。

普通攻擊須與敵方**上下左右相鄰**，不能斜角接敵或隔著地圖直接攻擊，每次消耗機動力2。[第36–37頁](https://cdn-ak.f.st-hatena.com/images/fotolife/j/jackallsasaki/20260802/20260802002901.jpg)的相鄰要求及費用，與ROM的`12:A368–A3D1`四方向判斷、`12:A31B/A31E`扣費一致。只有地圖目標合法後才進入兵士對陣演出；演出本身不替部隊移動或額外抽取亂數。

原版進入兵士戰鬥後，雙方接觸會自動交鋒；步／弓／騎／武將依次、攻方與被攻方交替行動，見[第38–39頁](https://cdn-ak.f.st-hatena.com/images/fotolife/j/jackallsasaki/20260802/20260802002905.jpg)及[第40–41頁](https://cdn-ak.f.st-hatena.com/images/fotolife/j/jackallsasaki/20260802/20260802002911.jpg)。本作將普通接敵接到與攻城相同的持久兵士子戰鬥，按步、弓、騎、將輪巡、雙方交替推進；野戰無城牆。整次接敵只扣發起方2機動力，守方即使餘額0仍可在這次交戰內行動，不額外取得整方戰術回合。被擊潰或體力0不行動；受擾亂則消耗一次跳過，不抽傷害亂數。選陣、下令、動畫和跳過演出不補打。精確原版攻基、兵數權重與攻防修正及本作後置訓練規則見[兵士戰說明](soldier-combat.md)。

移動以四方向逐格計費。地形和該隊的平／山／水適性影響每格費用，隊伍較大時更昂貴。森林、河流、山、砂地均可通行，不能把所有山水一律視為牆壁；已被友軍或敵軍占用的格子不能進入。原版在移動確認前可逐步取消並退還該步機動力，本作的路徑預覽與正式提交須分開。

城砦內部隊按真實格子判定：普通接敵時，其中一隊在原版地形`class5`，先消耗發起方2機動力，再進入**尚未造成傷害**的持久攻城子戰鬥。玩家確認長蛇、雁行、錐行、魚鱗之一，然後為每隊步、弓、騎及主將分別下達前進、後退、待機、包圍，按巡推進實際位置及兵損；選陣與下令本身不抽亂數。原版城內方使用固定城防陣位，四陣選擇改變城外方部署，沒有虛構城防加成。主將接觸會進入現有單挑，再回到同一攻城進度，不另扣機動力。

攻城場景直接使用獨立原核心捕捉的原版灰磚、雙城門背景與原四陣圖示，來源及受控輸入列於[`siege-original`](../game/assets/siege-original/index.json)。這次準備只在獨立測試快照安排原版城格與相鄰敵隊，由原核心自己進入場景；沒有修改ROM或玩家存檔，不能稱為自然戰役操作紀錄。

子戰場為16×10格；每軍將兵分成`ceil(兵數/100)`個兵槽，每槽100、末槽留餘數（使用者指定分隊方式），武將另佔一槽。兵種按原武力／等級閾值分配，並非固定四步四弓二騎。原11槽座標、城內固定部署、18個牆格均從固定原資料提取。步、弓每巡一次移動或攻擊，騎、將兩次，雙方按步→弓→騎→將交替處理。前進與包圍朝敵將移動，途中接觸敵兵才攻擊，不會以牆後最近的弓兵為移動目標。城牆阻移動、不阻箭矢；弓隊沿正交射線尋找2–4格的首個敵方單位，更近的部隊會遮擋。待機不移動且只在接觸時攻擊。後退到本方邊界的兵保留兵數，主將退出便返回戰術圖。

兵士傷害已按原版`C991/A84D/A871/A8F2`算式實作，並用獨立6502原指令執行核對126組攻基與2080組傷害；保留明示的本作訓練度及守護後置修正，移動平手採確定性方向優先。包圍不攻擊；本作以三隊有效四鄰包圍、敵將體力不高於30作降伏條件；這不是已確認的原版機率。200巡未分勝負退出本次交鋒，是獨立於30日戰期的有界保護。玩家、AI與AI對AI共用部署、移動、射擊及結算服務。新存檔只在攻城進行中增加可選`extended.siege`欄位，保存陣形、分組及逐隊命令、22槽以內的位置與兵數及已抽取的攻基；結束時移除，舊無此欄位的存檔不改動。

## 計略與弓的範圍

原版大地圖計略一般限制在`max(|dx|, |dy|)≤5`的範圍，還須符合各計略的地形、目標及鄰接資格。偽撃転殺、落石、連弩另要求施放者與目標上下左右相鄰；十面埋伏以自己為目標。合法目標與施放成功機率分開，路徑預覽及可選範圍不能先抽成功亂數。火計、亂水、水攻按目標所在格判斷；落石要求施放者在山或城、目標非城且正交相鄰，不能用整座城的戰略地形代替。完整16項施放者／目標條件列於證據JSON。

多目標也使用真實空間：共殺作用於所選敵軍及其四鄰敵軍，最多十字5隊；連弩只作用於所選1隊。連環、水攻、劫火從所選目標沿四鄰接觸的敵軍作廣度搜尋，城格阻斷、空格斷開，不會掃描全圖敵軍。連環與水攻最後只對連通集合中的水格單位生效，劫火對非城格生效；非水格敵軍可以作連通橋，這與沿河流水格的洪氾搜尋不同。本作保留既有單隊傷害及成功率模型，只把目標集合接到已證實的空間條件。

16種計略的機動力費用依ID順序為`6,5,4,6,7,8,8,8,10,9,9,10,10,8,12,10`。完整玩家確認鏈`12:AA8A–AA98`從整方`0505`扣費；原作這條已恢復的流程沒有本作舊版「每將氣力18、每輪恢復4」的第二筆付款。此輪接入以共享機動力作資格和扣費依據；保留舊存檔欄位不表示仍用它鎖住施計。

戰術大地圖的普通攻擊沒有獨立弓射命令。[第40–41頁](https://cdn-ak.f.st-hatena.com/images/fotolife/j/jackallsasaki/20260802/20260802002911.jpg)的弓隊遠射是在接敵後的兵士戰鬥模式內，與大地圖部隊移動不同。此處沒有足夠證據替大地圖所有持弓武將增加一般遠距攻擊，兵士模式的基準射線已確認為正交2–4格、先遇部隊遮擋、城牆不阻箭；沒有將這些條件擴成戰術大地圖的自由遠射命令。

## 誰能使用哪些計略

原玩家計略選單`physical bank9:D3EE`先檢查原人物ID的特殊組與等級碼，未達特殊門檻才按知分檔。一般人物的可用計略為連續的ID前綴：

| 當前知 | 可用ID | 最後一項 |
| --- | --- | --- |
| 0–39 | 0–1 | 陥穽 |
| 40–59 | 0–3 | 要撃 |
| 60–74 | 0–5 | 火箭 |
| 75–84 | 0–7 | 共殺 |
| 85以上 | 0–9 | 落石 |

因此普通人物使用籠絡至少須知85；有足夠機動力不表示能跳過知的門檻。每次仍須再檢查實際格子、距離、機動力及目標條件。

特殊名單以已核對的穩定人物ID綁定：程昱、荀彧、田豐、賈詡、法正、李儒、呂範、諸葛瑾、楊修、魯肅、馬良在等級碼3可用ID0–11。郭嘉、姜維、徐庶、陸遜、諸葛恪、鍾會另在等級碼4可用至13。龐統、司馬懿、周瑜再於等級碼5可用至14；諸葛亮則於等級碼6可用至15。所有組都先逐級開放，不因名氣直接獲得全部計略，也不任意擴充名單。

等級碼是原武將`byte11`高半位元組，不冒稱畫面顯示等級。原經驗門檻依序為1,000、2,000、3,500、5,000、7,500、10,000、15,000，本作既有`experience_tier()`使用同一序列。等級碼3、4、5、6分別對應原始經驗至少3,500、5,000、7,500、10,000；介面的「經」仍是原始經驗除50取整。特殊分支在達到等級門檻後直接選對應選單，不另要求知92；知92是原AI選擇器的附加條件，不能冒稱原玩家規則。玩家與AI在本作共用此處的玩家式合法名單。

## 本作接入與界線

現有30張原版戰場背景已有31×19的可見格與逐格地形，115城使用其明列的區域對應；城池位置及戰略道路不因此改變。本作把可提交的位置、可達路徑、共享機動力與合法目標交給同一服務，玩家與AI使用同樣條件。保存實際位置和兩方餘額，載入及切換畫面不能重新部署或補滿機動力。移動本身不抽亂數；既有戰鬥效果、天候與計略成功判定另按原有服務結算。

確認移動後，旗標沿遊戲規則返回的實際路徑逐格過渡；玩家與AI都回放其真實路段，埋伏效果排在抵達之後。選將後可直接使用鍵盤上下左右調整預覽、Enter確認、Escape取消，不必先將焦點移到畫布；輸入框、選單、對話框與敵方階段保留原有按鍵行為。演出只使用暫存座標，正式位置及機動力在命令成功時已結算。跳過、減少動畫、分頁轉後台、讀檔或離開戰鬥會回到正式位置，整批演出最多16秒。

目前資料集的舊戰鬥存檔若尚無戰術坐標，只在首次載入時分配陣位與初始機動力，從原本等待玩家決定的攻／守方繼續；不重跑敵軍、不改兵員、戰略命令書或亂數。已有戰術資料的存檔保留原坐標、行動方與餘額，完整驗證後載入。

原版部署與出征來向有關，恢復的`C3CB/C447`讀取攻方方向、城池陣位及合法矩形表；`DC99`只把尚未部署的坐標設為`FF`。本次不宣稱已重建30城所有來向的原版部署選單。按各戰場原城砦和合法空格自動安排起點，是本作的確定性部署適配。

本作保留大地圖的單挑快捷入口，限制為正交相鄰並按普通接敵使用機動力2；進入單挑後每招不再重扣共享機動力。原版沒有獨立的大地圖單挑命令，原單挑由接敵後兵士模式的將領相撞或「挑発」成功觸發，因此這個入口與費用明列為本作適配。

原玩家橫向移動檢查包含原始第32列，原AI檢查第31列以外不可走；本作以現有可見31列統一邊界，不重現這項不對稱。原玩家與AI的部分計略目標條件亦有差異，如落石；本作共用合法條件，不把原AI的特例或漏洞當成額外權利。

原說明書[第30–31頁](https://cdn-ak.f.st-hatena.com/images/fotolife/j/jackallsasaki/20260802/20260802002850.jpg)另規定30日未分勝負時攻方撤退、兵糧歸零則退卻。本次戰場以30日為期限，兩方都結束才推進1日；第30日結束仍未分勝負，攻方退卻。兵糧及既有補給模型仍由實際戰局結算，不由畫面演出推斷已完整還原。原兵士模式的格子移動、陣形及單位輪巡也不因此宣稱全部重製。既有計略傷害、成功率與輔助效果仍屬本作模型；單一伏兵記錄、自身減傷等保留機制不表示已完全復刻原版各方伏兵快取或奇門遁甲效果。

原表、官方掃描URL與圖片指紋、恢復源碼及CPU位置見[原版戰術證據](../game/config/references/original-battle-tactics-v1.json)。原ROM、模擬器及玩家存檔未修改，不加入發布包。

## 日本語

戦場の機動力は陣営全体で共有します。残数があれば同じ武将を続けて動かし、移動してから攻撃できます。通常攻撃は上下左右の隣接だけで2点、移動は通過した各マスの地形・適性・その部隊の兵数で払います。600兵未満と600兵以上で表が異なり、森・山・川も通行できます。味方を含む占有マスへは移動できません。

攻撃側から行動し、両陣営が終えると戦場の1日が進みます。未使用の機動力は翌日へ持ち越し、現在の兵数に応じた上限を使います。これは戦略段階の命令書と異なります。計略も同じ機動力で払い、旧版の個人18気力を別の実行条件には使いません。一般の計略範囲は縦横の差の大きい方が5マス以内で、近接指定や地形条件は別に満たす必要があります。

弓兵の遠射は接敵後の兵士戦闘モードです。戦術マップ全体の通常攻撃を弓の射程に置き換えません。31×19の可視マス、都市別背景、共通の合法判定を使い、自動配置・左右境界の統一など本作の適応を原作確認事項と分けています。単騎討ちの近接ショートカットを2点とするのも本作の適応で、対決中の各招式で機動力を二重に払いません。30日目の終了までに勝敗が決まらなければ攻撃側が退きます。保存・復元・AIとの対照は実際の位置と残数を含めて確認します。

現行データに一致する旧戦闘セーブに座標がない場合は、最初の読込時だけ配置と機動力を補い、元のプレイヤー側の手番から再開します。守備側でも操作不能にならず、敵の行動を再実行したり、兵数・戦略命令書・乱数を変えたりしません。既に戦術データがあるセーブは、その位置と残数を保持します。

通常接敵は原配置の兵士戦闘へ移り、主将と各100人隊へ指示して交互に進めます。開始側だけが機動力2点を払い、守備側の残数が0でも交戦内で行動できます。失った兵は行動に参加せず、混乱中はその巡の行動を見送ります。原攻基と兵数・目標種別の算式を使い、本作の訓練度・守護を後置補正として残します。移動は確定した経路に沿って旗が一マスずつ進み、選将後は名簿や行動欄に焦点があっても矢印キーで調整、Enterで確定できます。入力欄・メニュー・モーダルではキーを奪いません。演出のスキップやバックグラウンド移行で追加の損害、機動力、乱数は発生しません。
