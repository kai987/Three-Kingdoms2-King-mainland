# 武將歸城審計

25個最新劇本均已為1023名人物建立開局與未來登場安排，共25575筆人物×劇本計畫。每城在籍容量上限99人，並非開局每城都配置99人；戰場每方最多10人。當年月可登場者實際生成為在籍或在野；未出生、未出仕、已過卒年與劇本明列排除分開處理。

201年5月曹操的74名在籍武將現可全部容納於宛城、汝南，各城最多99人。未新增領土，也未把這14名超額者改為在野。孟達221／225／227年優先按新城任職參考配置；若遊玩中城池易主，不會因這份開局計畫強迫武將改投。

未來人物按月份檢查窗口，以在野待訪；已登場人物不重複生成、不復活，也不會依歷史日期被強制轉屬。已到當年可用資格的人物不再因缺歸城欄位被靜默丟棄。

## 證據精度

配置已完成不等於每條駐城都是確證史實。既有千人SAN14九個歷史年代快照、原典生涯窗口、同年月逐人攻略資料及本作區域／邊境分配，分別記錄。近期逐人頁採集核實15人、360條同日期資料；網站限流後停止，其餘985人明記未採集，沒有冒充完整官方匯出。其餘人物主要使用既有逐人年代記錄與有標示的連續任職推定，無可用勢力依據時採本人來源區域在野配置。

鮮于銀、齊周在194—220年的幽州在野安排屬本作配置：原典不能證明二人隨鮮于輔投曹，沒有把他人的生涯複製到其身分。249與263年的襄平、樂浪、帶方由魏接收，238年1月仍保留公孫淵。

資料頁可查看每人的歸城依據、參考年月／劇本、首次出場窗口及來源。全部配置在`game/data/campaigns/`，可用`python3 -B game/build_campaigns.py --check`離線重驗。

詳見人物頁的當前配置依據。只保留目前劇本與存檔規則，不提供歷史版本遷移。
