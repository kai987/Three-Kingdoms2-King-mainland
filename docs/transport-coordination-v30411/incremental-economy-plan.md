# 增量计划与失效范围

缓存只活在一次 AI 势力阶段。该阶段的报价和提交不推进时间，也不执行土地调整、灾害、外交或易主。跨阶段、读档、下次换旬重新构建。路线表按通行规则签名，来回程成本按两段路径、人员和保守模式复用，保留 G2 与现有季节预测缓存。

资金、可用人员、库存、在途承诺、市场、活动位与命令书随每次成功或有支出的提交重新读取。在同一轮分页内复用同一份来源及市场候选规划器。按单城库存、现役、预备兵、居民和驻军费、薪粮、真实预留及可靠到货判断九旬预测是否可用。条件到货等动态显示值每次写入新预测对象。

增量开关可独立消融。控制测试对 100 个动态库存状态比较完整预算，并用真实命令序列比较状态、乱数、调度选择和实际凭证。
