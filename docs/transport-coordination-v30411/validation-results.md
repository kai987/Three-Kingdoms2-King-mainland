# 复算与阶段准入

先用 `v30411_inputs.py` 按上一版索引还原存档。输出输入 manifest 记录来源和 SHA-256；所有重放均重复核对。上一版实际同档对照和当前集成版对照分别由 `TK2_OBSERVER_RUNTIME_ROOT` 指向对应工作树。目录内保留首次失败和各次重跑。

`v30411_replays.py` 接受 fixed、south、historical 与 performance。固定需求对照使用 U0/U1、分页 U2、多样性 U3a、重新报价 U3b、组合 U3、来源安全 U4、准备 U5p、过境 U5t、组合 U5、经济性和增量 U6 以及独立 D2 的 V0/V1/V2。U6-full 与 U6 只差增量开关。

`v30411_audit.py` 独立核对原引擎实际过账、位置、押运者、报表回执和增量等价。`v30411_report.py` 逐个检查点把原回放、集成基准和候选对齐。固定需求、资源、安全与性能逐级报告。阶段未达标时，后续观战和新保留种子在结果清单中标为未执行。
