# 居民、驻军与过境军队的同一粮账

原有 `staging_supply.active()` 按真实队伍、路线节点、归属和到达预计日期保留已承诺余额。九旬预算从期初可用粮一次扣除已保留额。行情或天气变化仍由原入口刷新承诺。原有实际领取和释放在行军节点结算。

30411 的过境消融在同一个真实官仓上进行。到达当前合法节点的军队仍能使用自己的真实承诺。没有承诺的部分只能从扣除其他仍有效的承诺及本城一期居民和驻军应耗后的余额领取。现有应急接济、已在途的军粮队与运队救援仍由各自的合法入口处理。

市场购买、实际仓库入账、军队领取、城池应付与实际付出使用独立凭证。家底不足会留在双方的实际缺口。巴西检查点按事件日序追踪仓储，消费影响以同档配对计算。
