# 固定需求调查

历史原始首次缺口和期限来自 89 个原目标及其已哈希存档。每个目标按检查点 SHA-256、势力、城市共同连接。期限旬先扣居民及驻军粮，当旬完成的入城晚于该次扣粮。原始及时到货、新购粮和首次缺口折顶覆盖分别核算。

新机会漏斗由原始需求、调度发现、来源可用账、合格人员、来回路径和预算、当旬位置与命令书、裁剪、进入分配、复核、真实发运、真实到货、消费覆盖组成。可观察字段分别来自需求事件及拒绝原因、来源现账、完整候选、交易回执和实际粮账。仅凭未到货无法区分缺粮已由其他渠道解决、发生易主、预测拒绝或真正遗漏。逐目标表保留并列证据与原路线，缺少直接证据时保留未确认状态。

已确认的程序风险包括首屏任一候选无解就结束，以及在完整返程及天气核算前截断路线。消融比较先保持旧效率排序和储备参数，分别量化分页、来源多样性与重新报价的实际覆盖变化。

逐目标归因表的字段表示观察到的下限。L0 取原始首缺口，L1 是实际需求事件，L2 至 L4 从保留的期限内报价读取来源、押运和路径，L5 只以已成功发运证明位置和命令书均可用。L6 记原来源是否仍有保留报价，L7 是提交次数，L8 是通过复核的事务，L9 为真实运队，L10 记录期限前实体收粮，L11 将实收折顶到首次缺口。市场购粮实际消费使用独立的城市结算表。空列表表示当时没有相应证据。多个阻塞可同时出现。
