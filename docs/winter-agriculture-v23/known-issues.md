# 已知限制

- V2.3 維持為獨立候選。個別劇本的糧食壓力與軍需準時率跨越警戒線，逐局差額和地區拆分見驗收報告。
- 舊版運隊重放依賴原始檢查點。原有流水和前次報告提供其他案例的歷史查證，這類證據與本輪實際重放分別記錄。
- 長期對照的每旬 CPU 時間含觀測開銷。局勢發展、交戰與運輸數量會改變每旬工作量。
- 冬季準時率的分母是冬月派出、在共同比較期內已到期的軍需運隊。分母為零時無可比準時率。普通轉運次數另列。
- 快速組未抄錄月初市場報價。逐城洪旱直接扣糧由補充配對採集，其餘組保存實際官倉災害扣糧的全局合計。
- Python 與 Rust 執行後的映射插入順序可以不同，壓縮後的存檔雜湊因此可能不同。跨後端互讀另用普通、緊湊兩種格式驗證，驗收比對領域狀態與亂數。
- 開局已錯過完整冬季的城市保留未完整觀測狀態，該年使用 100%。既有劇本摘要校驗仍負責判斷舊檔能否讀取。
