# 軍種の出典とセーブ方針

戦術地図の「平・山・水」は武将の移動適性を表す軍種です。接敵後に主将の武力・等級から配置する「歩・弓・騎」の百人隊とは別です。旗は現在兵数から求めた`ceil(兵数/100)`と有効軍種を表示し、最大1,000兵＝10隊です。名簿・HUD・詳細には武将のフルネームを残します。

## 1,052人の根拠

[版付きの全員表](../game/config/references/officer-troop-types-v1.json)は安定した`person_id`で対応します。現在の内訳は次のとおりです。

| 出典区分 | 人数 | 意味 |
| --- | ---: | --- |
| `verified_original_rom` | 221 | 手元の固定ROMで人物を照合済みの原値 |
| `original_table_transcription` | 9 | 身元照合済みの公開原作表の転記。ROMスロット照合済みとは扱わない |
| `design_trait_inference` | 7 | 経歴・専門性を参考に本作が推定 |
| `design_region_inference` | 265 | 固定の登場地域を参考に本作が推定 |
| `retained_design` | 25 | 既存の明示的な本作設定を維持 |
| `fallback_design` | 525 | 資料不足のため既存の基線を維持 |

ROM221人と転記9人以外の**822人は原作値と断定しません**。経歴や地域の史料にも、ゲームの軍種数値が記されているわけではありません。現在の有効値は平634人・山212人・水206人で、376人が保存用の基線値と異なります。地方文吏など新しいIDは生成時の本作適性を維持し、`generated_design`として表示します。

本機ROMの原人物データは12バイト、軍種は**0始まりのbyte11のbits2–3**、算式は`(byte11 >> 2) & 3`です。0＝平、1＝山、2＝水。byte8／9の兵数を軍種として読みません。原237レコードのうち人物照合済み221人を採用し、未照合16枠を推測で別人へ割り当てません。未命名コード3も無料移動能力や第四の軍種として公開しません。

転記とROMの違いは[同表の`source_disagreements`](../game/config/references/officer-troop-types-v1.json)に残します。呂範は本機ROMが水・転記が平、呂蒙は本機ROMが平・転記が水です。本作では固定した本機ROMを優先し、両方の元データをそのまま保存します。転記を誤りと断定したり、別版の値と同じだと装ったりしません。

地域による推定は人物の固定登場地域から作る静的な設定です。所属勢力、現在の駐在都市、戦場地形、年月の変化だけで軍種を変更しません。武力の高低から一律に推測せず、乱数で軍種を振り直すこともありません。

## 原図形の旗

[原素材インデックス](../game/assets/battle-markers-original/index.json)には平／山／水、隊数0–10、味方／敵、普通／指揮官の**132フレーム**を収録しています。原寸アトラスは176×192、厳密な4倍が704×768。原16×16の全体を描き、ブラウザーのフォントで似た文字を描く方式ではありません。白地の味方、赤い敵、指揮官の左上記号、10隊の組み合わせ図形も原CHRに従います。0隊の原図形は保持し、敗走表示の重ね描きとは区別します。

原手順`23:A983–AAE3`の132通りの出力を独立6502実行で確認し、保持された原コアの256×240フレームにある山／10隊／指揮官の256画素とも一致させています。これは隔離テスト状態の原コールバック画像との照合で、実機録画や自然戦役の証明とは区別します。図形の選択根拠、原調色板、固定CHR・数値表・CPU出力のハッシュは[出典](../game/assets/battle-markers-original/provenance.json)に保存します。ゲームとCIはROMやエミュレーターを必要としません。

## 有効値と保存値

[実効軍種サービス](../source/remake/troop_types.py)は原プロフィールとは別の読取専用ルール層です。表示用metadataには有効値、基線値、出典区分を含め、次の戦術移動の見積もり・合法判定・旗表示を同じ有効値に揃えます。プレイヤーとAIは同じ移動費表を使います。

既存の`profile.terrain_affinity`、人物ID、シナリオJSON・データSHA、セーブの乱数・位置・残り機動力は書き換えません。現行カタログに一致する既存セーブを再保存しても、軍種metadataをセーブ本体へ足しません。既に確定した行軍の経路・日数・兵糧見積もりも再計算しません。ただし、**ロード後の次の戦術移動見積もりは版付きの有効軍種を使う**ため、基線と有効値が異なる人物の将来の移動費は変わり得ます。過去の移動をやり直す処理ではありません。

```sh
python3 -B tools/officer-placement/build_troop_types.py --check
python3 -B tools/battle-markers-original/check.py
python3 -B -m unittest discover -s tests -p 'test_remake_troop_types.py' -v
python3 -B -m unittest discover -s tests -p 'test_remake_battle_markers.py' -v
```

## 繁體中文要點

- 平／山／水是戰術移動軍種，步／弓／騎是接敵後的百人兵槽，兩者分開。
- 1,052人中221人取本機ROM的byte11 bits2–3，9人取已核對身分的原表轉錄；其餘822人分為特性推定7、地區推定265、保留明確配置25、資料不足保留基線525，全部有來源標籤。
- 呂範（水／轉錄平）、呂蒙（平／轉錄水）按固定本機ROM採值，兩份證據保留。
- 旗標132格均為原16×16像素的精確4倍，不用字型仿畫；名單及詳情保留全名。
- 原始profile、劇本SHA及舊存檔的座標、機動力、亂數保持原樣；唯讀有效值影響之後的戰術移動報價與旗標，不重算既定行軍。
