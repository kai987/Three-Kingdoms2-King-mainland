# 原作UIの画像と操作欄

右側の都市命令を「都市／軍務／倉庫／町」の4組に分け、原作の命令アイコンを表示します。最初は軍務を開き、都市ごとに選んだ組を保持します。4タブは画面幅にかかわらず1行に配置します。矢印・Home・Endでタブを選択でき、「都市情報」と「今旬を終了」は組にかかわらず利用できます。武将一覧は名前と兵数を中心に折りたたみ、詳しい能力・忠誠・経・装備は都市情報や人物詳細で確認します。

町では医館・市場・学問所・武器屋をアイコン付きタブにし、対象・見積りと固定の確認欄を表示します。発展・防災・自動方針は都市側の画面に分けています。利用できない施設は理由を表示し、対象、金額の上限、行動消費、プレイヤー／AIの処理は既存のエンジンを使います。

装備は実際の `slot:itemID` と人物IDに結び付け、武器29種・防具8種を別々の画像で表示します。一覧と現在装備は画像と名前だけにし、ホバー、タップ、キーボード操作で強さ・重さ・実際の攻防補正を表示します。ポップオーバーは都市情報のスクロール枠に隠れない位置へ配置します。武器屋の選択候補も名前だけにし、選んだ商品の画像と購入費用、交換前後の見積りを別に表示します。購入・再装備後は最新の装備IDから画像を引き直します。表示の切り替えで基本能力や装備を書き換えません。

資金・兵糧・予備兵の名称と数値を同行に揃え、繁体字では「資金・兵糧・預備兵」に統一します。勢力選択の説明にはその劇本の君主の人物IDに対応する32×40の肖像を添え、後代の継承者も年代別に表示します。

## イベント画像

| イベント | 使用画像 |
| --- | --- |
| 武具の購入 | 原作で観察した武具店の店主・客・壁の武具 |
| 兵糧の取引、宝の売却 | 原作で観察した商人の取引場面 |
| 輸送隊の出発 | 原作の出陣挿絵を本作の輸送出発に転用 |
| 医館の治療、学問所の学習 | 確認済みの施設入口アイコンと対象の肖像 |
| その他 | 既存の地図・人物・イベント図にフォールバック |

日付・都市名・結果はHTMLのまま表示し、言語切替、確認、再生は保存済みのイベントを閲覧するだけです。再生による支払い、命令実行、乱数の消費はありません。画像が取得できない場合も、結果の文章と操作を残します。

## 素材の由来と保存

- [画面調査と元の全画面PNG](../art/original-ui-study/2026-10-24/README.md)
- [実装用素材のmanifest](../game/assets/original-ui/index.json)
- [再生成スクリプト](../art/original-ui-study/2026-10-24/export_runtime_assets.py)

本機OpenEmu／Nestopiaの「三国志2超级版」を実際に操作して得た14組の裁片を使います。`source/` に元の裁片を変更せず保存し、`pixel-base/` にウィンドウの約6倍のピクセル格子をnearest-neighborで再標本化した画像、直下に幅・高さをそれぞれ4倍にした表示用PNGを置きます。調色やAIによる描き直しは行っていません。

これは **`original-capture-derived`（観察した画面からの派生素材）** です。元のPPU画像を直接書き出したものではなく、ウィンドウの倍率やフィルターの影響も残るため、`native_dimensions_confirmed` は `false` としています。manifestには全画面の出典とSHA-256、裁片の座標・SHA-256、処理方法、各PNGの寸法・SHA-256を保存します。医館の診療内景、独立した学堂内景、ランダム災害など未取得の場面は、取得済みの原作画像として扱いません。

```sh
python3 art/original-ui-study/2026-10-24/export_runtime_assets.py --check
python3 -B -m unittest discover -s tests -p 'test_remake_original_ui_assets.py' -v
node tests/test_remake_original_ui.cjs
```

## 逐件装備アイコン

原作で確認できた共通分類アイコンも引き続き保存しています。37点の個別装備図は built-in imagegen で別々に制作した **重制素材** で、原作の個別商品画像を直接書き出したものではありません。生成原図とプロンプトは [制作記録](../art/equipment-icons-v1/)、配信用128×128 PNGとSHA-256は [装備manifest](../game/assets/equipment-icons/index.json) に保存します。画面上は従来の28〜40px枠で表示し、アイコンだけを拡大してレイアウトを圧迫しません。

```sh
python3 tools/equipment-icons/build_manifest.py --check
python3 -B -m unittest discover -s tests -p test_remake_equipment_icons.py
```

HTTPと静的配信は14組の既知PNG、37点の装備アイコンとmanifest、関連JS/CSSだけを許可します。ROM、エミュレーターの状態ファイル、全画面の調査資料をゲームサイトへ公開しません。コードと素材の権利の区別は[README](../README.md)に従います。
