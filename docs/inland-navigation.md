# 内河航路と流れの向き

江夏―長沙には、陸路と内河航路を別の経路として設定します。内河航路は海路とは分け、海の季風や暴風雨による損耗を適用しません。プレイヤーとAI、出陣・移動・輸送は同じ方向別の所要日数を使います。

## 地図で表す交通

本作の江夏拠点は夏口周辺、長沙拠点は郡治の臨湘周辺を表します。水路は夏口から長江をさかのぼり、巴丘・洞庭の出口側を経て湘水を臨湘までさかのぼる経路です。『水経注』巻35は湘水が南から長江へ入り、その下流側に陸口・赤壁・夏口の地域が並ぶことを記し、巻38は湘水が臨湘の西を北流し、巴丘付近で長江へ入る流れを記しています。[『水経注』巻35](https://zh.wikisource.org/zh-hant/水經注/35)、[同巻38](https://zh.wikisource.org/wiki/水經注/38)。

このため、江夏から長沙へ向かうと長江・湘水の両区間が上り、長沙から江夏へ向かうと両区間が下りです。地図上で南へ進むことを、そのまま下りと判定しません。

計算上は「長江」と「湘水・洞庭出口の水系」の2区間に概化しています。後者には湖との接続部分を含めますが、独立した湖面の自由航行や専用の湖面速度は設定していません。古代の河道や湖岸を現代のものと完全に同一とみなす復元でもありません。

陸路は長江南岸と洞庭東側を通る地域交通のゲーム上の表現です。『三國志』呂蒙伝には、孫権が陸口にとどまり、呂蒙が長沙などを攻略し、魯粛が益陽で対応した軍事行動が記録されています。ただし、この記述だけで夏口から臨湘まで続く一本の官道の位置が確定するわけではありません。本作の線形は既存の都市・山・河川に合わせた概略配置です。[『三國志』巻54](https://zh.wikisource.org/zh-hant/三國志/卷54)。

## 速度の根拠とゲームへの換算

三国時代のこの航路で、軍船が常に同じ速度で進んだことを示す実測資料は確認できていません。そこで、後代の官制史料『唐六典』巻3の載貨船の行程を、方向差を設けるための参考にします。同書の上りは長江が1日40里、その他の河川が45里、下りは長江が100里、その他の河川が70里です。[『唐六典』巻3・度支郎中条](https://www.shidianguji.com/zh/book/SK1116/chapter/1jzwtzmscgcnv)。

| 本作の計算区間 | 上り・逆流 | 下り・順流 |
| --- | ---: | ---: |
| 長江 | 20 km／日 | 50 km／日 |
| 湘水・洞庭出口の水系 | 22.5 km／日 | 35 km／日 |

この表は、参考の里数に本作の便宜的な **1里＝0.5 km** を掛けた作者設定です。唐代の里の厳密な度量衡換算でも、三国時代の軍速の実測値でもありません。「その他の河川」の定額を湘水側へ当てはめることも、本作の概化です。船型、乗員、曳航、渇水、洪水などの個別条件まで再現するものではありません。

## 日数と補給

水路全体を単一の速度で割らず、各区間の距離と進行方向から計算します。`ceil` は端数切り上げです。

```text
江夏 → 長沙の水上日数 = ceil(長江の距離km / 20 + 湘水側の距離km / 22.5)
長沙 → 江夏の水上日数 = ceil(長江の距離km / 50 + 湘水側の距離km / 35)
都市間の合計日数 = ceil(接続陸路の距離km / 30) + 水上日数 + 乗船準備日数
```

乗船準備はこの都市間の航路で1日、接続陸路は都市の中心から乗降地点までです。接続陸路と準備日数を水域ごとに重ねて徴収しません。地図の拡大率を変えても日数は変わりません。

内河の所要日数は通常の兵糧計算にも使います。海の季風による加減速、海上暴風雨の80〜90％損耗、海路探索の判定は行いません。内河に固有の通航損失はありませんが、**兵糧不足時の減員・待機・撤退は通常どおり適用**します。経由する自勢力都市での実在庫による補給、輸送武将の実際の帰還日数も共通ルールに従います。[行軍と兵糧の規則](hazardous-travel.md)。

## 史料と設定の区別

水系の接続と大まかな流向は古地理史料、方向別の速度差は後代の公式行程、kmへの換算・2区間への概化・地図上の線形は本作の設定です。岳陽市档案局が記す城陵磯と武漢・長沙との位置関係は地域の尺度を確かめる補助資料であり、三国時代の正確な水程として転記していません。[岳陽市档案局「城陵磯港沿革」](https://daj.yueyang.gov.cn/6658/6667/content_370345.html)。
