# 原版互動音效

遊戲優先播放使用者提供之《三國志2超級版》ROM的原音效。13 個獨立 WAV 對應 21 個互動名稱；四首原版背景音樂沿用既有錄音。執行遊戲不需要 ROM、模擬器或研究目錄。

| 互動 | 原音序 ID | 對應依據 |
| --- | --- | --- |
| 確認 | `62` | 原版城市面板確認呼叫 |
| 選擇、取消 | `60` | 復用原版單挑移動短音，未宣稱原版有專屬取消音 |
| 行軍 | `5A` | 復用原版普通移動音 |
| 普通攻擊、命中 | `5E`、`5D` | 原版攻擊呼叫 |
| 計略準備 | `65` | 原版計略準備呼叫 |
| 計略效果 | `88`、`8D`、`91`、`95` | 16 種計略經原版視覺索引表對應四組音序 |
| 單挑接受、拒絕及退出 | `62`、`60` | 本作操作復用原版短音 |
| 單挑攻擊、防守、佯攻 | `61`、`68`、`69` | 本作動作復用原版單挑動作音 |
| 錯誤、短勝敗提示 | `61`、`62` | 本作操作復用原版短音 |

原版 `6C`、`71` 長音樂未完成本輪單次音效整理，短勝敗提示沒有冒稱是這兩段錄音。換旬是本作新增流程，使用本作合成提示；載入、解碼失敗或首次載入超時也有合成後備。後備與原版不會因延遲完成而重複播放。

## 來源與隔離錄製

`tools/audio/capture_effects.py` 使用未修改的 Nestopia 核心、原 ROM 與外部提供的場景狀態。受控入口設定 CPU 暫存器及 RAM 呼叫器，先執行原版重設服務及 180 次 NMI 清除先前音訊，再呼叫原版音效描述器，交由原版 NMI 更新聲部。所有請求聲部完成後保留尾音，輸出 48 kHz、16 位元雙聲道 WAV，邊緣作 4 毫秒淡化。

這是受控驅動錄製，不是自然按鍵遊玩的證明；沒有修改 ROM 波形、音序或模擬器程式。每段錄製兩次，完整 PCM 與逐幀軌跡相同，並檢查呼叫前靜音及僅有請求聲部啟用。`game/assets/audio/effects.json` 保留輸入、工具、輸出與兩次錄製雜湊、原版呼叫點及用途映射。原音樂與音效的權利仍屬原權利人，見[授權紀錄](licenses/README.md)。

## 遊戲觸發

按鈕的通用音效會讓位給指令結果：攻擊、計略失敗、單挑接受／拒絕、戰果各只產生一次對應提示。計略失敗讀取本次新增戰報，亦支援戰報達 80 行後的滾動視窗。進入 AI 階段播放確認音，實際跨旬才播放換旬音。背景分頁、靜音及音量為零時取消待播音效；音訊診斷不寫入遊戲狀態，也不消耗遊戲亂數。
