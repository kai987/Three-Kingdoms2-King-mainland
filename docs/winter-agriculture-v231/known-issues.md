# 已知问题与结论边界

- 独立天气货损列只收独立事件。雪况增加的路线扣粮和一般路线扣粮走同一笔日结算，补采报表按实际扣账分开。
- 公开天气模型使用旬分箱和短期可见状态的混合估算。固定样本同时应看平均误差、低估率和保守覆盖率。冰封事件少时，区间估计仍弱。
- 上一轮历史仓库流水缺少每笔运输入城的渠道标签。长期地区账使用真实合计，渠道拆分以明确采集的固定复放为准。
- 一些旧基准只有运队比率，无法恢复军粮数量分母。这些数据只参与有证据的比较。
- 同种子策略变化能改变战争、易主、人口、市场及后续随机轨迹。长期差额用于整局政策比较，固定检查点用于解释单一短期原因。
- 历史 126、1685、1706、1723、1902、2095 采用早期原始证据。没有真实存档的样本不重建。
- 实验采用 G1/D0 背景，正式默认配置继续沿用现行规则。
