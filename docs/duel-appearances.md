# 單挑兵器與坐騎外觀

本設定只決定單挑演出的圖片、字幕與無障礙說明。武力、命中、傷害、先後手、馬匹速度、亂數及存檔均不讀取這些欄位。以 `game/config/duel-appearances.json` 為唯一對照表，綁定 `catalog.library` 的 `person_id`；不用姓名子字串判斷，不給地方文吏借用歷史人物的外觀。

## 原典與美術選擇

使用《三國演義》一百二十回本，按回目記錄維基文庫原文來源。這是小說角色形象，不稱為漢末實物兵器考證；部分小說兵器在真實漢代的年代問題不在此次外觀復原範圍。

25位武將有原典明寫的兵器種類，並不等於25套彼此完全不同的整身造型。刀、槍、矛、戟等使用對應素材類別；原文只寫大刀時，字幕只寫大刀，不擅自命名為青龍刀。青龍偃月刀、蛇矛、方天畫戟、雙股劍、雙鐵戟使用各自的辨識輪廓。未配置人物以固定人物ID作通用外觀選擇，不抽取遊戲亂數。

名馬採用**全劇本固定的小說代表形象**，不是馬匹取得、轉贈、失去的裝備系統。呂布和關羽各用赤兔，劉備用的盧，目的是符合使用者要求的人物辨識；不表示184年關羽已得到赤兔，也不會改變史實戰役中的裝備或速度。若將來實作馬匹所有權，應另設日期與事件，而不能把本表當作當年所有權資料。

- 赤兔：第三回明寫全身赤色；第二十五回明寫曹操將呂布舊騎赤兔贈關羽。
- 的盧：第三十四回明寫劉備乘的盧；第六十三回明寫劉備把自己的白馬換給龐統，但該段沒有再次叫出的盧之名。因此「白色的盧」明確標為跨回合讀後的美術選擇，不能稱這段直接證明馬名。
- 龐德：第七十四回直接描寫鋼刀和白馬。
- 趙雲白馬、馬超白馬、張飛黑馬及其他一般馬色：此次查閱章節沒有核實其個人馬色，均標成遊戲配色，不冒稱名馬。不採用未核實的「夜照玉獅子」「玉追」等後世名稱。
- 張遼：第五十三回可核實持刀；本次不將未核實的「鉤鐮刀」寫成原典定論。
- 雙斧：提供通用兵器素材，不把它錯配成典韋的雙鐵戟，也不憑其他遊戲設定指派給某位名將。

## 原文來源

以下只作短摘意與來源索引，沒有複製整章原文。JSON的 `weapon_evidence`、`horse_evidence` 分開記錄，方便後續逐項補證。

- [三國演義第007回](https://zh.wikisource.org/wiki/三國演義/第007回)：趙雲救公孫瓚時以槍與文醜交戰；文醜同樣使用槍。
- [三國演義第014回](https://zh.wikisource.org/wiki/三國演義/第014回)：許褚與徐晃交鋒使用刀、斧；曹操曾持寶劍督戰。

## 欄位與驗證

`profiles` 的鍵為正式 `person_id`；`runtime_id` 只供核對，不可替代人物ID。`weapon`、`horse` 是已允許的素材鍵；`weapon_label`、`horse_label` 同時提供繁體中文和日文。`sources` 的每一項有原典名、回目、網址及短摘意。`kind: novel_explicit` 代表原典明寫種類／名稱；`novel_explicit_name_inferred_coat` 代表明寫馬名但配色是合讀推定；`authorial_palette`／`authorial_generic` 是遊戲配色／通用造型。

原始像素素材必須保留。新畫面只讀取本表，不會把外觀寫回戰役，也不會新增歷史武將ID。
