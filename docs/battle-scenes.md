# 原版風格戰鬥畫面

戰術地圖、普通攻擊兵陣、計略與單挑畫面使用1024×960畫布，寬高各為原256×240的4倍；版面座標、比例與頁面佔用尺寸保持一致。文字、128×160肖像和新繪騎將直接畫進高解析畫布，沒有先壓回256×240再放大。原版背景及兵卒另產生Scale4x版本，保持有限調色盤與像素邊緣，小螢幕仍按可用空間縮小。繁體中文與日文切換會更新選將、招式及裝束文字。

## 操作與結算

進入戰鬥後，點選本方旗標與對手旗標，或展開「部隊名單」使用按鈕選將。方塊旗標只顯示姓名首個完整Unicode字元，HUD、名單和無障礙說明保留全名。點選位置依顯示尺寸換算到原版座標，不受畫布解析度影響。已行動、潰散或零兵的部隊不能再次操作。旗標位置只用於呈現；本作目前仍是原有的選將對戰規則，未增加格子移動、射程或地形傷害公式。

普通攻擊呈現交戰兵陣與實際損失，再依伺服器已結算的順序播放敵方回應。16種計略的成功、失敗、跳過行動與埋伏觸發分別呈現；範圍計略列出實際受損部隊。單挑保留原版黑底、姓名及分節體力條，雙方分別使用人物ID對應的兵器、馬色及兩個新繪姿勢，顯示本方招式、實際對手招式與體力變化，結束後回到戰場。

「略過演出」與Esc會立即顯示已結算的最終狀態；切到背景分頁同樣停止演出。降低動態效果設定不播放位移動畫，仍保留操作音效與結果。遊戲忙碌期間不接受第二次戰鬥指令，事件彈窗待演出結束後排隊顯示。

## 原版素材與範圍

`game/assets/battle-original/index.json` 記錄原ROM、原Nestopia核心、調色盤、來源畫面、裁切與透明化操作及出貨檔案雜湊。實際遊戲只載入明列的PNG與JSON，不讀取ROM、模擬器或研究存態。

- 戰術地形取自原戰術畫面，移除一個固定姓名旗標；這是共用參考戰場，不是每座城池已逐一還原的專屬戰場。
- 普通攻擊使用原版草地及灰／紅兩方兵卒的4倍像素版本。單挑新增9種兵器輪廓，各有準備與交鋒姿勢，配棗紅、白、黑、赤兔及的盧外觀；坐騎配色不改變速度或傷害。騎將仍是對應兵器類別的場景角色，不是25張名將專屬人物肖像。
- 25位名將按《三國演義》原文章節配置兵器；名馬採跨劇本代表形象。沒有核實的馬色標為遊戲配色，不使用後世未核實馬名。來源、人物對照及推定範圍見[單挑裝束](duel-appearances.md)。未配置人物及地方文吏依固定ID選擇通用裝束，不使用遊戲亂數。
- 火焰、箭矢、水流、落石、陷阱、護盾等尚未可靠提取的效果，以本作的少色像素幾何補充；不標作原版精靈。計略名稱及結算沿用現有重製版規則。
- 原始畫面witness保留作比例與像素比對，不把其中固定姓名或兵數當作目前戰役資料。

原素材離線檢查見[原版素材工具](../tools/battle-original/README.md)。新增素材以內置imagegen根據原騎將參考製作透明雙姿勢圖片，再做少色量化、馬色分層、完整邊界裁切及打包；提示詞、來源圖、輸出及雜湊均保留，見[四倍素材工具](../tools/battle-enhancement/README.md)。原圖未覆寫，圖像權利沿用各自素材條款，並未以程式碼MIT授權重新授權。

## 無副作用的播放資料

戰鬥命令回應可附帶暫態 `presentation`，結構為 `tk2-battle-presentation-v1`。每個場景帶本次動作前後的部隊快照、人物ID、行動方、計略效果、成功與跳過狀態，以及單挑雙方實際招式。敵方自動回應與十面埋伏各有獨立場景；前端不解析戰報來猜測損失或招式。

資料僅隨本次成功命令傳回，不寫入戰役狀態、存檔或劇本，也不抽取亂數。讀檔與重新整理只顯示當前狀態，不重播舊命令；同一回合版本不重播。前端只讀資料、驗證格式並繪圖，所有兵力、體力、氣力、行動次數及戰果仍由原有伺服器規則結算。

素材載入失敗時保留可操作的部隊名單並顯示提示；略過、取消、切頁、重設及讀檔都清理動畫回呼。無Canvas環境仍能操作原有名單，不會因此阻塞戰局。
