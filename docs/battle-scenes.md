# 原版風格戰鬥畫面

戰術地圖使用原版30張完整背景，每張496×304（31×19格、每格16×16），下方另加80像素的本作雙方情報欄。合計496×384邏輯尺寸直接畫入1984×1536畫布，寬高各4倍；普通攻擊、計略與單挑切鏡則維持256×240邏輯尺寸、1024×960畫布。畫面依可用空間等比例顯示，保留像素邊緣。文字、128×160肖像、新繪士兵與騎將直接畫進高解析畫布，沒有先壓回低解析畫面再放大。對陣優先使用原版風格補繪的步卒、弓手、騎兵八動作圖集；原版背景、Scale4x單兵及精確4倍完整兵陣全部保留作備用。繁體中文與日文切換會更新選將、招式、裝束及戰場來源文字。

## 操作與結算

移動也有獨立過渡場景：旗標沿伺服器回執的實際路徑逐格前進，包含同將多次移動與AI的連續行軍；回放不修改正式位置或機動力。整批演出最多16秒，可略過，減少動畫或切到後台時直接顯示已結算的最終位置。選將後上下左右與Enter也可從名單／操作欄的鍵盤焦點使用，所有對話框及輸入欄不搶鍵。

寬螢幕將可捲動的「部隊名單」放在戰場左側，戰場在右側，既有行動按鈕仍在最右操作欄；單挑的交鋒紀錄也移到畫面左側。手機與窄畫面改為戰場在上、可折疊名單在下。選將後保留名單捲動位置及鍵盤焦點，名單標明已行動、防備、受擾亂、潰散等狀態。

進入戰鬥後，點選本方旗標與對手旗標，或使用名單按鈕選將。方塊旗標通常顯示姓名首個完整Unicode字元；攻守雙方各自獨立判斷同姓，同一方參戰名單內至少兩位同姓人物時，只有該方該姓旗標改顯示姓名最後一字，例如同方劉備／劉表顯示「備／表」，對方單獨一位劉姓人物仍顯示「劉」。雙方各一位同姓人物不觸發；潰散或零兵但仍顯示旗標的同袍也列入判定。複姓整體比對，例如同方諸葛亮／諸葛瑾顯示「亮／瑾」，司馬與單姓司不混為同姓；判定用原始姓名，顯示字依繁中／日文姓名更新。單字姓名仍保留該字，HUD、名單和無障礙說明保留全名。點選位置依顯示尺寸換算到地圖座標，不受畫布解析度影響。潰散、零兵或不符合當前操作階段的部隊不能操作；同將先前執行過命令並不單獨封鎖後續行動。戰場31×19格的實際位置由遊戲規則保存，普通攻擊只允許上下左右接敵；同將可在整方機動力足夠時移動後再攻擊。移動逐格按地形、適性及該隊兵數計費；山與水不是一律不可走的障礙。計略改用實際格子與範圍，既有傷害與成功率模型分開保留。[戰術移動、機動力與原版依據](battle-tactics.md)說明表格、AI共用規則及自動部署的適配界線。

普通交鋒依次呈現進攻及存活守方的即時回擊，每個傷害場景原速以2.2秒呈現兩軍接近、交鋒、退回與戰果，各按原版半屏比例顯示完整兵陣與實際損失，再依伺服器已結算的順序播放敵方回應；首次素材尚在載入時先等待素材，避免演出在空白或替代標記期間播完。16種計略的成功、失敗、跳過行動與埋伏觸發分別呈現；範圍計略列出實際受損部隊。單挑保留原版黑底、姓名及分節體力條，雙方分別使用人物ID對應的兵器和坐騎。新圖集含待機、攻擊、防守、佯攻、退卻、捨命一擊、受擊及落敗八個姿勢，依雙方實際招式和已結算體力變化分別選圖；弓使用拉弓／放箭演出。結束後回到戰場。新招式的規則與移植範圍見[單挑招式](duel-actions.md)。

士兵各有待機、行進、備戰、攻擊、防守、受擊、退回與倒下八個動作。步卒與弓手每格64×64，騎兵每格96×96，分別直接裁片畫入16×16與24×24邏輯座標；右方鏡像後朝左。每方在原128×160半屏內沿原兵陣斜列放置4名步卒、4名弓手、2名騎兵，步卒在左上、弓手居中、騎兵在後列，灰／紅兩側制服保持一致。原畫面兵種面板的步400、弓400、騎200與此陣列對應；實際本作兵數仍顯示伺服器結算值，這個外觀陣列不會拆分或增加兵數。本作現有戰鬥及存檔沒有步、騎、弓兵種欄位，沒有依人物ID或適性推定兵種與人數比例。各組前進依最右原位置與圖格寬度保留中央間距，弓手最多前進28、後列騎兵最多24邏輯像素；退回與向外撤退保持完整位移。

動作依本次回執選擇：接近為行進，交鋒前備戰、行動方攻擊；防守方有既存`guard`時格擋，實際兵數或體力下降時受擊，歸零時倒下，退回後待機。弩兵計略的施放方由弓手展示射擊，另外兩組備戰；其他計略共用對應的備戰、防守及受擊姿勢。跳過行動、取消、失敗與敵方回應都使用原有回執，不增加傷害計算或亂數。

「略過演出」與Esc會立即顯示已結算的最終狀態；切到背景分頁同樣停止演出。降低動態效果設定不播放位移動畫，仍保留操作音效與結果。遊戲忙碌期間不接受第二次戰鬥指令，事件彈窗待演出結束後排隊顯示。

## 原版素材與範圍

`game/assets/battle-original/index.json` 記錄原ROM、原Nestopia核心、調色盤、來源畫面、裁切與透明化操作及出貨檔案雜湊。實際遊戲只載入明列的PNG與JSON，不讀取ROM、模擬器或研究存態。

- 戰術背景由指定原ROM的地圖、CHR與調色資料離線重建，30張496×304布局各不相同。`game/assets/battlefields/index.json` 記錄原版城市編號、地形、據點與素材雜湊；三個原版畫面樣本另作像素驗證。PNG只含背景層，畫面上的小城堡是本作依原據點座標加上的UI標記，尚未還原原版建物圖層。舊共用參考戰場保留作載入失敗時的備用。
- 普通攻擊保留原版草地與完整灰／紅兩方兵陣，各兩個原畫面姿勢，128×160半屏素材精確放大為512×640作備用。新增三類士兵八動作圖以原版風格參考補繪，來源、動作及灰紅制服配色在`manifest.soldiers`記錄；這些補繪動作的來源與原模擬器截圖分開保存。接近、交鋒、退回的Web播放時間是本作呈現。舊`cavalry`單兵鍵仍僅為紅方原兵卒的相容別名，新增騎兵外觀使用獨立的士兵圖集。單挑擴充為12類兵器、13類坐騎外觀；坐騎配色不改變速度或傷害。騎將是對應兵器類別的場景角色，不是逐人專屬肖像。原9類兵器／5種馬色的90張兩姿勢圖全部保留作備用。
- 27名人物依正式人物ID配置代表外觀；原典明寫、使用者指定的後世通俗形象及本作配色分別標記。名馬採跨劇本代表形象，不作當年裝備所有權推定。來源、人物對照及推定範圍見[單挑裝束](duel-appearances.md)。未配置人物及地方文吏依固定ID選擇通用裝束，不使用遊戲亂數。
- 火焰、箭矢、水流、落石、陷阱、護盾等尚未可靠提取的效果，以本作的少色像素幾何補充；不標作原版精靈。計略名稱及結算沿用現有重製版規則。
- 原始畫面witness保留作比例與像素比對，不把其中固定姓名或兵數當作目前戰役資料。

完整地圖的重建、像素檢查及未確認範圍見[原版戰場工具](../tools/battlefields/README.md)，既有切鏡素材檢查見[原版素材工具](../tools/battle-original/README.md)。新增素材以內置imagegen根據原騎將參考製作透明兩姿勢與八動作圖片，再做少色量化、馬色分層、完整邊界裁切及打包；提示詞、來源圖、輸出及雜湊均保留，見[四倍素材工具](../tools/battle-enhancement/README.md)。原圖未覆寫，圖像權利沿用各自素材條款，並未以程式碼MIT授權重新授權。

### 115城的對應範圍

`game/config/battlefield-city-bindings.json` 為115個穩定城市ID逐一指定原版戰場：14城為攻略表同標籤關聯（`same_label_association`），101城為本作按地區選用（`regional_reuse`）。畫面顯示雙語來源標籤與說明；不能將它們稱為115張原版專屬地圖。攻略的「西安阳」「予州」「永晶」等原始表記保留為證據，未逐一核實全部ROM城名字形；同標籤也不等於已證實原版城市與現在節點完全同一。

`game/battlefields.js` 只讀取並驗證地圖索引及對應表，依戰鬥目標城選圖，不依武將、地方文吏或遊戲亂數選擇。後端`battle_grid`讀取同一組31×19地形資料及城市對應，保存部隊坐標與機動力。僅按需載入目前的PNG，不預載30張；圖片缺失時仍保留權威坐標與同尺寸網格，繼續按實際地形判定移動。戰略地圖、行軍規則與單隊傷害公式沿用既定設定。

## 無副作用的播放資料

戰鬥命令回應可附帶暫態 `presentation`，結構為 `tk2-battle-presentation-v1`。每個場景帶本次動作前後的部隊快照、人物ID、行動方、計略效果、成功與跳過狀態，以及單挑雙方實際招式。敵方自動回應與十面埋伏各有獨立場景；前端不解析戰報來猜測損失或招式。

資料僅隨本次成功命令傳回，不寫入戰役狀態、存檔或劇本，也不抽取亂數。讀檔與重新整理只顯示當前狀態，不重播舊命令；同一回合版本不重播。前端只讀資料、驗證格式並繪圖，所有位置、兵力、體力、整方機動力及戰果仍由遊戲規則服務結算，前端不自行放行非法移動或接敵。

新單挑素材為156張四倍圖集／1248個動作格，每格512×384，以128×96邏輯比例顯示。只載入目前兩人的圖集，沒有預載全套組合。可用兵器／坐騎變體只限人物對照表，未配置武將與文吏使用通用兵器和普通馬色。外觀選擇只保留在畫面控制器：切換語言保留，重設或讀檔清除，不增加存檔欄位。

三類士兵、兩方制服共6張動作圖集／48格，只有播放部隊對陣或計略時才載入；戰術旗標與單挑不預載它們。載入時驗證獨立schema、寬高各4倍、八個動作順序、路徑與每格裁切矩形，並核對PNG實際尺寸。單獨損壞的士兵資料不會停用既有背景與單挑素材。素材缺失依序使用原版風格補繪圖、既有4倍完整兵陣、原尺寸完整兵陣、原單兵；任一方的三類圖集不齊時，該方整體使用備用兵陣。降低動態效果或切頁後直接顯示已結算狀態，不為額外圖片等待動畫。

素材載入失敗時先回退到既有兩姿勢或原始騎將，字幕明示備用圖，避免把通用騎將宣稱為已顯示指定兵器／名馬。保留可操作的部隊名單；略過、取消、切頁、重設及讀檔都清理動畫回呼。無Canvas環境仍能操作原有名單，不會因此阻塞戰局。
