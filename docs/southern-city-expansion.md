# 吴蜀九城与月度开放规则

v10在原106个城池定义上增加9个地点。原城标坐标、1352×1024底图、地形与原版32×32城标轮廓不变；只增加城标、文字和17条陆路连接。武将人数、身份、年代与属性规则保留，每城30人、每方出战10人。

## 城池、日期及性质

| 地点 | 本作开放 | 性质与日期边界 |
|---|---|---|
| 葭萌／汉寿 | 最早184年剧本即开放 | 汉代旧县、蜀军镇；215年起显示汉寿，是定蜀后名称的玩法分界，不声称史料载明215年正月改名 |
| 涪县 | 最早184年剧本即开放 | 汉代旧县、蜀东北军镇，今绵阳方向；不是涪陵 |
| 宕渠 | 最早184年剧本即开放 | 汉代巴郡旧县，土溪城坝方向；同名郡的反复设废不删除县城 |
| 南广 | 最早184年剧本即开放 | 汉代犍为旧县；同名郡仅知延熙年间设置，不假定238/262是确切设废年 |
| 武昌 | 221年4月 | 原典四月改鄂为武昌并置郡；八月筑城另记，不重复建城 |
| 临海 | 257年2月 | 原典明确分会稽东部置郡，治章安 |
| 临川 | 257年2月 | 原典明确分豫章东部置郡，治临汝 |
| 建安 | 260年10月 | 原典记260年置郡，未载确月；10月是本作保守开放约定，不能当成实月 |
| 吴兴 | 266年12月 | 原典冬十月段附记、十二月迁都前置郡，未单列确月；12月是本作保守开放约定 |

依据为[《后汉书·郡国五》](https://zh.wikisource.org/wiki/後漢書/卷113)、[《华阳国志·汉中志》](https://zh.wikisource.org/wiki/華陽國志/卷二)、[《三国志·吴主传》](https://zh.wikisource.org/wiki/三國志/卷47)和[三嗣主传](https://zh.wikisource.org/wiki/三國志/卷48)。月份沿用史书月号映射到游戏月回合，不作现代公历日转换。逐条证据、地理估位和暂不采用的东广汉郡见[史料复核](shu-wu-history-research.md)。

原本“统一郡名”在此区分节点层级：吴五城为郡级节点；蜀四城明确标注县城或军镇，使用实际城名，不把它们都冒充成当时的郡。南广、宕渠后期升郡不另复制地点。汉寿不因历史上的晋代改名而强制触发本作尚未实现的受禅事件。

## 13个开局的势力

四座蜀地旧县：184年中立；190、191年刘焉；194、200、207、208年刘璋；217、219、221、227、238、249年刘备／蜀。184年的中立表示未设独立驻军，不表示历史无官府，也不把蓟城刘焉的游戏集团提前扩到全益州。

武昌在221、227、238、249四个开局归吴；221、227年的孙权本营改到武昌，238、249仍在建业。更早开局不预置武昌郡节点。其余四个吴郡均晚于现有最晚249年开局，只会在长期战役到达日期时出现。

开局疆界是既有宏观地图的年代改编，并非全员逐城SAN14原始导出。新城加入后，重新运行已确定的驻城规则：君主本营与审定驻城优先，其余同势力在职人物均分到接壤其他势力的城池；无前线或满员时均分到其他己城。新城并不凭空生成郡守、武将或部队。

月结按具体年月开放。武昌继承江夏、临海及建安继承会稽、临川继承豫章、吴兴继承吴郡**当时实际控制者**。例如会稽已经被魏占领，临海不会被强制改给吴。新城分出父城四分之一金钱、粮食和预备兵；不复制武将，不抽随机数，重复月结不重复开城。正常当月收入另按目录计入。

未开放城市不能显示、被选为调动或出征目标、参与AI邻城选择或成为中间路线。开城后，涉及该城的道路才可见、可走。原有建业—吴通路保留；吴兴新增两段复用该道路走廊，不在266年前把通路截断。

## 地图和经济

旧106城坐标与地形不动。仅移动原阆中、蕲春标签以给新增城标让位；新城标签另有偏移，避免压住其他城标。

新武昌取今鄂州方向。旧江夏旅行坐标曾几乎与鄂州重合，v10将其改为夏口地区军事代理 `[114.30,30.55]`，城标不动；并非声称江夏历年郡治均在此，或223年筑成的夏口城184年就已存在。南广使用CHGIS盐津附近的近似历史点，不取今宜宾南广镇；该估位不等同考古城址测绘。

武昌按战略都城配置为大城，开局金钱2400、粮7600、预备兵2400，月收入70、180、60；其余新城使用普通城基线。这些是本作数值，不是SAN14原始开局资源。长期创建武昌时仍从父城资源分出，不凭空补足大城开局数值。

所有原85份目录保留原字节和存档校验，新版13份v10开局加入后服务合计98份目录。菜单仍只显示13个最新年代，旧战役继续读取原版本，不自动加城或转换规则。

## 生成与验证

源配置在`game/config/shu-wu-expansion.json`，重建命令为`python3 -B game/build_southern_campaigns.py`。日期引擎兼容旧新兴年初规则，未给旧目录补写新字段或改写旧事件文本。

长年边界测试以只推进日历的受控存档验证年月、实际归属、资源守恒与保存读取；这不代表自动证明了十余年的自然AI战役结果。自然AI与前端行军流程另行验证。
