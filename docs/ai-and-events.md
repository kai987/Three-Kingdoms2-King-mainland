# AI、難度與圖文事件

目前使用本作的確定性規則 AI，不呼叫外部模型。策略評估不抽取亂數；招募、尋寶、計略成功與實際戰鬥使用戰役已保存的種子序列。這些是重製版規則，並非執行 NES ROM 或《三國志14》的 AI。

## 本次都市開發與戰場補給

土地開墾、產業發展、城町人口開發共用同一執行服務。原版已核的知與費用分檔、兩次整數除法、實際增幅及統治度副作用保留；115城初值、月度相對生產與10日一旬是適配。生產因子統一採原版普通難度的`人口百人×(60+floor(產業或土地/3))×統治稅率`，各難度、玩家與AI皆使用同式，開局比率為1，不額外發資源。AI也須有健康在城執行者、實際資金與勢力命令書；報價、取消與查看不抽費用或效果。完整費用表、上限及低統治損失見[都市開發規則與來源](city-development-rules.md)。本次低統治事件稱「統治不穩」，記錄人口、資金兵糧或土地與產業其中一類的實損，不強制改變城主。

戰場補給使用真實庫存與獨立隨軍糧台帳，沿用本作行軍日耗與分數餘額，並非已考定的原版配給式。雙方完成一天行動才結算一次；米屋購入直接進本軍隨軍糧。火箭按已核對的B243整數式燃燒對方隨軍兵糧，燒失明細與食用、補給分別記錄；現代一般14計成功門本輪接原B7BE距離／正知等級差／最終byte判定，原玩家+10共用三難度；籠絡8與伏兵11分開。來源與新驗收狀態見[共用成功門](general-tactic-success.md)。籠絡改用B72B的忠、知德及等級差公式，忠71以上仍付機動力但必敗、不抽效果成功率；AI不選成功率0的目標。攻方缺糧撤退，守方缺糧失守；同日雙方斷糧時先處理攻方撤退，不憑此贈送城池。玩家與AI、AI對AI走同一補給結算，事件僅在玩家參與時彈出。

都市開發與戰場補給資料隨正式交易保存並驗證。若現格式戰局缺少新台帳，查看僅顯示只讀估計，首次實際命令才初始化並扣真實庫存，不因開頁、預覽、語言切換或讀取事件而補糧／初始化存檔。已存台帳的消耗與補給收據不能在載入時重置；事件是有界歷史快照，戰鬥結束後仍可回顧，不要求該戰鬥仍存在。這是原版對齊首批功能，不代表其後全部階段已完成。

## 跨旬戰略與協同攻城

玩家結束本旬後，以「執行電腦行動」處理非玩家勢力。每個勢力保存目標、建立／複查旬期、各出發城的武將名單、預定出發與抵達旬及實際行軍憑據。計畫寫入存檔，讀檔後繼續，不會每次呼叫重新抽取目標。

- 前線威脅按鄰城實際可出戰的健康、未行軍前10名武將，以及已知來襲部隊評估。攻城比較也使用實際10隊守軍，不再把全城99人的兵數全部當成單場守軍。
- 目標評分考慮可投入兵力、守軍、錢糧價值、行軍日數、出征糧耗及地形／季風的最壞減員。規劃不預抽未來天候亂數，過於危險或過遠的路線會放棄。
- 出征、增援與運輸使用與玩家相同的分段備糧及每日消耗服務：先備至下一友城、依實際庫存補糧，明確等待也耗糧。AI可派真實運輸隊在城市節點救援本方在途部隊；不即時送達。缺糧每天損兵1%向上取整，連續10日於旬末開始真實撤退，不殺武將、不抽額外亂數。抵達開戰不重收已付出征費。
- 普通與困難可安排兩／三座城協同攻擊同一目標。長路先出發、短路等待；跨月時按預定出發月重算天候，實際出發再次核對。不同部隊使用既有行軍服務，沒有改短抵達時間。
- 協同部隊在同旬抵達後依現有到達服務接續攻城。每支部隊、每場戰鬥仍各最多10將，不會合成20／30將的超額軍隊。前隊攻下城池後，後隊改按友城容量入城或等待。
- 側翼受威脅時保留實際守軍與預備兵。後方保留至少一名武將，經合法己方／空城通路向目標前線增援；調動仍花糧並受99人容量及在途名額限制。
- 先安排並執行合法出征／增援，再處理勢力內政的自動人事、募兵與前線運輸；旬末由軍備官把剩餘預備兵依能力順序補給在城武將，之後進行駐軍訓練，玩家與AI使用同一服務。城池易主、人員退場、道路阻斷、糧食不足或實際旬期不合時會取消失效訂單並重新評估。處理到玩家參與的戰鬥時保留續行狀態。

地方文吏使用獨立字串 ID，但雇用後與歷史武將共用編兵、戰鬥、單挑、人事轉屬及繼承流程。軍事評估包含健康、未行軍且有兵的文吏，每城合計99人，每方出戰最多10人。

AI從全勢力人選中補足一名高知民政官及另一名高武軍備官，兩人統管全部所屬城池。軍事出征／協同／增援先規劃，後方增援保留勢力委任官；再依前線需求使用與玩家相同的自動登用、勧誘、付費募兵與運輸服務。人事目標跨本方各城排序，同勢力同旬對同一目標去重，自動失敗後冷卻三旬；主動命令共用勢力命令書，手動優先。同城及同一名健康在場武將可反覆執行合法命令，不額外贈送AI命令書或免費資源。收入與訓練按全勢力官員的實際履職狀態在各城結算，各城自行支付費用；駐軍訓練度隨出征部隊記錄，普通攻擊以70為基準按80%–110%調整傷害，AI預估與玩家結算共用係數。文吏月俸仍每人5金，欠薪暫停委任工作。詳細公式、優先排序、失敗冷卻與在途物資規則見[內政委任與前線運輸](domestic-delegation.md)。

玩家與AI都按旬界領城快照發放命令書，未用額度不結轉；旬中易主及存讀不補書。手動配兵確認用1本，已付徵募命令內的配兵及旬末自動分兵不另收；太守任免與方針設定免費。運輸同來源同時最多一隊、目標冷卻與在途資格限制保留；戰場另用整方機動力，`b.used`不再作每將一次的通用鎖；同將在餘額內可連續移動與接敵攻擊，規則見[戰術移動與機動力](battle-tactics.md)。完整費用與原版證據見[命令書規則](command-books.md)。

外交目前包括孫劉同盟及潼關戰事期間馬超、韓遂的協力；沒有通用外交談判或 AI 主動探索未知海路。

## 三檔難度

開局選擇，預設普通，選項隨劇本切換保留，開始後寫入存檔。各檔人物能力、城池收入、兵糧、計略成功公式和減員規則相同，沒有額外資源或傷害加成。

| 項目 | 簡單 | 普通 | 困難 |
| --- | --- | --- | --- |
| 目標複查間隔 | 3旬 | 6旬 | 9旬 |
| 進攻兵力門檻／實際守軍 | 150% | 125% | 110% |
| 同目標最多出發城 | 1 | 2 | 3 |
| 目前劇本全 AI 每旬出征上限 | 1 | 3 | 6 |
| 戰略可接受最壞路線減員 | 35% | 30% | 25% |
| 最遠計畫行軍 | 8旬 | 12旬 | 18旬 |
| 戰場決策 | 普通攻擊 | 評估全部合法計略與普通攻擊 | 再考慮反擊風險、保護與擾亂價值 |

所有進攻至少150兵，並依側翼威脅保留守軍；比例門檻不是額外戰鬥倍率。自訂規則關閉 AI 出征時，所有難度都維持關閉。

## 完整計略決策

AI與玩家共用戰場位置、移動路徑、整方機動力、相鄰攻擊及計略合法目標判定。火箭損糧與籠絡專門機率採[已核對的原式](tactic-effects.md)，虛兵／連環／奇門的現代狀態已分別接線；一般14計成功門本輪接入[距離、正知／等級差及byte符號式](general-tactic-success.md)。其他尚未接的個別傷害／體力／偽擊擾亂及單一伏兵保留明示本作模型；費用使用已證實的整方機動力表；舊每將18氣力不作額外資格鎖。移動按實際地形、適性與該隊兵量計費，一般計略須在5格Chebyshev範圍內，個別仍須正交相鄰或符合地形組合。普通／困難會逐一評估16種計略的合法演員、目標與預期收益，選擇前不抽亂數。評分包括實際兵損、可擾亂隊數、減傷保護、伏兵、體力潰退、低忠誠勸降與敵軍隨軍兵糧；不重複保護、擾亂、降服或對已無隨軍糧的敵軍施放火箭。

| 計略 | 主要評估 |
| --- | --- |
| 火計、要撃、乱水 | 單隊兵損與機動力效率、實際格子地形 |
| 陥穽、落石 | 體力損傷與能否使部隊退場，落石限山地 |
| 虛兵 | 單隊移動封鎖的接敵／空城砦進入威脅；按施計側的日界掃描計數與剩餘戰期估算，不視為取消相鄰攻擊或反擊；AI不重施已中虛兵／連環者 |
| 連環 | 連通水格逐隊移動封鎖收益，攻方4／5、守方3／4的平均日界計數及剩餘戰期；已受虛兵／連環者不重計，不當成取消反擊 |
| 火箭 | 對方隨軍糧可支撐日數與下餐斷糧風險，含已付端數餘額 |
| 偽撃転殺 | 兵損及擾亂反擊 |
| 共殺、連弩 | 所選目標四鄰的十字敵軍／所選單一敵軍 |
| 籠絡 | 忠誠對成功率的影響及可解除的敵兵 |
| 十面埋伏 | 至少100兵、沒有既有伏兵、敵方下一次行動的收益 |
| 水攻、劫火 | 所選敵隊的相鄰BFS連通集合；城格切斷連通，水攻再篩水格，劫火取合法非城格；不評估全圖敵軍 |
| 奇門遁甲 | 現代格局估四持續值平均日界損兵＋移動封鎖、按剩餘戰期封頂；不是自身護盾；舊內部接口仍保留原有guard模型 |

部分原有效果存在相同收益但成本較高的計略；AI 會偏向較有效率的選擇，不為了展示16種名稱強造加成。火箭評分逐一估算五種燒失量，封頂剩餘戰期；敵方尚可行動時折減迫退收益，敵方已待機且下一餐確定不足、依攻方先退規則確定可勝時，AI可直接待機結束當日。虛兵使用幾何接近距離估算移動封鎖收益，不為每一組施計者與目標重跑尋路；攻方寫入3、守方寫入2是日界掃描次數，守方施計後立即到來的首個日界也要計入。已正交接敵的敵隊仍能攻擊，不給虛假的反擊失效收益；空城砦旁仍可占城的攻方隊伍則另計進入威脅。受虛兵／連環影響的AI只排除移動候選，合法攻擊、計略與原地設施操作照常；玩家仍可付費重施，失敗也可能解除對方舊效果。這些評分與待機判斷是本作啟發式，沒有預抽效果亂數或直接執行未發生的勝負。現有單一伏兵記錄按設伏者所屬側觸發，消耗一次、不誤擊己軍；尚不是原版兩側可同時持有的獨立快取，也未扣100兵或計5日界期限，見[缺口台帳](original-parity-gaps.md)。AI 對 AI 也走同一套普通攻擊與計略服務；按共享機動力移動、接敵與換方；雙方完成操作才推進1日，第30日結束仍未分勝負時攻方退卻，按實際兵損結算。單挑沿用既有招式與體力規則。

現代真正接敵會進入持續兵士戰；`expected_attack/expected_contact_exchange`目前仍用舊macro單次傷害與存活反擊作AI近似，不是完整兵士交鋒的精確期望值。既有「prediction matches actual」kernel試驗不等於已對兵種、城砦、武具與訓練的整場分布校準。下一步可用少量真兵士kernel向量校正，仍不預抽RNG、不為每個候選模擬整戰，也不把原AI起戰配置完成說成原AI全決策完成。

## 人物對白與忠誠依據

事件畫面在實際結果說明前加入繁中／日文人物對白，按相關人物ID顯示肖像；醫者、商人及傳令者使用職務稱呼，不虛構史實人物出場。戰場移動、攻擊、待機等高頻操作在原戰報欄顯示兩行簡短預覽，可點擊或用鍵盤展開完整對白，不另擠小地圖。操作失敗保留實際錯誤說明。對白是本作創作，不是史書引文；不消耗命令書、兵糧或亂數，亦不重跑已結算事件。

玩家與AI共用現任君主的親屬／信任忠誠基準，只在開局、實際投效與正式繼位時提高數值。一般調動與讀檔不重套；例外只取消新的關係加成，不強制叛變或降低已獲忠誠。資料與史料逐對列於[人物關係與忠誠](officer-relations.md)。

小沛節點於219年1月上旬切換為譙郡，221年1月上旬升為大都市；兩則事件附史實介紹，明示小沛與譙為不同城池、此處是指定的區域代理切換。都市成長按實際跨月交易判斷：建業在240年1月上旬由大都市升為巨大都市，事件列出新等級及月收入；保留戰局當時的實際城主，不補庫存或免費兵員。重複AI請求、存讀及以後月份不再產生同一事件；240年以後的新開局直接使用巨大都市，不追發成長。此日期與等級為本作設定，不作史實都市分類。

行軍補給事件只在友城實際扣庫存或運輸隊於同城交糧時產生。缺糧減員按旬彙總當旬實際損兵；自動撤退說明回城目的地及原因，部隊仍須走完返程。等待會合、滿城等候及缺糧等待均使用相同每日耗糧服務；事件展示不重跑結算。

都市開發事件保留執行者ID、開發種類、費用、字段與統治度前後值；到上限後僅提高統治，或統治已滿但開發仍增加，均按實際增幅顯示。統治不穩事件保留當時統治度、單一損失分類與實損，零損失也不虛構損害。戰場斷糧事件記錄戰局ID、攻守側、已過日數、剩糧、日需與不足量，說明攻方退卻或守方失守。三類均有繁中／日文對白與說明，復用原版城政／倉庫圖示，不把它們冒稱為原版新取得的內景。市場事件另可記錄戰場去向，明示購入兵糧直接補入隨軍庫存，避免誤認已入戰略城市。

寶庫事件附像素寶箱、目前地圖及可用的相關肖像，記錄實際費用、取得／售出數量與忠誠前後值。每次正式尋寶只抽一次亂數；賞賜、出售和任命不抽亂數。AI自動賞賜與閒置搜尋／賣寶使用同一服務；遠方AI的寶庫事件不自動打斷玩家。同旬同類本方寶庫事件合併展示，操作彈窗開啟時先排隊，返回戰役後顯示。[詳細規則](treasures-rewards.md)。

文吏推薦、受聘、拒絕、期限屆滿／編制補足後撤回及所在地變化，保存文吏的獨立ID、當時姓名與共用肖像標記，不寫入歷史人物參照。即使候選已離開名冊，事件仍可回顧；共用肖像明列為架空文吏形象。文吏事件只記錄與玩家有關的變化，同旬同類事件合併展示；玩家所屬各城的月俸、實付金額、欠薪人數及金糧預備兵加成合為一則月度摘要。文吏尋訪史將仍產生原有的登用成功／未果事件。

彈窗確認只改本機播放狀態，不發遊戲命令、不抽亂數。操作對話框、忙碌狀態及劇本預覽期間延後顯示；切換繁中／日文保留目前佇列。最近100項結構化事件隨存檔保存；載入進度與初次開頁以既有事件作播放基線，不自動重播全部歷史，可手動回顧。
