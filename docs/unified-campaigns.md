# 统一年代、驻城与界面配置

v9保留原图、106个城池定义和行军规则，215年前开放105城；没有在本轮擅自增加吴、蜀城池。菜单合并为13个不同年月：原版本篇7篇、加强版本篇4篇，以及旧版独有的221年7月、249年1月。重复旧版不再作为新开局选项，但72份已发布目录保留原字节、ID及校验规则，旧存档仍能继续。

这是参考《三国志14》的游戏设定，不等于184年存在九个独立国家。小沛、北平使用本作既有棋盘代理，不是假定地理同址。中立表示本作未配置势力驻军，不代表汉代无人治理。原137名在职武将、150名在野人物及总兵力均保留；按原始来源君主拆回所属集团，不复制人物。详细证据见`game/config/unified-scenario-review.json`。

## 官渡与驻城

200年上党改属袁绍。依据[《三国志·武帝纪》](https://zh.wikisource.org/wiki/三國志/卷01)和[袁绍传](https://zh.wikisource.org/wiki/三國志/卷06)所记高干领并州及204年后降曹的关系；这是本作郡级疆界配置。《三国志14》没有独立上党主城，其高干晋阳记录不能称作上党城市导出。原驻上党的曹方武将保留曹方身份，再参与曹方驻城分配。

现有千人名单快照的在职记录只有所属君主，没有具体城市。因此为已有13名武将补入80条同年同月的公开攻略驻城记录，存于`game/config/reviewed-san14-postings.json`。来源为玩家Wiki逐人表，非官方原始剧本导出。

分配顺序：

1. 君主固定本营；227年牵招雁门的已核实任职保留。
2. 同日期、同来源君主且本作已有在职身份的记录，若对应城市属于该势力且未满30人，优先驻入。
3. 小沛、广陵、建安、新野、北平、柴桑等非同址代理，不计为精确来源驻城。关隘未映射、城市不属该方或未有记录者，进入下一步。
4. 剩余武将按当前总驻人数，从少到多均分到与其他非中立势力有开放道路相连的己城；没有这类前线，或前线满员，再均分到己方其他有空位的城市。同人数按稳定城市ID排序，生成结果可复现。

所有分配只改变开局城市，不改人物属性、兵力、年代资格、在野状态或阵营。13篇共59次实际采用攻略城市、1次保留史料任职；80条参考记录不等于80次实际入驻。`garrison_audit`逐人记录来源、回退原因、最终位置与分配方式。具体城池名册仍是本作玩法配置，尚未完成《三国志14》全员逐城导入。

221、249从旧版独有日期重新生成开局，继承当年来源势力与年表，同时使用当前地图、千人完整属性、30人容量和海陆行军规则，不把其旧版20人存档原地转换。

## 行军时间与随机种子

里程使用城池真实经纬度计算，不使用地图像素距离。各段时间为玩法估计，不声称是史实军队实测速度。

| 路段 | 距离计算 | 日速度 |
|---|---|---:|
| 平地 | 大圆距离×1.18 | 30公里 |
| 山路 | 大圆距离×1.45 | 15公里 |
| 沙漠 | 大圆距离×1.30 | 20公里 |
| 海路 | 沿海航点之间的大圆距离之和 | 70公里 |

陆路单段天数为`ceil(里程/日速度)`，最少1日。海路包含两端陆地接驳，按`ceil(陆地接驳/30)+ceil(海程/70)+2日上下船`计算。多段路线先累加各段天数，再以`ceil(总日数/30)`计算月回合；“最快路线”按预计天数寻路，可包含海路。“仅走陆路”排除海路。没有按天气、部队负重或士气另外加时。

例如当前目录：吴—山阴平地约172公里、6日；阴平—成都山路约378公里、26日；敦煌—酒泉沙漠约430公里、22日；山阴—番禺海路含接驳约1402公里、26日。它们单段均为1个月回合，多段累计超过30日才增加回合。

原“战局编号”实际是随机数种子，影响招募、战斗、单挑等判定。改称“随机种子”并说明相同开局、种子及操作可重现战局；存档保留随机序列进度。

## 界面

桌面战报与地图同列、同宽。右侧操作栏跨地图和战报两行延伸到底，主菜单势力列表占用剩余可用高度。手机保留纵向布局。新增丁原势力使用独立颜色，不会误显示成无主城；无主城仍为原版纯白无黑边城标。

## 后续吴蜀城池候选

吴可优先研究武昌（221年起、今鄂州，非今武汉武昌）；临海、临川（257）、建安（260）、吴兴（266）适合按年代开放，不能一律从184年开始作为郡城。蜀的主要郡节点已较全；宕渠、东广汉、南广的设废年份与治所需单独复核。葭萌、涪县可作为县城或军镇，但应与郡级节点区分。

武昌参考[鄂州市资料](https://www.ezhou.gov.cn/zjez/ezrw/ezrj/201501/t20150114_44732.html)；临海、临川、建安、吴兴的设年见[《三国志·三嗣主传》](https://zh.wikisource.org/wiki/三國志/卷48)太平二年、永安三年、宝鼎元年条。本轮只记录建议，未改变地图或增加未确认城池。
