# v14：按城市與年代配置資源

25個最新劇本改用v14；161份已發佈目錄繼續供舊存檔使用。新版本保留115城、每城30人、1023人總庫、歸屬、道路與人物規則，僅調整開局經濟與對應月收入。

原先同一規模的城池固定使用一組數字，同一座城跨劇本也大多不變。現在採用城市生產特色、區域階段和劇本年月，再對洛陽戰亂、許縣遷都、建業建都、漢中爭奪等事件設定個別階段。每個開局有39～45種資源組合，115座城跨年代都有變化；錢、糧、預備兵分別配置，並非一起等比增加。

| 洛陽開局 | 金錢 | 糧食 | 預備兵 |
| --- | ---: | ---: | ---: |
| 190年1月 | 3670 | 10025 | 3730 |
| 191年10月 | 1290 | 2500 | 1680 |
| 217年7月 | 2730 | 8625 | 3090 |
| 263年5月 | 6210 | 17925 | 5710 |

以上為本作平衡數值，並非史實庫存或《三國志14》的開局資料匯出。史料只支持事件、地點和年代；各區域整合、恢復及動員的比例是明列的遊戲設定。建業遷都按《三國志》卷47的229年九月處理；無確切月份的其他設計階段另標為遊戲年界。完整來源及比例在[配置檔](../game/config/scenario-economy.json)。

新開局使用該日期的庫存和月收入。遊玩後，招兵、編兵、行軍、計略、戰損及收入依實際戰局增減；不會在歷史日期強制燒掉玩家的資源，也不重演歷史征服。新城仍從實際所屬母城分出資源，保持兵員守恆。

每名初始武將仍依既定規則帶300兵，城市駐軍總量由當篇實際駐將決定；預備兵則另外按年代配置。沒有把年代未到、已故或歸屬待考的人物塞入城市來湊兵力。人物安置的完成範圍見[逐劇本審計](officer-placement-audit.md)。

城市詳情顯示開局參考日期、經濟階段與現有資源；繁中／日文均支援。武將庫另可篩選本局在籍、在野、年代限制、歸屬待考和容量不足，避免將總庫人數誤認成當年駐城人數。

## 存檔與驗證

舊目錄沒有改寫，也不升級玩家存檔中的資源。重新開啟v14戰役才採用新配置；已開始的其他版本繼續使用原目錄與校驗值。

瀏覽器保存及讀取改為保留伺服器輸出的原始JSON文字。舊版行軍存檔中的`315.0`等數字不再因重新編碼成`315`而損壞校驗；伺服器仍嚴格檢查原checksum，未放寬驗證。

```sh
python3 game/build_economy_campaigns.py
MARCH_CORE_BACKEND=rust PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -p 'test_remake_scenario_economy.py' -v
python3 -m unittest discover -s tests -p 'test_remake_save_transfer.py' -v
node tests/test_remake_library_status.cjs
node tests/test_remake_save_transfer.cjs
```

經濟測試涵蓋25個劇本／219個勢力開局、年月邊界、增減方向、實際招兵／編兵費用、月收入、兵員守恆、新城繼承、讀檔及舊資料位元組不變。瀏覽器另驗證城市預覽、武將篩選、語言切換、手機版，以及舊版行軍存檔的實際保存與讀取。
