# 按真实到货计算剩余需求

3021 在城市开局现有仓粮上扣未支付的真实承诺。九旬余额依序加入生产、结算粮食和工资、记录缺口，再加入该旬到货。同一旬到达的粮只影响下一旬及以后。当地市场、求援及普通运输走原有实际支出入口。

提供无到货、加入可靠到货、再加入日期可用的条件性到货三条计算。软天气风险使用公开可见条件推迟预测，已停驶、失去路权或改道的运队不以确定日期覆盖需求。未发运运单需要实物仍有保障、押运者仍可用且路径能重报，并估算其最迟执行后的净到期。已入仓的粮已在当前库存中。

候选报价从实际预计到达旬之后寻找最早剩余缺口。总量有限于真实剩余需求、城池接收、来源政策和命令书。普通调粮和战略调粮共享同一时序。单站中转的第二腿用已收货粮重新核查。
