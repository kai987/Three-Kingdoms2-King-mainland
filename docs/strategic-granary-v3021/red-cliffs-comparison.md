# 赤壁二十年经济对照

上一轮 208-10／2026／策略 211／天气 221 中，S1 至 S3 的缺粮城旬从 2,159 减至 1,158，累计缺口从 496,090 减至 392,075。单次缺口中位数从 37 升至 147.5，说明缺粮频率与缺粮深度需要同时看。期末官仓粮从 15,956,216 增至 21,996,311。同期战斗数从 203 降至 177，历史数据存在战事与经济轨迹的共同变化，无法只归因于粮仓调度。

S3 账面长期未动的储备约 48.71%。定义取期末仍贴有储备标签、连续九旬以上未记入该观察器计数的储备粮。这个比例适用于该局及该定义。国库资源流、实际军事供粮和不同势力的存续应分别核对。

赤壁以长江及南北水陆连接为主，黄巾样本同时出现大量北部边境及河西缺口。用 `spatial-grain-imbalance.csv` 和城市分组检查地域聚集，用 `winter-army-supply-comparison.csv` 核对军队申请粮和期限前实收。两个剧本继续各自保留历史配对。
