# 粮食可调配能力分层

| 层级 | 含义 |
| --- | --- |
| L0 | 同势力全部城市的实际官仓库存，并单列除目标城以外的库存 |
| L1 | 扣已承诺资源及必要保护后的经济余粮 |
| L2 | 允许外运且具备合法去程与返回路线的经济余粮 |
| L3 | 当时合格来源城能够装载的粮，计入命令书、回程、押运和单次限制 |
| L4 | 扣途中损耗后可赶上最早未覆盖缺口的预计到货量，上限为该旬缺口 |
| L5 | 从同一检查点继续真实观战，按主动调粮新运单与实到收据核对的同一截止日前净交付 |

固定检查点逐目标出值。同一来源的多种走法只取一条可行容量。同一条来源资源可以出现在多座目标城的独立反事实中。各目标预计金额只能单独阅读。L5 只计检查点当旬或此后新发运的主动调粮，随时间变化的道路和其他城市竞争仍按实况结算。源表保留运单、运队、来源城与实际到货旬。更长的整局收据另见 `proactive-dispatch-comparison.csv`。

历史实付字段的三个月地理余粮与固定检查点的九旬来源预算是不同采样。没有采集到具体资格或候选兑现的部分用空值。0 表示适用且测量为零。

旧版欠缴观察器直接将 `timely_new_shipment` 写成 0，当时没有对该城重新计算期限报价。旧汇总的 `timely_legal_coverage` 因此只反映这个占位值。新版汇总把旧字段标为未采集。这里的 L4 和 L5 分别来自固定状态报价与实际续跑。
