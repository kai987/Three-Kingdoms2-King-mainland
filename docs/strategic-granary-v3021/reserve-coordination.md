# 实物承诺和战略储备

仓内粮按军队承诺、未出库战略运单、中转实到额度及战略标签分账。可用余额等于实际官仓减去有效分账。预测固定费用、政策存量和冬季安全需求用于推导安全线。汇合保护目标取对应的最高要求。

两旬或三旬后的紧急缺口才评估能及时到达的条件性储备释放。实际发运前重新核对已承诺资源、粮袋、留守兵力、人员、来源账及路线。来源仍保留必要开支、预报净缺口、防御和正式冬季保护。换旬内沿用同一储备标记，真实花费提交时只改变标签与原官仓余额。

民用刚性消耗仍从官仓结算。紧急返程补粮检查独立的真实锁定资源、本地必要消耗和物流政策。仓内标签没有独立库存。

3021 的 `coordination` 是独立开关。G3d 只采用剩余需求，G3 开启协调，两者共用 G2 的计算。
