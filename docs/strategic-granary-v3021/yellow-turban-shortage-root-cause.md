# 黄巾二十年缺粮复核

V3.0.2 的 184-02／2026／策略 211／天气 221 跑满 720 旬。同一个实付口径下，S1 的 1,092 次缺粮合计 468,290 粮，S3 的 2,166 次合计 557,913 粮。单次缺口中位数从 157.5 降至 30 粮。策略扩大了频繁的小额缺口，累计缺口仍增加约 19.1%。

S3 的 2,166 个缺粮城旬中，同势力其他城市的仓内库存均足以覆盖这次缺口。按旧观测的三个月储备口径，621 次还观察到可沿合法路线到达的理论余粮足以覆盖缺口。候选押运人员与来源城任务限制常在此前九旬同时出现。运输日数、官仓余粮、实际人员和命令书会进一步缩小可按期发运的可行集合。

历史观测记录了 1,119 次因有运单而排除目标的规划，其中 1,098 次同旬预测仍有缺口。日志没有保留每一次拦截时的全量替代报价，无法量化其中本来一定能送到的粮量。本次以真实运单和同一结算时间线验证了可部分覆盖的情况，并改掉城市级整段跳过。

1,092 笔战略发运中，有 7 笔随后三旬内在相同所有者的来源城见到缺粮。现金、实际市粮、战争和兵力流动需要分别对照。旧观测缺少每次发运时的反事实安全结果，保留 7 条时序关联及未确认的因果字段。

`top-city-turn-ledger.csv` 的时间键为命令起始旬。`shortage-root-cause.csv` 使用实际欠缴结算旬。月度人口、兵力、城镇等级及库存见 `top-city-monthly-facts.csv`。四个五年区段的频率、缺口深度、连续旬及减员见 `shortage-severity-comparison.csv`。
