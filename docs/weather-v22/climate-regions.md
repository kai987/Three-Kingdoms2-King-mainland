# 区域与路线映射

现有经纬度、山地类别和路线分段决定气候归属。分区独立于势力、行政州和剧本开城日期。南方高地以越嶲、云南和建宁的已配置地形为锚点。夷洲、珠崖及吕宋使用热带岛屿区。

| 区域 | 地理范围 |
|---|---|
| `liaodong` | 辽东及东北高寒区 |
| `northern_frontier` | 北边塞、河套 |
| `northwest` | 凉州、河西走廊 |
| `qinling_highlands` | 秦岭、陇山高地 |
| `north_china` | 华北北部 |
| `central_plains` | 司隶和中原 |
| `huai_north_jing` | 淮河、荆州北部 |
| `southern_basins` | 长江中下游、四川盆地 |
| `southern_highlands` | 南方指定高地 |
| `lingnan` | 岭南、交州低地 |
| `tropical_islands` | 南方岛屿 |

陆路和海路取端点之间 16 个等距中点，连续同区采样合并。分段工作量按覆盖比例分配，保留原报价总和。河流沿用已有物理河段 ID。已配置冻区优先使用河段规则；其他河段以现存路线的经纬度近似位置归区。水陆接驳与登船采用对应城池的区域。

验收数据含 158 个城市、59 个物理河段及双向路线分段。端点插值是游戏地图概化，复核时优先查验高地、跨区以及折线较长的航路。表格中的 `mapping` 说明各行的映射依据。
