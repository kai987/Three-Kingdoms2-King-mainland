# 性能

天气每日按固定区域、启用的物理河段、实际行军与运输任务更新。路线分段按地图输入缓存，报价表按当时可用的通行网络和观察日复用，所有权及库存检查读取当前状态。

每局的 CPU、墙钟时间、最大单旬、进程内存、路线调用次数、重新规划次数、区域和河段更新数见 `performance-comparison.csv`。墙钟时间包含并发观战的资源争用。RSS 是观战工作进程的峰值，工作进程可接续运行多局。

策略 211 的首轮数据使用优化报价缓存前的引擎，正式候选 G4a 使用缓存优化后版本。缓存增强在三个十二月 W5 案例中逐回合复测，111 份紧凑存档完全相同。不同组的引擎快照与实际源文件哈希随包附上。
