# 观测指标与数据口径

每局保留原观战的月度、城市、势力、城池缺粮、作战、军队军粮需求、运队、资源承诺和行动能力流水。新增天气可按每个区域、物理河段、队伍和游戏日追查。

| 数据 | 口径 |
|---|---|
| `regional-weather-daily.csv` | 区域实际雪势、始末日、积雪、寒冷与冬季年度 |
| `snowfall-events.csv` | 降雪事件的第一个实际日 |
| `snow-accumulation.csv` | 每次积雪变化 |
| `river-ice-daily.csv`、`river-freeze-events.csv` | 河段每日指数与状态、状态跃迁日 |
| `weather-route-impacts.csv` | 有天气附加影响的队伍日，粮、兵折算人数、实际工作量和冰封状态 |
| `winter-cargo-impacts.csv` | 当日货粮路线实扣，以同一库存和余数计算基础与新增部分 |
| `winter-military-actions.csv` | 出征与援军、到达和运输回执、市场和 AI 季节性操作 |
| `river-freeze-duration-summary.csv` | 按一次连续完全冰封的实际天数计数，跨观察结束日的河段以 `censored=true` 标记 |
| `winter-army-supply-comparison.csv` | 冬季打开的 V2.1.2 军粮需求口径，使用原始需求登记及给付回执 |

日期采用战役 30 日制，粮、金和人口沿用游戏量纲。每完整的平常路线日是 644,000 工作单位。实际路线延迟用工作单位衡量，除以 644,000 可读成等效日。人员日含实际兵士、武将折算人数及承运预备兵。`affected_unpaid_grain_numerator` 是带天气影响记录的行军日未发口粮分子。除以 5,000,000 可换算为粮值，包含当天的原有后勤缺口。

CSV 的 `0` 表示观测得到的零，`null` 及原始事件可选字段的空值表示当前无可定义值。各局 `run.json` 单独标注不适用的天气流。尚未结束或运行错误见 `simulation-manifest.json`。不同观察期限的配对显式标出，百分比以基准非零为前提。

区域气候汇总使用每个剧本和种子最长的实测序列，同一气候序列的短期和长期重复部分合并计算。配对结果保留原始组别。分季节统计中，实际出征按起点归区，作战计划和有战斗日的守城按目标归区。实际结算的战斗次数包含空城战，守城次数须有守方和至少一天战斗。出阵耗时使用出阵时的路线报价。

及时补给率沿用现有 V2.1.2 独立需求分段定义，它以基础路线粮耗估算需求开始和截止时间。引擎真正扣粮、阻塞和天气新增成本使用独立的每日流水复核。因天气取消而未形成的军事计划、冰封引起的各次改道和完整的押运人日未单独逐笔采集。
