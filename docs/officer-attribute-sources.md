# 武將屬性來源與原版德修正

原版ROM SHA256為`26c8d921ff5c208191f136480bcd8d7e89c2e4ed40a0ac7b51482bcb52fe2b82`。武將表由檔案位移`0x22010`開始，共237筆、每筆12位元組；`+4`為德，`+6..7`是小端序原始經驗。資料保存在`game/config/references/original-officer-stats.json`，每筆均保留位移、原始12位元組及記錄SHA256；一般建置與遊戲執行不需要讀取ROM。

## 修正原因與優先規則

先前擴充人物資料時，原版姓名對照尚未完成，大部分德使用了歷史參考評分或使用者授權的預設60。後來完成220名原版人物的姓名身分核對，肖像綁定已有此對照，屬性來源卻沒有同步更新。因此嚴顏被設為60，劉備被歷史四維評分設為88，並非原版ROM的值。

目前德的來源優先順序為：已確認身分的原版ROM值、其餘人物的逐人歷史參考遊戲評分、史料不足的使用者預設60。220名原版對應人物中214名的數值有差異：89名原先是預設60、125名原先是歷史參考評分；另6名數值本來就相同，現在也統一標明原版來源。其餘803名的德沒有因此改動。先前評分與依據完整保存在`previous_virtue_design`及`previous_virtue_profile`，目前值標為`verified_original`。

| 人物 | 原版記錄ID | 德欄位檔案位移 | 修正前 | ROM值 |
|---|---:|---:|---:|---:|
| 嚴顏 | 63 | `0x22308` | 60 | 86 |
| 劉備 | 222 | `0x22A7C` | 88 | 99 |

這次只修正德的來源優先級。武、知與原版不同，多數是使用者已確定的SAN14武知轉換，保留原始100並轉成99；不隨德修正還原成原版武知。體力、適性、兵力、忠誠、裝備及登場經驗也保持本作初始化規則。

## 身分核對範圍

220名對應來自原版姓名字形轉寫、明確姓名／異體字及唯一人物身分核對，使用`portrait-identity-map.json`既有審查記錄；不使用肖像相似度、能力相似度、名冊順序或執行期ID推定人物。

剩餘17筆原版記錄仍未自動對應：王建、韓瑛、韓琪、義渠、金環結、刑道栄、蔡陽、崔諒、尚寵、任双、趙月、張南、董荼奴、龐柔、雷同、李湛、李珪。其中10名目前人物庫沒有對應姓名；張南在目前庫中有兩位同名人物；其餘6筆涉及省字／異字，不能僅憑近似字串就視為蔣義渠、金環三結、邢道榮、向寵、董荼那、雷銅。這17筆的原版數值已保存，但在身分確認前不覆蓋其他人的屬性。

## 經驗與驗證

原版「經」的顯示值為`floor(原始經驗 / 50) % 1000`。合法原始值0–49999對應0–999；初始值0表示尚未取得經驗，不表示沒有這個欄位。等級使用原版門檻1000、2000、3500、5000、7500、10000、15000，執行期分級0–7（對應原版等級1–8）。現行戰鬥結算累積原始經驗並更新等級，轉屬與存讀保留該值。

可用下列命令重驗：

```sh
python3 -B tools/officer-placement/import_original_stats.py /path/to/三国志2超级版.nes --check
python3 -B -m unittest discover -s tests -p test_remake_original_stats.py
python3 -B game/build_campaigns.py --check
```

匯入工具只接受已釘選的ROM，使用已審查姓名對照，重跑可重現。建置器會逐劇本檢查220人的德及原始記錄證據，不允許劇本差異把它們重新改成預設值；原版以外的人物繼續使用既定來源規則。
