# 武將屬性來源與目前轉換政策

目前1,052人採用 `campaign-officer-stats-v1`：**有SAN14來源者的武、知、德對應武力、知力、魅力；初始體力與忠誠另按可核對的原版武將表配置。** 缺SAN14來源者明列原版數值或本作設定。數值是遊戲資料及本作轉換，不是史實測量；目前共同政策取代先前「原版ROM德優先」與逐人歷史德評分的執行規則。

## 武、知、德

已保留SAN14參考值的1,000人，德直接取魅力，與武、知共用最高99的尺度；來源100保存在 `profile.source_stats`，顯示及規則使用99。其餘52人沒有魅力來源，依使用者指定設德60，不用姓名相近者、原版德或舊歷史評分補值。這52人中，遼東王建採已核原版武24、知75，其餘51人的武、知為明列的本作設定。

| --- | ---: | ---: | --- |
| 嚴顏 | 86 | 77 | SAN14魅力77 |
| 劉備 | 99 | 99 | SAN14魅力99 |
| 曹操 | 97 | 96 | SAN14魅力96 |

因此嚴顏現在77是政策變更的結果，不是再次漏用原版86。初次轉換的1,023人中983人的德改變、40人相同；其中972人來自魅力轉換，11人由先前歷史設計值改為缺來源的預設60。這是首次轉換的歷史快照，不改寫為目前人數。

按目前人物各自的不可覆寫基準 `pre_campaign_stat_policy_v1` 重算，1,052人有984筆德變更（提高385、降低599）及68筆不變。比首次快照多出的德變更是新綁王建的原德41轉為目前60，並非修改原1,023人的基準。這些數字由 `import_campaign_stats.py` 的 `make_report()` 計算，與[逐人JSON](officer-stat-changes-v1.json)及[CSV](officer-stat-changes-v1.csv)一致。屬性政策不代替年代、歸屬或駐城的獨立核查；本次另外處理的劇本配置見[配下與年代核查](retainer-affiliation-audit-20261027.md)。

SAN14數值來源為保留的[第三方轉寫參考](../game/config/references/san14-abilities.json)，不是官方資料匯出。1,000筆魅力與目前52筆缺來源分開標記，不宣稱新增人物具有來源中不存在的魅力值。

## 原版表的體力、忠誠與身分核對

參考[攻略頁附件](https://www.cnblogs.com/strick/p/10171248.html)的武將資料ZIP，保留為[離線數值與逐行證據](../game/config/references/cnblogs-officer-stats.json)。ZIP的SHA256為 `6dff28ec4bb74776de6cb6e232388e7210982e8e1761adff45a73adccc2933b0`，內文SHA256為 `231c554b6de801ecf9d2387e42b549ce49a3e12ae94dd237a8e6153f1bb18187`。這是第三方遊戲資料轉寫，並非官方原始檔或歷史測量。

237筆來源中，224人可綁定：212筆唯一姓名／既有別名、9筆逐人審查異字、3筆具上下文的身分核對。剩餘13筆保留未綁定，不按能力相似度、肖像、排序、執行期ID或模糊姓名猜配。

本次只新增 `cnblogs-line-0229` 的王建綁定，其餘236條完整來源記錄與舊223個綁定不變。原表的「196年、遼東在野」遊戲語境及[《晉書》卷一](https://zh.wikisource.org/wiki/晉書/卷001)的公孫淵相國王建，支持與唐代同名人物分開核對；不是用武知、頭像或行序猜配。原表196年出場、249年壽命不帶入史實年代；出生估界與238年仕履的留保另載於人物年代設計。

### 初始體力與恢復上限分開

- 224名可核對者取原表的**初始／當前體力**；其餘828人初始體力80。王建為42、恢復上限80；此次其他21名新增人物初始體力80。
- 恢復上限是 `max(轉換前本作上限, 新初始體力)`，以容納新初值，並保留既有恢復能力。這是本作相容政策，**不宣稱來源表證明了原版最大體力**。
- 初次1,023人轉換中，201人的初始體力改變，85人的恢復上限提高、938人上限不變；先前追加7人採80，這些數字保留為當時快照。目前1,052人相對各自基準仍有201筆初始體力變更、85筆上限提高、967筆上限不變，詳見逐人報告。
- 新開局與未來首次登場都用這個初值；未來登場當月不立即再加一次月恢復。之後仍按本作每月恢復8、至上限為止。
- 查詢、預覽、存讀、調動及轉屬不會重新填滿受傷武將的體力，也不會復活已死亡或退場人物。

### 忠誠必須符合所屬勢力

原表忠誠有勢力語境。目前217名匹配人物有數字忠，其中180人能確認勢力ID；另7筆來源是君主標記 `--`。普通武將初始化時，只有目前所屬勢力在來源明列的 `faction_ids` 中，才使用該數字忠。只有地點說明、未能對應勢力、沒有原表或來源為 `--` 時，普通武將採80。

例如嚴顏原表忠86屬劉璋語境：劉璋開局可用86，其他勢力開局不盲目套用。諸葛亮原表最後欄是「孫策左側空城」，這是地點，不能據此推定忠97屬孫策。新登場在野者忠為0；任何本局君主內部固定100、畫面顯示 `--`，包含地方文吏繼承人。原表 `--` 不直接轉成普通武將忠100。

王建的原表忠59同樣保留，但「袁紹右側空城」只是位置說明，`faction_ids=[]`；公孫氏臣屬開局仍採忠80，在野則0。原表德41保留為原作證據，目前缺SAN14魅力時仍採德60。

成功登用與勸誘仍按現有 `recruitment_loyalty()` 結算，轉屬、繼承、戰後處理與存讀保留目前規則。這次不把原表忠誠當成永久固定值。

## 新來源與既有ROM證據分開保存

[原版ROM參考](../game/config/references/original-officer-stats.json)仍保留237筆原始12位元組、檔案位移及SHA256，既有[肖像身分對照](../game/config/portrait-identity-map.json)的220個綁定保持不變；本次只新增原版11號王建，現在為221個綁定、16個未綁定。ROM的德欄位 `+4` 是可查證據，不再覆蓋目前SAN14魅力政策。

新表的224個綁定不是原版221個綁定的改名覆蓋。兩份轉寫有身分與數值分歧，例如新表「費帏」對應費禕，舊ROM同數值記錄的姓名轉寫是潘濬；「傅婴」與舊傅巽亦分別記錄。相同數值不證明同一人物。目前可比較同身分215人，5筆數值衝突保存在變更表，未靜默合併。

原版參考中的首次220人匯入審計仍為改動214人（原預設89、原歷史設計125）、原值相同6人；這是舊匯入的歷史記錄，不因目前綁定221人就重算成221人的審計。新增王建的原11號、原德41及目前德60分開驗證。

逐人轉換前的 `profile`、`configuration`、`virtue_design`、`initialization` 存在不可重複覆寫的 `pre_campaign_stat_policy_v1`。更早的原版德修正及歷史評分證據也保留。逐人[JSON](officer-stat-changes-v1.json)及[CSV](officer-stat-changes-v1.csv)包含目前1,052人與各人的基準，不以新人物改寫舊人物的過去值。

[29篇開局稽核報告](officer-stat-scenarios-v1.json)逐人核對來源體力、勢力語境忠誠、魅力轉德、預覽與同版存讀。目前統計以重新生成的報告為準。先前版本的3,169城次預覽、8,844名次駐城人物、2,338名次在野人物，以及1,511筆忠誠與2,919筆初始體力變動，保留為舊資料集的跨劇本實例快照，不能當成目前實例數或不同人物總數。

## 經驗、容量與驗證

原版「經」顯示為 `floor(原始經驗 / 50) % 1000`；合法原始值0–49999對應0–999，登場初始化為0。等級門檻1000、2000、3500、5000、7500、10000、15000不變。每城歷史武將與文吏合計99人、每方出戰10人；全部29個劇本採同一轉換政策，歷史及假想的日期、城池歸屬與人物安排維持各自設定。

下列檢查完全離線，不需要ROM、下載原附件、登入帳號或開啟既有存檔：

```sh
python3 -B tools/officer-placement/import_campaign_stats.py --check
python3 -B tools/officer-placement/import_original_stats.py --check
python3 -B tools/scenario-history/retainer_audit.py --check
python3 -B -m unittest discover -s tests -p test_remake_stat_policy.py
python3 -B -m unittest discover -s tests -p test_remake_original_stats.py
python3 -B game/build_campaigns.py --check
python3 -B tools/officer-placement/audit_campaign_stats.py --check
```

若另有已取得的原ZIP，可用 `--source-zip /path/to/霸王的大陆武将.zip --check` 重解析並核對釘選SHA與輸出。一般建置直接讀離線參考。建置器驗證1,000筆魅力、目前52筆預設、初始體力、恢復上限與忠誠語境，劇本差異不能覆蓋共同政策。原版匯入工具的 `--check` 僅驗保留證據，不執行舊德匯入，不寫人物或重算首次220人審計。

這是資料集更新，不改寫或遷移舊資料集存檔。刷新最新版本後請新建戰役；目前戰役的體力與忠誠不會在畫面刷新或讀取時偷偷重設。
