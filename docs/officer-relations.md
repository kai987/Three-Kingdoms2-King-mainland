# 対話・人物関係と忠誠 / 對白與人物關係忠誠

人物の対話は本作用に書いた台詞です。史書の引用や、原作台詞の完全な復元ではありません。56種のイベントに繁体字中国語／日本語の応答を添え、実際の結果・費用・損失は、その下の既存の明細を正とします。医師・商人・伝令などの役割を使い、実在しない担当武将を勝手に作りません。44種の命令を分類し、登用の相談、成功・拒否、編制、出陣、移動、攻撃、計略、一騎討ち、施設、輸送、政策の設定を共通表示層で扱います。内部のAI進行や後処理は新しい対話を挟みません。

頻繁な戦闘操作の応答は、既存の戦報欄へ2行でコンパクトに表示し、クリック・タップまたはキーボードで全文を開けます。地図の高さは変えません。イベントの履歴と既存の重複防止・プレイヤー関連判定は維持し、対話のために再計算、乱数消費、命令書の支払い、保存形式の追加を行いません。操作失敗は実際のエラーメッセージを保ちます。

## 忠誠の適用条件

- **現在の君主本人と同じ勢力に所属する、生存中の本人**を、安定人物IDで照合します。同姓、同郷、劉氏の遠縁、仮の親子関係からは推定しません。
- 新規戦役・実際の登用／転属（戦場の籠絡を含む）・正式な君主交代の時だけ、従来の忠誠計算に関係の基準を適用します。プレイヤーの後継選択前の仮君主には適用しません。プレイヤーとAIは同じサービスを使います。
- 通常の武将は **`max(従来の忠誠, 適用基準の最大値)`**。複数の関係は加算しません。基準は最大99、従来値が100なら下げません。在野0、君主の内部値100／画面`--`は維持します。
- 一般基準は親子95、兄弟92、叔甥90、宗族88、養親子90、姻戚90、史料上の信頼95。個別の史料と既存設定を優先し、劉備配下の関羽99・張飛98を保ちます。**数値は本作の設計値であり、史書に忠誠95と書かれているという意味ではありません。**
- 年代の例外は新しい関係加成を抑えるだけです。既に得た忠誠を下げたり、史実どおりの裏切り・処刑を強制したりしません。対立があれば、全ての親族を一律に高忠誠にはしません。
- 既存の進行中セーブの忠誠、負傷、乱数、君主、所属は読み込み時に変更しません。表示・更新・通常移動・月替わりでも基準に戻しません。今後実際に投効／正式継承した時に適用します。詳細画面は「任用時の基準」と「現在値」を区別します。

関羽が曹操に属する局面に、劉備との関係を持ち込みません。張飛と関羽の義兄弟儀礼を正史の事実と断定せず、[『三国志』巻36](https://zh.wikisource.org/wiki/三國志/卷36)の「恩若兄弟」等の記述を信頼関係の根拠にします。劉封、袁氏兄弟、董卓と呂布などの対立は、下の例外に記録します。

## 繁體中文說明

對白為本作創作，不是史書引文。現任君主與武將同屬一方且存活時，以明確人物ID及年代比對親屬／信任關係，在新開局、實際投效及正式繼位時提高任用忠誠基準。玩家與AI同規則；不按同姓推定、不累加、不反覆修復忠誠。例外只取消新的加成，不強制叛變或降低已有數值。既有存檔讀取後的忠誠保持不變；人物詳情另列目前數值、任用基準及史料。

## データと検証

- [関係JSON](../game/config/references/officer-relations-v1.json)：史料・安定ID・個別の年代。人物の元属性、年代、所属、都市を変更する資料ではありません。馬超・馬騰・公孫康などの既存データとの年代差を、この作業で隠して修正していません。
- [共通忠誠サービス](../source/remake/officer_relations.py)：現在の君主、例外優先、適用時点、読み取り専用の説明。
- [対話表示](../game/dialogue.js)：56イベント／44命令、人物・役割、繁中／日文。過去イベントの話者に、現在の君主を無条件で代入しません。
- [29シナリオの独立監査](officer-stat-scenarios-v1.json)：元の武将表と別の関係データオラクルから期待値を求め、全都市のプレビュー、新規開始、保存・再読込を照合します。従来の原版忠誠と新しい関係による基準は別の証拠として保持します。

人物表のIDは増減せず、既存のシナリオカタログのハッシュも変更しません。関係ファイルはブラウザーのPython/WASMパッケージに明示的に同梱し、ローカル版と同じ規則を使います。
