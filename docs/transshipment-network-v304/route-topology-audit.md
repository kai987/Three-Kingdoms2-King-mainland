# 路线与接岸证据

审核 29 个剧本和 158 个地图城池 ID。实际可通行的有向段中，陆路 16,517 段，混合路 3,833 段，纯河段 58 段，纯海段 0 段。剧本间共享道路，因此按剧本计数。

郁林、苍梧是同时与纯水段、可衔接陆段相连的两座地图城池，共 58 个剧本／城池组合。每份可执行订单还要核查当时的同势力归属和实际人员。

长江江阳至巴郡、黄河金城至朔方、珠江郁林至苍梧及辽东至东莱已列出原路线的分段与固定点工作量。江段和海岸几何样本的加权工作量与原方向相等。
