# 观测与数据字典

| 统计 | 定义 |
| --- | --- |
| 发运 | 实体运队创建之后记录实际来源、货粮、口粮、模式、物理瓶颈及命令书 |
| 到货 | 原游戏交割事件中的实际数量。格外标记军队、运队接济和入库货量 |
| 收据 | 真实终结时记录货粮结转、粮袋收支、人员接收及冷却 |
| 来源阻塞 | 发运次数、活动位置、储备、防御、真实人员等。保留报价次数与唯一来源城旬 |
| 总容量利用率 | 同组有可比容量的载粮与粮袋之和除以容量之和 |
| 货粮利用率 | 有可比容量的货粮之和除以容量之和 |
| 冬季及时 | 原实际需求及期限所覆盖的实到量 |
| 两种战略及时率 | 发运时原始预测窗口，以及实际运单承诺窗口 |
| 缺粮风险 | 同势力同一来源城在发运后 1、3 或 9 旬有实际缺粮事件 |
| 期末在途 | 右删失。只对观察到的到货和日耗给出数值 |

`null` 表示未采集、尚未完成或分母为零，适用条件随字段记录。零是已观测计数。CSV 与 JSONL 保留可复算的分子、分母、日期和归属。观察回调读取事件和快照，挂载前后验证游戏状态和随机数一致。

来源城风险只统计结束日前具备完整后续观测期的发运。历史基线用原 `convoys.csv` 发运和 `shortages.csv` 的实际缺口复算。当前运行先用原运单核对所有新增发运事件，再用相同口径统计。
