# Web戰役規則層

目前可玩的獨立Python規則：最多115城、每城30人、每方出戰10人、1023名人物、25個v13開局。161份目錄保留各版本的身分與規則，用於舊存檔驗證。啟動與操作見 [遊戲說明](../../game/README.md)。

本目錄不讀ROM、不呼叫模擬器或原CPU，也不解釋控制IR。`source/recovered/`與C11庫是另一條原機規則研究線，保留作為證據參考。

| 模組 | 職責 |
| --- | --- |
| `campaign.py` | 戰役狀態、xorshift32亂數、指令提交、普通攻擊、兵員守恆、驗證與存檔 |
| `officers.py` | 人物／屬性、出生與出仕及退場、名冊、轉屬、容量與出戰選人 |
| `campaign_expansion.py` | 招募／勸降、16計略、單挑、戰後處理、戰略AI與簡化繼承 |
| `travel.py` | 路徑報價、在途部隊、到達、探索航路及AI行軍 |
| `route_hazards.py` | 陰平單行、子午谷季節、季風、一次航程風暴與整數餘兵分配 |
| `session.py` | 劇本切換、讀檔、開局預覽、勢力資源與人數；快取不變的開局摘要 |
| `map_presentation.py` | 年代城名、原版城標與按劇本固定的勢力配色 |
| `garrison_postings.py` | 建置期駐防均衡與邊境配置共用助手 |
| `errors.py` | 共用遊戲錯誤 |

## 保持的契約

- 總人物庫與當年登場分開；高編號及非連續ID有效，1005保留空槽。執行期容量1200，空引用用`None`。
- 依目錄讀取每城容量；v13為30人，舊目錄保留各自規則。出戰包含主將，最多10人。
- 缺乏任職／駐城依據的人物保持待考；新增人物的本作估計年代與史載分開保存。
- 指令先在副本執行並驗證，成功後提交；失敗保留資源、名冊、兵員、亂數與進度。戰果及AI回執防止重複結算。
- 存檔包含scenario、原目錄位元組SHA及狀態校驗。舊目錄不改寫，不繞過校驗替換規則。
- 預覽、查看城池、切換語言及重畫地圖不抽亂數或推進月份。開局摘要快取只保存不變資料，每次回應仍重算目前在籍人數與資源。

人物設定、來源與完整玩法見 [v13名冊](../../docs/officer-expansion-v13.md) 及 [戰役規則](../../docs/remake-campaign-rules.md)。效能量測及Rust邊界見 [優化與遷移評估](../../docs/code-optimization-and-rust.md)。完整外交、逐格戰術移動、複雜歷史事件與原版音畫仍有待開發。
