# 遊戲操作與建置

```sh
python3 -B game/build_march_core.py
python3 -I -S -B game/serve.py --port 8878
```

開啟 http://127.0.0.1:8878/ 。服務只監聽本機；預設使用 Rust 原生核心，瀏覽器預估使用 WASM。Python 計算仍可作後備與差分驗證。執行不需要 ROM、原模擬器或逆向研究檔案。

服務會核對本機 Host、Origin 及瀏覽器跨站請求，並限制 JSON、連線與審計記錄的資源占用。大型介面資料支援 gzip，靜態資源以 ETag 重驗證；存檔不快取，原始存檔格式保持不變。這是單機服務，雲端登入不會把本機 API 變成多人伺服器。細節及效能量測見[本機服務安全邊界與效能](../docs/runtime-safety.md)。

主選單提供 25 個年代／IF 劇本，預設 217 年 7 月。選劇本及勢力會預覽城池顏色、錢、糧、預備兵與實際武將數。人物總庫 1,023 人；當年在籍、在野、未來登場及不登場分別處理，不把全人物庫塞入同一年。

選擇劇本時，可點擊地圖城池選中該城所屬勢力，右側名單與摘要同步更新；歸屬使用所選劇本的開局資料。點空城保留上一次選中的勢力。城池情報仍可查看，開始新戰役前不改變目前進度。

城池內的歷史在籍武將與已雇文吏合計最多 99 人，出戰每方最多 10 名武將（包含文吏），每名武將最多 999 兵。在野人物與尚未雇用的文吏候選不占定員。人物按出生、出仕與退場年月處理；缺精確駐城史料的安排明記為本作推定。人物頁可查屬性、德的依據、歸城證據、參考年月及登場窗口。

武將名鑑提供全部、我方勢力、在籍、在野、未登場及已退出六種篩選。「我方勢力」依本局實際所屬，包含行軍武將；不把規劃中的人物算入。武／知／德分別參考SAN14武力／知力／魅力，1,000人德取魅力（來源100轉99），23人缺來源設60。原版德與舊歷史評分保留為證據，執行時採新政策。經按原版 `floor(原始經驗 / 50)` 顯示0–999；尚未登場者顯示「—」，經驗成長、戰鬥分級及轉屬保留既有規則。逐人變更見[屬性來源](../docs/officer-attribute-sources.md)。

223名可核對至原版武將表者採表中初始體力，其餘800人初始80；恢復上限保留原本作上限與新初值的較大者，不等同已考證的原版最大體力。未來登場當月不立即再回復8，之後按月正常恢復。普通武將僅在來源忠誠的勢力語境與本局所屬相符時採該數字忠，其他情況80；在野0，本局君主畫面顯示`--`（內部100）。原表`--`不給普通武將忠100。登用後依既有公式結算；預覽、存讀及調動不重設現有忠與受傷體力。這次不改29篇的年月、城池歸屬及人物配置；請以新版資料新建戰役。

## 地方文吏

本方城池的「地方文吏」可查看缺編、候選期限、雇員、薪俸、專長與尋訪選項。零武將城也可操作。普通城以2人、大城及巨城以3人為最低編制；開局零人城立即提供候選，其餘依連續缺編與月度檢查生成，每城最多保留1名候選、有效3個月。雇用費60金，占本城本旬行動；拒絕不扣雇用費、不耗城池行動，兩者均有3個月冷卻。

地方文吏以獨立字串 ID 與名冊保存，不占歷史人物 ID；武將名鑑仍為1,023人，文吏另列。雇用後進入共用人物流程，可編兵、出戰、施計、單挑、轉屬及繼承，與歷史武將合計受每城99人、每方出戰10人限制；城池失陷時按普通武將撤離或成為在野，不隨城自動轉屬。每月每人5金薪俸，未足額支付者暫停委任工作；不再按文吏專長重複增加被動收入。

正常履職、健康且本旬未行動的文吏可尋訪本城及可訪問鄰城的歷史在野人物，與歷史武將共用成功公式、登用費與城市行動。雇用當旬已使用城池行動，須等下一旬再尋訪。玩家與 AI 共用候選、雇用、尋訪、薪俸及容量規則，不自動把歷史武將替換成文吏。完整觸發、亂數及存檔規則見[地方文吏招募](../docs/civil-staff.md)。

## 內政委任與前線支援

頂部「勢力內政」或本方都市情報的入口，均開啟同一份勢力委任。整個勢力共兩名不同的民政官及軍備官，從全勢力各城選人，統管全部己方城池，亦可保留空缺。民政官的知影響每城商農額外收入；軍備官的武影響各城付費募兵及駐軍訓練度，費用和預算由各城分別支付。訓練度隨出征部隊記錄，影響普通攻擊傷害；70為基準，0及100分別對應80%及110%，玩家與AI相同。共同方針包含自動登用／勧誘、全勢力使者、能力優先、成功率、每城預算、排除名單、資源保留量及工作順序；全勢力目標擇優且每名操作者每旬最多一次。手動命令優先，各城主動命令仍每旬一次；商農及訓練為全勢力持續工作。友城調任保留職位，在途、參戰、負傷或欠薪時暫停，抵達友城或恢復條件後繼續，同一旬不重複結算。

「前線支援」設定目的城、保留量與補充目標，啟用並儲存後顯示可派遣預覽。資金、兵糧及預備兵在出發扣庫存、途中計帳、抵達入庫；押運人員保留原城編制，永久增員另派調動。保留委任官及守軍，已在途補給扣除需求。只自動使用已知安全陸路；海路及險道須明確啟用，天候與減員沿用既有行軍核心。目的地易主或道路被截斷時按實際行程返程，無法接收時等待。玩家與 AI 共用執行服務，完整公式見[內政與運輸](../docs/domestic-delegation.md)。

玩家主將退出時會先要求選擇本方存活的繼承人，文吏同樣可選；AI 依德、知、經驗及穩定ID決定。

## 地圖與回合

地圖右下城名按鈕依「主→巨→大→全→隱」循環。巨僅顯示巨大都市、大僅顯示大都市，兩者按所選劇本的都市等級精確區分。寬螢幕且頂部餘寬足夠時，原戰報欄移到標題與操作選單之間，日誌在固定高度內捲動；地圖按原比例利用騰出的高度、右側欄相應收窄。窄螢幕、低矮視窗或頂部不足容納時，戰報保留在底部，切換不重設倍率與選城。

長安、譙郡、江州、吳、山陰設為大都市，陳留為通常都市，成都為巨大都市。建業於240年1月上旬由大都市升為巨大都市，出現一次「都市擴建」圖文事件，地圖篩選與都市情報同步更新；240年以後開局直接使用巨大都市，不追發事件。新開局資源與月收入按新規模設定；進行中只改後續月收入，不補存量、不增加免費兵員、不強制轉屬。這是本作設定，不是史實都市等級。

地圖在視覺輸入相同時保留原SVG、相機、焦點與導航監聽器，編兵等不改變地圖的操作不再整圖重建；城池歸屬、日期、地名、路網、顯示模式、預覽及目標高亮等變化則重新繪製。操作處理器仍綁定目前戰役，避免讀到上一份狀態。

點擊城池圖標或名稱可看城池詳情。滾輪／雙指縮放，滑鼠或手指拖動，左下可縮放／還原全圖；縮放及平移受地圖邊界限制。頂部導覽列的「返回主選單」可重新選劇本，開始新戰役會取代目前記憶體中的戰局；內政、名鑑、事件回顧、規則、語言與音樂設定集中在「更多」。

本方城池可編兵、出征、招募／勸降、調動及徵募預備兵。都市情報名單顯示姓名、兵、武、知、德、忠、經與體力，招募依德、編兵與出征依武排序。數字輸入超出上限會自動修正；編兵還受現有兵數與本城預備兵之和限制，確認後對話框保留，可繼續編制。確認前可取消。出征後部隊先行軍，到達才進入戰鬥；在途武將占出發城名額，不能重複行動或參加守城。滿員目的城會等待名額。

點選出征或招募／勸降後，地圖先高亮可操作目標；點選高亮城池才開啟該城的名單。登用只有本城一個可操作目標時，直接開啟本城登用對話框。招募依實際在野地點、勸降依可勸降敵將的駐城篩選；取消或 Esc 不耗資源及行動。觸屏操作會自動捲回地圖。武將選項把兵數放在姓名後；編兵／出征依武→知→德→體力→經驗→兵數排序，招募依德→知→武→體力→經驗→兵數排序，最後以穩定人物 ID 決定同值順序。

出征即時顯示已選人數／10人；選滿後停用其他未選項，已選者仍可取消。返回名單保留選擇。調動名單則依目的城剩餘定員、可用武將及路線兵糧計算上限，切換目的地或路線後自動取消最近選取的超額人選。零人、滿城、缺糧、無路線及無法行動的武將不能確認；招募與徵兵亦預先檢查資源、定員及執行武將。計略會停用不符合氣力、地形、受擾亂或設伏條件的選項。

兩座本方城之間，可沿道路經過任意數量的本方城與無主城調動。目的城仍須屬本方，敵城不能通過；途中不占領無主城、不改變其資源或駐將。抵達前再次核對沿線與目的地歸屬，敵方截斷時依既有規則取消調動。

行軍選項按實際路徑合併，同一路徑只列一次；單一路徑顯示最短日數，不同路徑分別標示陸路、海路或海陸並用及天數。陰平道、子午谷的名稱與減員規則保留在風險說明。未知航路須先點「探索未知航路」，才顯示探索路徑並允許確認；取消探索或切換目的城後回到已知路線，不會自動改走未知航路。

每回合固定一旬 10 日，每月固定 30 日，依序為上旬（1日）、中旬（11日）、下旬（21日）。每旬先進入玩家戰略階段，玩家結束後各電腦勢力依序行動，再推進下一旬；月收入、體力恢復、到期登場與建城僅跨月結算，年度事件僅跨年結算。行軍按 `ceil(實際日數 / 10)` 旬抵達，不會提前到達。地形、距離、道路類型、季節與季風影響時間及減員，見[特殊路線](../docs/hazardous-travel.md)。電腦完成本旬行動後再交回玩家。重複 AI／戰果請求不會重複結算。

出征、調動和運輸共用按日口糧，以當天 `兵數＋100×隨行武將數＋運輸預備兵` 計算、保留小數餘額後累計取整，一般部隊的運輸預備兵為0。出發只預裝至下一座本方城的口糧，途中依友城庫存補足下一段；沒有可補給友城時預裝全程，空城不供糧。正常行軍最後不足10日只計實際路程，但滿城、缺糧、等候會合等明確等待仍每日耗糧。

缺糧時暫停正常前進，每日各隊士兵及運輸預備兵損失 `ceil(現有兵數/100)`，不扣出不存在的糧、不殺武將、不抽新亂數。連續10日缺糧在旬末觸發真實撤退，返回途中仍可能缺糧減員，不會瞬間入城退款。「前線支援」可選本方在途部隊，顯示實際會合城、可派押運官、送糧上限及最大值按鈕；同一城市實際接觸才交付，不能隔空補糧。

運輸貨物與口糧分開記帳，抵達才交貨；押運人員始終保留原城編制且忙碌，不占目的城名額，卸貨後自動實際返原城。永久增員請另用武將調動。返程先用貨物及未耗口糧，友城依實際庫存補給；不足仍按每日規則處理，不免費補糧。抵達開戰不重收已付出征費，重複到達／AI請求也不重扣。詳見[前線運輸](../docs/domestic-delegation.md)及[行軍耗糧](../docs/hazardous-travel.md)。

戰鬥可普通攻擊、施放 16 種計略、挑戰單挑或退卻。這些是本作規則；目前 AI 能力與事件畫面範圍見 [AI 與事件](../docs/ai-and-events.md)。38類結構化事件以目前地圖局部、人物像素肖像及說明自動排隊呈現，包括友城／運輸補給、缺糧減員及自動撤退；可略過本批或從事件回顧重讀，文吏事件使用獨立身分與明列的共用像素形象。

戰場以1024×960畫布繪製，寬高各提高4倍，保持原版256×240比例與原顯示尺寸。旗標預設顯示姓名首字；同一陣營出現同姓武將時，該陣營的同姓旗標改顯示姓名末字，敵我兩方分別判定。HUD及部隊名單保留全名。單挑按人物ID顯示12類兵器、13類坐騎外觀；27位具名人物另有來源或本作演繹設定，各項考證與美術選擇分開記錄，其他人物使用固定通用配置。點選戰場旗標或展開部隊名單選將，普通攻擊後依實際結算順序播放攻擊與敵方回應；16種計略、埋伏觸發及單挑均有演出。可點「略過演出」或按Esc；背景分頁與降低動態效果設定會直接顯示結果。動畫不抽亂數、不修改存檔，也不增加戰術移動規則。原版素材、補充效果、裝束來源及回退方式見[戰鬥畫面](../docs/battle-scenes.md)。

## 音樂與音效

首次點擊或按鍵後播放原版標題、戰略、戰場與單挑音樂。四曲由使用者提供的ROM以原Nestopia音訊回呼錄製，包含N163聲部；原音序、振音相位、循環邊界及來源雜湊記錄在 `assets/audio/index.json`。

互動音效優先使用原版錄音：13 段原音效供 21 種操作使用，涵蓋選擇、確認、取消、行軍、攻擊、計略及單挑。16 種計略依原版資料表對應四組音效；選擇、取消、單挑操作及短勝敗提示等網頁操作復用原版短音效，並在 `assets/audio/effects.json` 明記用途映射。原版未對應的換旬提示採用本作音效；原音檔無法載入或解碼時使用合成音效。素材整理方式及原版／復用界線見[原版音效](../docs/original-sound-effects.md)。

「音樂設定」可分別調整背景音樂及音效音量、靜音及試聽。背景分頁暫停，偏好僅保存在本機，不消耗遊戲亂數或改變存檔。

## 本機與雲端存檔

「儲存進度」同時保存瀏覽器本機資料及下載 JSON。「讀取進度」可選本機資料或 JSON 檔案。只接受目前版本資料；不載入或遷移舊劇本存檔。無效檔案、校驗錯誤或過期操作不改變目前進度。

新戰役建立、每旬結束與推進、戰鬥結果或戰後結算、載入成功後會建立瀏覽器本地自動恢復點，與手動存檔分開存放，最多保留最近3份；容量不足時逐步減少份數。介面顯示戰役日期與保存時間，失敗時提示手動下載，不中斷戰役。從「讀取進度」選擇恢復點並再次確認後，才把原始JSON交由既有載入與校驗流程處理。開始操作或切換戰役會使延遲的自動保存失效，避免舊回應寫入錯誤戰役。自動保存不更改原存檔JSON、不覆寫手動保存、不自動上傳雲端；關頁前仍應確認已保存，必要時下載JSON。

「雲端存檔」提供電子郵件／密碼帳號、跨裝置讀寫與每帳號 5 個私人槽。註冊後先確認電子郵件。登入不自動上傳；覆蓋、載入及刪除由使用者明確操作。多裝置以版本及存檔 UUID 防止相互覆蓋。詳細設定見 [雲端存檔](../docs/cloud-save-options.md)。

## 瀏覽器載入與資料傳輸

靜態Web版依實際進度顯示版本清單、資料下載與執行環境準備、戰役初始化。顯示的累計遊戲資料位元組不含Pyodide執行環境，也不是整體下載百分比；重試的讀取量亦會累計。已驗證的Python程式包、主選單預覽與初始劇本可與執行環境並行取得。暫時性下載錯誤採有限次重試，雜湊、解壓大小及來源路徑檢查仍保留。

首次就緒前若載入失敗，可點「重試載入」建立新的Worker。遊戲已就緒後不提供這種重建重試，避免悄悄失去記憶體進度；應重新整理並明確讀取存檔。命令、載入與其他寫操作不自動重放。

瀏覽器可選`view_cache`傳輸協定，在分頁內保留不變的人物基本資料與劇本說明；後續只傳目前所需的動態資料並還原完整介面視圖。行軍報價重用依資料集、玩家、月份、有效城池及歸屬、已發現航路失效，不把整份戰役或指令結果當成跨回合快取；仍使用相同規則與亂數。這不表示所有路徑計算均已省略，本機API與原始JSON存檔亦維持原有邊界。

## 唯一資料來源

`config/campaigns/` 保存目前戰役的共用資料與劇本差異；都市規模另以 `config/city-scale-rules.json` 為共用輸入。`data/campaigns/` 為生成結果。

- `people.json`：1,023 人的共同資料、穩定 ID、能力與史料依據。
- `shared.json`：共用世界、路線、規則，以及劇本共用的基準資料。
- `scenarios/*.json`：每篇差異，使用明列的 `set`、`update`、`delete`；人物差異另列 `people_overrides`。
- `index.json`：25 篇順序及預設劇本。
- `provenance.json`：來源 URL、原始快照雜湊與資料整理紀錄，僅作依據，不載入歷史目錄。
- `../city-scale-rules.json`：都市等級、規模倍率與建業240年成長日期；開局生成和即時月收入共用同一規則。

```sh
python3 -B game/build_campaigns.py
python3 -B game/build_campaigns.py --check
python3 -B game/build_map_anchors.py
python3 -B game/build_map_presentation.py
python3 -B game/build_portrait_manifest.py --check
python3 -B game/build_message_locales.py
python3 -B game/build_locales.py
```

重建不連網、不讀舊版生成檔案，也不讀玩家存檔。修改配置後應重建並測試；人物、城池或規則變更會改變劇本資料 SHA，存檔只對目前資料有效，不建立逐代相容層。
