# 本地试玩：九十六城扩展战役

在项目根目录运行：

```sh
python3 -I -S -B game/serve.py --port 8878
```

打开 **http://127.0.0.1:8878/** 。只需Python3.10以上与现代浏览器，无需ROM或安装游戏依赖。服务仅监听本机。默认提供217年7月的96城战役，可选184、190、194、200、207、221、227、249年；选择页保留之前的八个剧本读取旧存档，选项标示配置人数以区分版本。

## 开始一场战斗

1. 选择“217年 · 汉中争衡”和刘备势力，开始战役。
2. 定位巴西，在“编兵”将张飞调整为999兵、法正调整为600兵。
3. “出征”选择汉中，勾选张飞、法正、马忠，经过确认页再出征。
4. 选择部队和敌军，使用普通攻击、计略或挑战单挑。对手可以拒绝单挑；接受后操作突击、防守、佯攻或退出。
5. “接收战果”一次结算名册、兵员、经验与城池归属。
6. “结束回合”后“执行电脑行动”。电脑攻打玩家时，会暂停并让玩家操作守军；接收战果后继续电脑行动，全部完成才推进一个月。

每城最多20人，出战每方最多10人，包含主将。地图位置、32×32原版城标及海陆连接保持v42文件原样，已有7条城际海路也接入出征与调动；下拉框可定位任意城池，“本城/全图”切换视角。

## 人物与人事

总库1000个独立人物条目，五组同名人物分别保留。上一批补齐了体力和适性，本批继续增加120份德评分，完整人数从148增至268。217年7月开局164人仕官、7人在野；其他完整人物按各自年代及来源状态筛选。剩余人物包含尚未出仕、已过卒年、地点或属性待配置等情况，“人物库”可以检索和筛选，不会把1000人直接塞入城市。

- **招募**：寻找本城或相邻本方/中立城的在野人物。每次60金并消耗本城行动；可以被拒绝，满城时不执行。200年孙策势力可在吴郡寻访朱桓、顾雍等。
- **敌将转属**：劝说相邻敌城的非君主武将，每次100金并消耗本城行动。成功后保留体力、带兵、装备与经验，按招募公式结算忠诚，双方名册一起更新。
- **调动**：沿连续的本方道路调往另一座本方城，每人每段道路5粮，消耗出发城行动。本回合已参与人事或调动的武将不能连续调动或立即出征。
- **年代**：出生、出仕和死亡分别判断。新的登场人物必须属性和位置齐全，以0兵、基础短剣/絹巾和0经验进入在野；不自动加入势力。月份未知的卒年在次年处理，释放兵员入原城预备兵；此前已死亡人物只补零资源变化回执，不复活。
- **德**：267人有逐人史料参考的四维游戏评分，阿会喃保留原版基线。本批120人的理由、卷次、评分对照和来源在`config/officer-batch3.json`，低置信评分另标；732人仍缺德，不拿魅力或统一50补齐。
- **体力与适性**：已配置基线保留；原缺项体力上限80，适性默认0平地，新增有战区参考者逐人指定1山地或2水地。这是本作可调规则，不是史书测量，也不是按阵营统一给水或山适性。

九个新年代均记录1000份开局安排，来源身份与本作驻城分开。来源有地名时映射到固定地图，其余由势力区域、人物生涯区域及20人容量配置；规划包含暂缺德的人物，防止后续接入时超员。夏侯渊守汉中、张飞领巴西、李严领犍为等另设区域提示。未启用的势力保留待接入标记，不悄悄改投别方。

初始城池归属、人物分布、地形类别及资源属于试制配置，不能视为精确的历史驻军图。SAN14武、知的千人来源为公开第三方数值转录；年代同样是游戏设定，历史认证单独保留。

## 战斗、计略与电脑

16种计略全部有可操作效果、气力消耗、成功判定和结算。名称与成本数字参考已恢复资料；效果、范围、概率、单挑和AI采用本重制版独立规则，详见[战役规则](../docs/remake-campaign-rules.md)。本版没有单位方格移动，不声称重现原机全部算法或动画。

单挑中体力归零前按负伤败退处理，不随机永久杀死人物；双方同时败退不会误报攻城胜利。普通兵损包含伤亡和溃散。战后守军优先退往相邻本方城；无处退往则转在野，剩余兵员入被攻占城预备兵。籠絡产生的投降兵也入城，不记为凭空伤亡。

电脑会招募、劝降、补兵、沿道路调兵，并按邻城兵力判断出征。玩家守城与AI攻城共享同一战斗和结算规则。电脑进度、已处理城池、随机序列和回执都能保存；重复请求不重复推进月份或接收战果。君主到寿命边界后按德选择仍在本势力的继任主将；无驻军或城池时退出战役。全部96城归本方时胜利。

## 存取与重建

“保存进度”保留浏览器本机副本并下载JSON。“读取进度”支持本机副本或导入文件，包含单挑、战斗和电脑攻城中进度。坏存档不会覆盖当前状态。原四城版本的存档仍可读取；新旧17个剧本按各自数据身份校验。扩展版数据后续修改时需要明确的版本迁移，不能绕过属性或年度回执校验强行加载。

```sh
PYTHONDONTWRITEBYTECODE=1 python3 game/build_mainland.py
PYTHONDONTWRITEBYTECODE=1 python3 game/build_eras.py
PYTHONDONTWRITEBYTECODE=1 python3 game/build_campaigns.py
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -p 'test_remake_*.py' -v
```

扩展版构建只读仓库中的名单、数值表和设计配置；运行时读取独立剧本JSON、剧本目录及地图PNG。原演练`demo.json`和52人版`mainland.json`逐字节保留，`build_data.py`是其早期开发转换器，启动游戏无需运行它。

当前732人的德仍待逐人史料评审，251跨年幻想未接入寿命规则战役；九个新年代仍需驻城精考与平衡，190年渤海超过20席的5人保留待安排，不增加虚假领土。装备影响、逐格战术移动、外交及复杂亲族继承未在本批扩展中实现。原逆向源码、ROM及原机资料保持原样。
