# 遊戲操作與建置

```sh
python3 -B game/build_march_core.py
python3 -I -S -B game/serve.py --port 8878
```

開啟 http://127.0.0.1:8878/ 。服務只監聽本機；預設使用 Rust 原生核心，瀏覽器預估使用 WASM。Python 計算仍可作後備與差分驗證。執行不需要 ROM、原模擬器或逆向研究檔案。

主選單提供 25 個年代／IF 劇本，預設 217 年 7 月。選劇本及勢力會預覽城池顏色、錢、糧、預備兵與實際武將數。人物總庫 1,023 人；當年在籍、在野、未來登場及不登場分別處理，不把全人物庫塞入同一年。

城池最多 99 名在籍武將，出戰每方最多 10 人，每名武將最多 999 兵。在野人物不占在籍定員。人物按出生、出仕與退場年月處理；缺精確駐城史料的安排明記為本作推定。人物頁可查屬性、德的依據、歸城證據、參考年月及登場窗口。

## 地圖與回合

點擊城池圖標或名稱可看城池詳情。滾輪／雙指縮放，滑鼠或手指拖動，左下可縮放／還原全圖；縮放及平移受地圖邊界限制。右上「返回主選單」可重新選劇本，開始新戰役會取代目前記憶體中的戰局。

本方城池可編兵、出征、招募／勸降、調動及徵募預備兵。武將名單顯示武、知、德、兵力與體力，招募依德、編兵與出征依武排序。數字輸入超出上限會自動修正；編兵還受現有兵數與本城預備兵之和限制，確認後對話框保留，可繼續編制。確認前可取消。出征後部隊先行軍，到達才進入戰鬥；在途武將占出發城名額，不能重複行動或參加守城。滿員目的城會等待名額。

每回合固定一旬 10 日，每月固定 30 日，依序為上旬（1日）、中旬（11日）、下旬（21日）。每旬先進入玩家戰略階段，玩家結束後各電腦勢力依序行動，再推進下一旬；月收入、體力恢復、到期登場與建城僅跨月結算，年度事件僅跨年結算。行軍按 `ceil(實際日數 / 10)` 旬抵達，不會提前到達。地形、距離、道路類型、季節與季風影響時間及減員，見[特殊路線](../docs/hazardous-travel.md)。電腦完成本旬行動後再交回玩家。重複 AI／戰果請求不會重複結算。

戰鬥可普通攻擊、施放 16 種計略、挑戰單挑或退卻。這些是本作規則；目前 AI 能力與事件畫面範圍見 [AI 與事件](../docs/ai-and-events.md)。多數事件以戰報呈現，尚無自動插畫事件彈窗。

## 音樂與音效

首次點擊或按鍵後播放原版標題、戰略、戰場與單挑音樂。四曲由使用者提供的ROM以原Nestopia音訊回呼錄製，包含N163聲部；原音序、振音相位、循環邊界及來源雜湊記錄在 `assets/audio/index.json`。

互動音效優先使用原版錄音：13 段原音效供 21 種操作使用，涵蓋選擇、確認、取消、行軍、攻擊、計略及單挑。16 種計略依原版資料表對應四組音效；選擇、取消、單挑操作及短勝敗提示等網頁操作復用原版短音效，並在 `assets/audio/effects.json` 明記用途映射。原版未對應的換旬提示採用本作音效；原音檔無法載入或解碼時使用合成音效。素材整理方式及原版／復用界線見[原版音效](../docs/original-sound-effects.md)。

「音樂設定」可分別調整背景音樂及音效音量、靜音及試聽。背景分頁暫停，偏好僅保存在本機，不消耗遊戲亂數或改變存檔。

## 本機與雲端存檔

「儲存進度」同時保存瀏覽器本機資料及下載 JSON。「讀取進度」可選本機資料或 JSON 檔案。只接受目前版本資料；不載入或遷移舊劇本存檔。無效檔案、校驗錯誤或過期操作不改變目前進度。

「雲端存檔」提供電子郵件／密碼帳號、跨裝置讀寫與每帳號 5 個私人槽。註冊後先確認電子郵件。登入不自動上傳；覆蓋、載入及刪除由使用者明確操作。多裝置以版本及存檔 UUID 防止相互覆蓋。詳細設定見 [雲端存檔](../docs/cloud-save-options.md)。

## 唯一資料來源

`config/campaigns/` 是目前唯一的戰役來源，`data/campaigns/` 為生成結果。

- `people.json`：1,023 人的共同資料、穩定 ID、能力與史料依據。
- `shared.json`：共用世界、路線、規則，以及劇本共用的基準資料。
- `scenarios/*.json`：每篇差異，使用明列的 `set`、`update`、`delete`；人物差異另列 `people_overrides`。
- `index.json`：25 篇順序及預設劇本。
- `provenance.json`：來源 URL、原始快照雜湊與資料整理紀錄，僅作依據，不載入歷史目錄。

```sh
python3 -B game/build_campaigns.py
python3 -B game/build_campaigns.py --check
python3 -B game/build_map_anchors.py
python3 -B game/build_map_presentation.py
python3 -B game/build_portrait_manifest.py --check
python3 -B game/build_message_locales.py
python3 -B game/build_locales.py
```

重建不連網、不讀舊版生成檔案，也不讀玩家存檔。修改配置後應重建並測試；人物、城池或規則變更會改變劇本資料 SHA，存檔只對目前資料有效，不建立逐代相容層。
