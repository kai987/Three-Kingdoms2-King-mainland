# Web版：百城战役与年代扩展

在项目根目录启动，然后用现代浏览器打开游戏：

```sh
python3 -I -S -B game/serve.py --port 8878
```

地址为 **http://127.0.0.1:8878/**。需要Python3.10以上；无需ROM、原模拟器或安装游戏依赖。当前服务只监听本机，尚未发布公网版本。

新版采用原游戏的浅粉信息底、黑色方框菜单、像素字体和鲜明地图色彩；v7扩为100城：原图西北增加西平、张掖、酒泉、敦煌，仅姑臧配合新城调整位置，西平在姑臧左下山脚，其余95城、1352×1024尺寸与地形不变。使用32×32原版城标和10条城际海路（含3条新增分段沿海连接）。中文字体使用本地GNU Unifont，出处与许可证在`assets/unifont-source.json`及相邻许可文件中。浏览器中的布局为扩展地图和鼠标/触屏调整，并非256×240原画面的逐像素复制；原版战斗动画与音效尚未重现。

城池显示接入州治城名：成都、长安、洛阳、建业、邺、昌邑、晋阳、临淄、姑臧、寿春、江陵、番禺、蓟和信都，另补上既有颍川节点的许昌城名。原郡名与稳定城池ID保留在目录中，坐标不变；这些名称沿用既定地图节点，不模拟每次州治迁移。地图默认标注主要城名，按钮可切换全部城池或关闭；城池列表和详情保留年代别名：212年前为“建业（秣陵）”，221年前为“许昌（许县）”。依据[南京市地方志资料](https://dfz.nanjing.gov.cn/gzdt/202403/t20240315_4186987.html)及[许昌市政府资料](https://xuchang.gov.cn/zjxc/walkIntoXC.html)。

另按用户确认的10项映射显示：辽东→襄平、渤海→南皮、东郡→濮阳、南阳→宛城、豫章→南昌、吴郡→吴、会稽→山阴、巴郡→江州、巴西→阆中、广汉→雒城。城池详情保留正式县名与原郡名，其中吴显示“吴县 · 吴郡治”。来源与证据在`config/city-name-overrides.json`，以《后汉书》《华阳国志》和CHGIS为依据；豫章误指福建南安的旧链接及广汉原百科链接由本配置中的原典来源替代，旧v42历史地图文件保留原样。此为现有城址的显示选择，“常用”没有统计频率依据，也不表示每个节点在所有年代均为州治或郡治。汉中、长沙、北海等保留既有名称。

这些名称通过独立显示层应用于全部136份目录和已有存档，不需要重开战役；旧目录的底图、位置、道路与存档校验数据不变。

选择剧本时地图实时预览该年代开局归属；选择势力时显示其城池颜色、根据地和城池数量。城标沿用原版32×32像素轮廓；有主城保留黑边和势力内部颜色，无主城为全白无黑边的城标，与有势力但无驻将的城分开显示；均不显示势力色条。重开选择使用地图旁的操作栏，可返回原战役；确认开始前不改变当前进度。右下角道路示意已移除，替换为原版单行风格的年月框，随选择和游戏月份更新。

新开v12统一战役**最多115城（现有25个开局为109～114城），每城最多30人，每方出战最多10人，包含主将**。招募、劝降、调动、AI和战后撤离共用目录容量。已发布的111份目录保留读取旧存档；菜单按剧本分组，仅显示25个最新开局，不再列出重复版本。

v8在原100城位置和地形不变的基础上，增加赵、钜鹿、河间、甘陵／清河、雁门、新兴，并逐剧本配置归属。新兴215年才开放，长期战役中继承晋阳当时实际归属，资源从晋阳分出，不复制兵员；赵和甘陵的地图名称随年代更新。190、191年的雁门以地方汉郡中立映射表示，不声称是历史空城。驻防调配与史料任职分别记录。详见[六城与年代、归属规则](../docs/northern-city-expansion.md)。

v9按《三国志14》公开攻略将184年何进缩为4城，拆回九势力、17个有主节点，其余88城中立；200年上党改属袁绍。13名现有武将补入80条同日期驻城参考，其余同势力武将按敌方边界城人数均分，保持30人容量和年代约束。详见[统一剧本、驻城依据与行军公式](../docs/unified-campaigns.md)。

v10新增蜀地葭萌／汉寿、涪县、宕渠、南广，以及按日期开放的吴地武昌、临海、临川、建安、吴兴。武昌221年4月起，后四吴郡在257～266年的长期战役中开放；具体游戏月份与史料精度分开注明。原106城位置与地形不动，221、227年孙权本营改至武昌。详见[吴蜀九城、年代与归属](../docs/southern-city-expansion.md)。

## 险道、季风与海路发现

v11新增阴平→成都单行道（平地2倍时间、最终余兵1/3）、汉中↔长安子午谷（7～9月4倍时间及50%减员，其他月份2倍及20%）。海路顺风120、逆风7.5公里/日，整次航行只结算一次80%～90%暴风雨减员；4月为平静过渡期。出发月份锁定季节与事件，确认页显示风险。18个沿海节点之间可探索未知海路，成功登陆后在地图和存档保留；内陆节点不可探索。势力选择与战役右栏显示钱、粮、预备兵合计。完整定义、兼容范围及地图重建见[险道与航海规则](../docs/hazardous-travel.md)。

主選單新增所連結[官方PK劇本頁](https://www.gamecity.com.tw/sangokushi14/wpk/scenario.html)列出的3個付費DLC、6個更新IF和1個特典，另加入211年7月「入蜀爭奪戰」與234年2月「秋風五丈原」。225年7月「征伐南蠻」只保留一份；合計25個新開局。史實、IF、特典與自訂分組顯示，詳見[劇本日期、來源、人物例外及配置範圍](../docs/dlc-scenarios.md)。領土、駐將與數值是本作獨立改編，並非官方原始劇本檔案匯入。

頂欄或對話框內的語言選單可切換「繁體中文／日本語」，預設繁體中文並在本機記住選擇。選單、城名、人物名、戰報、風險提示、計略及單挑文字即時更新；切換保留劇本與勢力選擇、搜尋／篩選、勾選武將、路線與對話框，沒有戰役指令請求。人物德值、城池年代的長篇原始資料有日文概要與可展開的繁體原文；出典連結與原資料不假稱已另行史實考證。

語言只影響畫面文字與下載檔名，不更動城池ID、人物身分、原始戰報、隨機數或存檔校驗值。字形轉換使用附來源、固定版本與Apache-2.0授權的OpenCC字典；遊戲執行時不需下載外部字典或安裝套件。日文介面與動態句型由本作詞典翻譯，專名沿用既有來源身分對照。

地圖上方資訊列縮小高度，左下角顯示倍率與縮放按鈕。滑鼠滾輪以游標位置為中心縮放，按住左鍵拖曳；觸控可單指平移、雙指縮放。倍率以完整地圖適合畫面的尺寸為1倍，限制在1～4倍，拖曳依地圖邊界約束；「全圖」恢復1倍，「本城」以3倍定位所選城池。切換城名、語言或更新戰役資訊會保留視角；城池下拉選擇會移至該城。拖曳和雙指操作不會誤開城池資料，正常點擊及鍵盤操作仍可查看資料。視角只存在於目前頁面，不寫入戰役存檔。

服務保留111份已發佈目錄，再加入25份v12，共136份；主選單只列最新25篇。舊存檔可在兩種語言下繼續，原v11險道／季風／海路發現規則由v12沿用。

## 开始一场战斗

1. 选择“217年7月 · 汉中争夺战”和刘备势力，开始战役。
2. 用城池下拉框定位阆中（原巴西），查看本剧本分配的守将，并在“编兵”调整准备出征者的兵力。
3. “出征”选择汉中，勾选本城最多10名可出征武将，确认页查看路线、里程、天数及预计到达月，再出征。部队进入在途状态；结束回合并执行电脑行动，至预计月份点击“处理到达部队”才进入战斗。
4. 选择部队和敌军，使用攻击、计略或挑战单挑。对手可以拒绝；接受后操作突击、防守、佯攻或退出。
5. “接收战果”结算名册、兵员、经验和城池归属。
6. “结束回合”后“执行电脑行动”。遭到攻击时由玩家操作守军；接收战果后继续电脑队列，全部完成才推进一个月。

点击地图城标或城名会打开城池资料窗，显示归属、钱粮、预备兵、地形、驻城人数及武将武知兵力；鼠标、触屏和键盘均可使用。选择剧本时读取该剧本的开局资料，游戏中读取当前城池状态；电脑回合与战役结束后也可查看，关闭后保留原阶段及操作按钮。查看不扣资源、不推进回合、不改变存档。玩家回合用下拉框选择城池仍可直接在右侧操作，“本城/全图”切换视角。只有当前选中城显示方框，有主城仅用城标内部颜色标识势力，原下方色条已移除，无主城为白色空城标。

## 人物与玩法

总库1000个独立人物条目现已属性齐全。本次保留269份已有配置，新增16人的史料参考德评分；其余715人按用户指示暂设德60，并单独标明“默认值”。合计284人参考史料评分、715人默认60、1人保留原作基线。既有武、知、体力、适性和个人身份保留；本次731人的体力80、平地适性0仍是初始化默认。人物库支持按评分来源筛选、检查依据。详见[德值配置与各年代开局人数](../docs/virtue-completion.md)。属性齐全不等于当年登场，仍按年表、归属、驻城及容量筛选。

- 招募：访问本城或相邻本方/中立城的在野人物，每次60金且消耗本城行动，可能拒绝。满城在扣钱、抽签前拒绝。
- 劝降：相邻敌城非君主武将，每次100金。成功后保留体力、兵力、装备及经验，忠诚按本作规则结算。
- 调动：按最短预计天数寻找本方连通路线，可选最快海陆联运、仅走陆路，v11另可指定险道、已知直达海路或探索未知海路，每人每段5粮。确认后进入在途状态，到达月份入城；途中不能重复人事、编兵或守城，仍保留出发城编制容量。
- 年代：出生、出仕、死亡分别判断；未来人物必须属性、位置齐全才以在野出现，不强制按历史改投。卒年月份未知者在次年清理，已有退场人物不复活。
- 战斗：16计略含成功判定、气力与结算；单挑体力降至1时负伤败退。战后守军退往有空位的相邻本方城，否则转在野，兵员入城预备兵。
- AI：招募、劝降、补兵、调动、邻城出征及简化继承。电脑攻城暂停并交给玩家操作守军，回执防止重复结算与推进月份。

战斗、人事和AI使用本重制版规则，详见[战役规则](../docs/remake-campaign-rules.md)。当前没有单位逐格移动、完整外交、复杂亲族继承或完整历史事件链；不声称还原原机全部算法。

## 存取与离线重建

顶部“返回主菜单”可从城内、行军到达、电脑回合或战斗界面返回剧本与势力选择；点击“继续当前战役”恢复原阶段，战役结束时可“返回战役结果”。返回菜单和继续均不扣资源、不推进回合、不重置战斗或行军；只有点击“开始新战役”才建立新战役。

“保存进度”写入浏览器本机副本并下载JSON；“读取进度”可读本机副本或文件，支持战斗、单挑和电脑回合进度。数据身份与哈希匹配后才载入，失败保留当前进度。136份目录（当前v12的25份、已发布旧版111份）各自校验，不能修改旧目录或绕过校验迁移存档。已有进度不会自动切换到v12；新版归属与驻城规则需从主菜单新开战役。v7旧战役仍为100城。v6及更早版本继续沿用即时调动及出征。

## 西北布局、航路与行军

西北五城仅调整城标和道路图层；姑臧旧城标、旧接驳路从新版底图中移除，地形图层完全不动。源资产和旧版底图均保留。重绘新版底图使用 `node game/render_city_map.cjs --travel`，沿海矢量重绘使用 `node game/render_coastal_roads.cjs`，再运行 `python3 game/build_map_presentation.py`。

江东经吴—山阴陆路接海，沿东冶一带海岸中转至番禺，再经高凉、合浦到交趾。东冶是航路点，不增加第101城。沿海军运有史料依据，具体路线、港口接驳及速度是本作改编；269年的建安海道出兵次年退还，不能写成已验证的全程成功通航。

下述常规速度是v7～v10基线；v11险道与季风覆盖对应路段，见上文。陆路按经纬度距离与地形绕行系数估算；海路按沿海经纬度航点累加，港口陆上接驳另按陆速计算。平地30、山地15、沙漠20、海上70公里/日，每条海运边另加2日上下船。各段天数相加后，以30日为一个月回合向上取整，因此12日和26日都在下一个月到达，超过30日的长途运输会跨多个回合。电脑采用相同规则。确认页显示预计到达月，“在途部队”显示剩余月回合。

到达事件逐一处理，遇玩家战斗暂停，接收战果后继续剩余到达；满城等待下个月，目的城或沿途友城易主则取消调动，出发城失陷按战后撤离并取消原行军，途中死亡按原年度规则回收兵员。取消与退却暂不另算返程时间，没有路上拦截战或逐日模拟。完整边界见[行军规则](../docs/remake-travel.md)。
