# 本地试玩：荆襄演练

在项目根目录运行：

```sh
python3 -I -S -B game/serve.py --port 8878
```

打开 **http://127.0.0.1:8878/** 。只需Python 3.10以上和现代浏览器，无需安装游戏依赖。服务只监听本机。

## 一条完整操作路线

1. 选择蜀军，点击“开始演练”。
2. 在襄阳点击“编兵”，选择伊籍，兵力设为600后确认。
3. 点击“出征”，目标选择南郡，勾选伊籍，经过确认页再出征。
4. 选择本方部队及守方目标，点击“攻击”直到出现战果；也可主动退却。
5. 点击“接收战果”，一次结算兵损、名册、归属和城内资源。
6. 点击“结束回合”，再点击“执行电脑行动”，进入下一玩家回合。连续三次会从217年11月推进至218年2月。

“保存进度”同时保留浏览器本机副本并下载JSON文件。“读取进度”可以读取本机副本或导入文件，包括战斗中进度。坏存档不会覆盖当前状态。重开演练的选择页可以取消，确认开始后才替换当前战局。

## 本切片的规则边界

- 采用完整96城底图和1000人物总库。本局只开放南阳、襄阳、南郡、江夏四座相连城池和217年可登场的7名已配置人物。姜维尚未登场；没有虚构补齐992人的能力。
- 城内最多20人，战场每方最多10人含主将。出征期间保留原城占位，胜利后移驻目标城。稳定人物身份与运行ID分开；本局实际使用255和999两个ID。
- 城市阵营、驻地、初始资源/兵数、普通攻击公式和电脑整备都是本作演练设计，不是史实剧本或已证等价的原作算法。攻击目前只使用兵力、武力及保存的随机序列；智力、体力、装备、地形、计略与单挑尚未接入战斗效果。
- 普通战斗兵力归零代表败退，不随机造成武将永久死亡。胜利时守方武将退出驻军但保留人物记录；未出战守军的余兵进入目标城预备兵，不自动招降武将。败退和主动退却保留实际兵损与耗粮。
- 编兵是预备兵与带兵数之间的调配。征募与出征各消耗城池当回合行动，编兵不消耗。电脑每回合执行一次驻军整备，当前不主动攻城。
- 出生、出仕和寿命事件按已提交年份推进；月份未知的卒年在次年处理，释放兵员回到原城预备兵，不复活已死亡人物。此前已死亡的人物跨过寿命年份时只补一次零资源变化的年代核对回执。复杂君主继承、外交、完整势力灭亡和完整战役属于后续范围。
- 随机序列、回合、资源、人物、战斗和结算回执随存档保存。校验和用于发现损坏，不是防作弊机制。
