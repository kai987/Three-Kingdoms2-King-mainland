# Web版：九十六城战役

在项目根目录启动，然后用现代浏览器打开游戏：

```sh
python3 -I -S -B game/serve.py --port 8878
```

地址为 **http://127.0.0.1:8878/**。需要Python3.10以上；无需ROM、原模拟器或安装游戏依赖。当前服务只监听本机，尚未发布公网版本。

新版采用原游戏的浅粉信息底、黑色方框菜单、像素字体和鲜明地图色彩；保留96城位置、32×32原版城标及7条城际海路。中文字体使用本地GNU Unifont，出处与许可证在`assets/unifont-source.json`及相邻许可文件中。浏览器中的布局为扩展地图和鼠标/触屏调整，并非256×240原画面的逐像素复制；原版战斗动画与音效尚未重现。

城池显示接入州治城名：成都、长安、洛阳、建业、邺、昌邑、晋阳、临淄、姑臧、寿春、江陵、番禺、蓟和信都，另补上既有颍川节点的许昌城名。原郡名与稳定城池ID保留在目录中，坐标不变；这些名称沿用既定地图节点，不模拟每次州治迁移。地图默认标注主要城名，按钮可切换全部96城或关闭；城池列表和详情保留年代别名：212年前为“建业（秣陵）”，221年前为“许昌（许县）”。依据[南京市地方志资料](https://dfz.nanjing.gov.cn/gzdt/202403/t20240315_4186987.html)及[许昌市政府资料](https://xuchang.gov.cn/zjxc/walkIntoXC.html)。

另按用户确认的10项映射显示：辽东→襄平、渤海→南皮、东郡→濮阳、南阳→宛城、豫章→南昌、吴郡→吴、会稽→山阴、巴郡→江州、巴西→阆中、广汉→雒城。城池详情保留正式县名与原郡名，其中吴显示“吴县 · 吴郡治”。来源与证据在`config/city-name-overrides.json`，以《后汉书》《华阳国志》和CHGIS为依据；豫章误指福建南安的旧链接及广汉原百科链接由本配置中的原典来源替代，旧v42历史地图文件保留原样。此为现有城址的显示选择，“常用”没有统计频率依据，也不表示每个节点在所有年代均为州治或郡治。汉中、长沙、北海等保留既有名称。

这些名称通过独立显示层应用于全部50份目录和已有存档，不需要重开战役；地图底图、位置、道路与存档校验数据不变。

选择剧本时地图实时预览该年代开局归属；选择势力时显示其城池颜色、根据地和城池数量。城标沿用原版32×32像素轮廓，仅着色内部；无主城保留白色空城标，不显示势力色条。重开选择使用地图旁的操作栏，可返回原战役；确认开始前不改变当前进度。右下角道路示意已移除，替换为原版单行风格的年月框，随选择和游戏月份更新。

新开本篇战役**每城最多30人，每方出战最多10人，包含主将**。招募、劝降、调动、AI和战后撤离共用目录容量。已发布的39份目录按原版本规则读取旧存档（其中17份每城20人、v4/v5的22份每城30人）；选择页勾选“显示旧版战役”可重开旧版本。

## 城市规模与四川通路

新开v6的11个战役按城市规模初始化资源；每月收入仅发给已有归属的城池，新增预备兵计入兵员账本。

| 规模 | 城数 | 开局金钱 / 粮食 / 预备兵 | 每月金钱 / 粮食 / 预备兵 |
|---|---:|---|---|
| 普通城 | 83 | 1200 / 3800 / 1200 | 35 / 90 / 30 |
| 大城 | 9 | 2400 / 7600 / 2400 | 70 / 180 / 60 |
| 巨城 | 4 | 3600 / 11400 / 3600 | 105 / 270 / 90 |

巨城为邺、许昌、洛阳、长安；大城为陈留、濮阳、宛、襄阳、江陵、汉中、成都、建业、寿春。其余扩展节点先用普通城基线。这是参考《三国志14》城市经济差异后制定的本作缩放值，**并非其剧本开局资源的直接导入**。来源、收入参考值及二手资料边界记录在`config/city-economy.json`。

新增阴平—成都直连道路供出征、调动及AI共用；北段复用原有道路，仅画入成都的分支。地图将四川盆地内5组原有山体逐组平移到盆地边缘，不增加山体，河流、原有道路和城池位置保持不变。v6的成都、广汉地形同步改为平地，周边山地城保留山地。旧存档保留原资源、收入和地形；仅含新边的v6目录显示新增道路。

地图源场景、移动蒙版和路径在`config/city-map-refinement.json`；原图`assets/map.png`、上一版`assets/map-clean.png`保留，新图为`assets/map-basin.png`。需要重新渲染地形时，在已有Playwright和Chrome的环境运行`node game/render_city_map.cjs`；运行游戏不需要这些绘图依赖。

## 剧本

默认217年7月。选择页按原版本篇7个、威力加强版本篇4个分组，显示本剧本实际开局在籍和在野人数。11个年代均可选择势力开局；详见[剧本清单和配置边界](../docs/web-main-scenarios.md)。DLC、购买特典、假想剧本和称霸战记不属于本次本篇范围。

官方资料确认的是剧本名称、年月和事件背景。地图疆界、驻城、开局资源及新增年代的人事安排是本作独立改编，尚非《三国志14》原始开局数据的完整导入。人物库会显示“本作转属复核”“前后快照归属一致（推定）”或“归属待考”；未确认者不会自动入场。

## 开始一场战斗

1. 选择“217年7月 · 汉中争夺战”和刘备势力，开始战役。
2. 用城池下拉框定位阆中（原巴西），在“编兵”将张飞调整为999兵、法正调整为600兵。
3. “出征”选择汉中，勾选张飞、法正、马忠，经过确认页再出征。
4. 选择部队和敌军，使用攻击、计略或挑战单挑。对手可以拒绝；接受后操作突击、防守、佯攻或退出。
5. “接收战果”结算名册、兵员、经验和城池归属。
6. “结束回合”后“执行电脑行动”。遭到攻击时由玩家操作守军；接收战果后继续电脑队列，全部完成才推进一个月。

点击地图城标或使用下拉框查看城池，“本城/全图”切换视角。只有当前选中城显示方框，有主城用城标内部及下方小色条标识势力，无主城为白色空城标。

## 人物与玩法

总库1000个独立人物条目现已属性齐全。本次保留269份已有配置，新增16人的史料参考德评分；其余715人按用户指示暂设德60，并单独标明“默认值”。合计284人参考史料评分、715人默认60、1人保留原作基线。既有武、知、体力、适性和个人身份保留；本次731人的体力80、平地适性0仍是初始化默认。人物库支持按评分来源筛选、检查依据。详见[德值配置与各年代开局人数](../docs/virtue-completion.md)。属性齐全不等于当年登场，仍按年表、归属、驻城及容量筛选。

- 招募：访问本城或相邻本方/中立城的在野人物，每次60金且消耗本城行动，可能拒绝。满城在扣钱、抽签前拒绝。
- 劝降：相邻敌城非君主武将，每次100金。成功后保留体力、兵力、装备及经验，忠诚按本作规则结算。
- 调动：沿本方连通道路，每人每段5粮。本回合处理过人事/调动者不能连续操作或立即出征。
- 年代：出生、出仕、死亡分别判断；未来人物必须属性、位置齐全才以在野出现，不强制按历史改投。卒年月份未知者在次年清理，已有退场人物不复活。
- 战斗：16计略含成功判定、气力与结算；单挑体力降至1时负伤败退。战后守军退往有空位的相邻本方城，否则转在野，兵员入城预备兵。
- AI：招募、劝降、补兵、调动、邻城出征及简化继承。电脑攻城暂停并交给玩家操作守军，回执防止重复结算与推进月份。

战斗、人事和AI使用本重制版规则，详见[战役规则](../docs/remake-campaign-rules.md)。当前没有单位逐格移动、完整外交、复杂亲族继承或完整历史事件链；不声称还原原机全部算法。

## 存取与离线重建

“保存进度”写入浏览器本机副本并下载JSON；“读取进度”可读本机副本或文件，支持战斗、单挑和电脑回合进度。数据身份与哈希匹配后才载入，失败保留当前进度。50份目录（当前v6的11份、已发布旧版39份）各自校验，不能修改旧目录或绕过校验迁移存档。已有进度不会自动切换到v6；使用新资源及阴平直连道路需新开当前版本战役。

```sh
PYTHONDONTWRITEBYTECODE=1 python3 game/build_mainland.py
PYTHONDONTWRITEBYTECODE=1 python3 game/build_eras.py
PYTHONDONTWRITEBYTECODE=1 python3 game/build_campaigns.py
PYTHONDONTWRITEBYTECODE=1 python3 game/build_map_anchors.py
PYTHONDONTWRITEBYTECODE=1 python3 game/build_map_presentation.py
PYTHONDONTWRITEBYTECODE=1 python3 game/build_main_scenarios.py
PYTHONDONTWRITEBYTECODE=1 python3 game/build_virtue_completion.py
PYTHONDONTWRITEBYTECODE=1 python3 game/build_city_campaigns.py
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -p 'test_remake_*.py' -v
```

重建只读仓库名单、数值与配置；运行只读取独立剧本JSON和Web静态资源。新剧本规格在`config/main-scenarios.json`，单独复核人事使用稳定`person_id`，包括同名的吴、蜀两位马忠，不能只按姓名连接。
