# 界面依据

主界面概念为`concept.png`，由内置图像工具生成，参考现有已定稿的v42像素地图。地图原图在`assets/map.png`逐字节复用，未重画地形或城标。

实际提交的完整提示词保存于`prompt.txt`。概念输出原生尺寸1536×1024，已用同尺寸浏览器截图作对照。

生成要求：1536×1024横屏的中国三国策略界面；纸色底、棕色墨线、方角；顶部标题/年月/存取按钮；左侧地图与荆襄/全图切换，右侧城名/资源/武将表/编兵/出征/结束回合；底部战报。没有营销区、肖像或装饰图标。所有文字、按钮与数据由真实HTML渲染。

风格变量：底色`#f3e6ce`、文字`#35291f`、主按钮`#5c402c`、边线`#8b7158`。标题宋体、正文与表单使用系统中文字体；主体为地图、平直表格及命令区域。桌面保持双列，窄屏上下排列。

必要的功能扩展：选势力、编兵、出征确认、双方部队与攻击/退却、战果、电脑回合、存档错误。战斗用有姓名和兵力的可选部队列表，这是功能控件而非替代美术的角色精灵。概念中的示例数字由实际状态替换，源地图中的图例保持原样。与概念的对照记录放在验收证据中。
