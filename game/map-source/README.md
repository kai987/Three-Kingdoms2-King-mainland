# 地形渲染来源

`valley-ground.png`复用此前地图v34的`river-valley-ground-fill-v34.png`，SHA-256为`c92c170d35c4bc0e17ec1bd4ae4bdb0cd9cbfbb96504486f1b95e43a1ce13d86`。它只用于填补山体移走后的原有轮廓，不作为整张底图覆盖。游戏服务器不开放此源文件。

`../render_city_map.cjs`读取仓库内v42的原地图场景和v41地形，按`../config/city-map-refinement.json`的2像素网格蒙版平移5组山体。每个run为`[y,x,格数]`，坐标使用裁剪后地图；原地形取样时加上`mapCropX=136`。山体RGBA像素完整复制，不缩放、不重绘、不新增。渲染时核对10,812个源像素与目标像素，检查蒙版外像素及原有河道、道路、城标SVG均未变化。

新道路以运行时SVG叠加，只有目录含阴平—成都边时显示。原有北段道路复用，避免重复绘制。城市命名、资源配置与地图地形源文件相互独立；修改地形不应改写已发布战役目录。
