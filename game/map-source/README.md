# 地形與道路渲染來源

目前使用已確認的 1352×1024 原風格底圖，五張既有 PNG 的雜湊固定在 `../config/map-source.json`。`../build_map_presentation.py` 驗證底圖及原版城標遮罩，再產生 `../assets/map-presentation.json`；不依賴已移出的歷史開發頁面或工具。城池名稱、地形外觀及戰役資源各自處理。

成都西側三座山只調整顏色。`presentation.mountain_recolors` 記錄三組原圖綠色山面及向外 6 像素內綠色輪廓的逐行遮罩，共 5,071 像素，補齊原先漏出的綠色山緣；前端以裁切的 SVG 色彩矩陣映射為棕橙色。原山體輪廓、黑色陰影、位置和全部底圖 PNG 均不修改，河道、道路、城標及遮罩外像素沿用原圖。整張生成參考圖未替換進遊戲。

道路以執行時 SVG 疊加。`../config/route-corridors.json` 統一襄平、樂浪、山陰原有港口接道及牂牁山道；`../build_navigation_geometry.cjs` 產生導航線形，`../build_campaigns.py` 再輸出各劇本。海港接道沿既有折線繪製，避免曲線與底圖產生第二條平行路。共用路段只畫一次。道路明列的頂點若在城標中心 3 像素內，僅校正該頂點；經過城池的曲線在中心分段，避免把城池當作偏離曲線的控制點。沒有明列節點的鄰近城池不會自動增加連線。

`valley-ground.png` 為早期移山處理保留的來源，SHA-256 為 `c92c170d35c4bc0e17ec1bd4ae4bdb0cd9cbfbb96504486f1b95e43a1ce13d86`；目前不作整張地圖覆蓋，遊戲伺服器亦不開放此來源檔案。
