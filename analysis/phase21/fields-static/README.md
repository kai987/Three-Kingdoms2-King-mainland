## 对阶段 20 的明确纠正

`superseding-erratum.json` 纠正阶段 20 将 E89A 的中间 `LDX $0054` 当作净返回 X 改变的判断。原固定银行 31 `$E89A..$E8A9` 为：

```asm
STX $0053
LDX $0054
LDA $E8BA,X
INC $0054
LDX $0053
RTS
```

原例程曾写 X，但完整普通 RTS 将 X 恢复为输入值。`register_may_write` 描述执行期间可能发生的写，不能代替返回输入输出关系。阶段 20 冻结文件原样保留，此目录的纠正文件给出原文件路径、SHA256 与全部原字节。

新等值分析从任意调用输入 A/X/Y 和未知内存开始，分别跟踪寄存器输入符号、零页暂存以及 PHA/PLA。部分写、绝对索引的全部 0..255、16 位回绕、RAM 镜像、未知间接写、栈镜像写和不兼容前驱合并都会使相关保存值失效。仅接受无调用、无未知控制出口且所有已声明局部 RTS 都满足的返回关系。本轮得到 274 个合同，其中 8 个包含“执行中曾写，返回时恢复”的寄存器。

这些是正常返回合同，不是中断原子性证明。外部代码若在 `STX $0053` 后、`LDX $0053` 前修改 `$0053`，返回 X 可以改变；验证器保留明确反例，但该反例不是一次观测到的原 NMI。原核心中的实际中断行为需引用独立 Native/中断证据。

## 237 条武将招募扫描

`bounded-recruitment-contract.json` 给出物理银行 11 `$C71A..$C76D` 的完整原指令、外部入边和 callee 依赖：

- `$C71A` 初始化 `$22/$23=$63C0`，`X=0`。
- `$C66F` 与 `$E89A` 普通返回保存 X，且不写 `$22/$23`。
- `$C752..$C75D` 完整进位地将 16 位指针加 12；随后 `INX / CPX #$ED / BCC` 只让 X=0..236 继续下一条记录。
- 成功分支离开扫描；可信 CFG 没有跳过初始化而进入该扫描体的外部入边或已知子程序入口。

因此 `$C726`、`$C73F`、`$C767`、`$C76D` 分别读取/写入 237 条原武将记录的 `+11/+5/+11/+11`，不触及城市辅助字节。这一结论限定为初始化入口开始的普通无中断执行，不能套给任意中途 PC 或外部改写。

该例程检查武将状态低两位为 0、byte5 为本城或八个邻城之一，成功写状态低两位 2，之后往城池首个 FF 槽追加 ID；属于在野武将招募，不能称 HP 维护。后面的 `$C778/$C77F` 首 FF 城池名单扫描仍未给出上限，继续保留潜在尾字节和跨记录别名。实际 `+1/+2` 错位合字阈值、整块初始化、名单越界访问等历史证据也没有被删除或正式重命名。

## 直接与绝对索引访问补盘点

`direct-indexed-accesses.json` 完整列出可信控制图内 19,174 条普通零页/直接/绝对索引读写，绝对索引采用原始 0..255 与 16 位回绕。它们的地址域没有一条命中 30 城的 `+1/+28..31`。这仅是这 48,754 条已证指令的结论。

`untrusted-PRG-opcode-windows.json` 另对全部 32 个 8 KiB PRG 银行的 262,080 个银行内三字节窗口作已列明的合法 6502 绝对内存 opcode 盘点，得到 345 个可能碰到辅助字节的原始窗口。它们全部不在本可信指令集合，可能是数据、内联表或尚未证明的代码；假设 CPU 映射与原字节单列，不能当作实际读写者。银行边界跨三字节窗口、非法 opcode 和间接操作不属于这张 raw 表。两类清单不能混合成全 ROM 字段未使用证明。
