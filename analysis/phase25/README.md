## 为什么选择G033

[比较记录](fields-static/selection-comparison.json)保留两条链的入口、mapper、指针写入、竞争解释和证据成本。G033已有自然母档，位于阶段22实际月度AI登场之前，普通空闲输入即可短程重现。G107旧handoff点可能已过初始化，独立CPU续行未命中不能证明部署代码不可达；需要从更早存档和原输入重新进入。

两条链此前都有具名源码。本轮不再次声称首次恢复C5D2登场算法，也没有并发实现G107。新增源码是D471的精确可读8×8乘法及其实际caller、指针与映射合同；调查和验证的主要新增价值是即时现场证据。

第4帧末22/23已变成`8B6C`，属于下一城4的复用。此前无新NMI的独立CPU探测能进入城市3读表，却没有得到同一录用概率结果；它是另一证据域，不能冒充Native成功的逐帧复现。即时链见[原机观察](runtime/natural-appearance-pointer/opcode-observations.json)。
