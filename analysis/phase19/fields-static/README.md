## 关系域与原字节合同

阶段18分别合并低字节和高字节，再取笛卡尔积，会制造不存在的完整指针。例如 `25:$B54F` 从 `$10/$11` 读取武将：其来源 `25:$B4CA JSR $F2D7` 原子产生 `$63C0 + 12*A`，随后完整复制。旧独立字节集合可拼出 `$631C` 等城市尾部地址；真正完整地址最低是 `$63C0`，即使原Y未知取全0..255，也不会向下进入城市记录区。

新分析仅在原子工厂调用、经证明的工厂直线前缀、完整字节复制或原分派协议建立配对。配对保存的是完整16位地址的集合。合流要求每个前驱都保留该配对，然后合并完整地址；不会交叉拼接其高低字节。

任何可能覆盖一个字节的写入，都会删除该配对，并清掉所有寄存器、PHA跟踪栈及未完成复制中引用它的半字节能力。此后即使同一PC再次调用同一工厂，也不能把上一次的低字节与这一次的高字节拼接。完整复制到另一位置的旧指针可独立继续存在。

写入检查包含零页、绝对寻址、索引0..255、16位回绕、`$0800/$1000/$1800` RAM镜像，以及未知间接写入。普通未知callee按冻结的保守may-write集合失效；不宣称其真实返回或终止。无调用叶子只有在所有本地控制出口可核、输入指针不被写、全部间接写均不可能触及零页时，才使用带输入完整地址集合的条件合同。有PHA/PLA/PLP/TXS或潜在栈写时，不保留调用者的半指针栈能力。

共有14个显式工厂合同，涵盖 `$F2AF/$F2D7/$F308/$F368/$F387`、bank8 `$B469/$B491/$B4C2/$B4E1`、bank11 `$D105/$D283/$D2AB/$D304/$D319`。所有工厂保留原A的0..255输入；君主表保留全部0..15原始索引，包含越过通常七项的邻接原字节。没有把合法角色数当作未经证明的索引限制。

本域一次工作表收敛，处理63,757次原指令状态传递；这只表示**本限定关系域与冻结callee/index合同**的固定点，不是全ROM、全寄存器或中断交错语义的固定点。一般函数返回的完整指针对摘要、指针算术、未知 `$8000` 映射及未解析入口仍保守退回。全部48754条校正CFG原指令都按含16字节NES头的file offset核对。

1125项排除中，1046项由本轮完整指针对直接支持，79项仅沿用阶段18的独立域证明。沿用证明保留其原前置条件；新的较宽关系域未知或仍相交，并不能推翻旧的较窄可靠证明。每项输出明确 `proof_basis`。

## 原机标签的新联接

[原始输送画面](../runtime/resource-transfer-baseline/transfer-gold-after-up.png)清楚显示左侧“金／米／宝”，三个数量输入标为“キン／コメ／タカラ”。[联接证据](city16-original-UI-link.json)保存原图SHA、标签区域与实际RAM/SRAM字节：源城市11和目的城市14的 `+16` 均为99；目的城已满，第三数量上限为0。

原代码 `25:$B8F7..B8FB` 把城市 `+16` 放入第三数量缓存 `$049C`；`25:$B937..B963` 将其限制为 `min(源数量,99−目的数量)`；`27:$B933..B96D` 选择第三输入并保存到 `$0432`；`27:$B9AC..B9B4/$B9D8..B9E0` 分别减源城和加目的城的 `+16`。因此这次名称确认有实际标签与专用数据链，不能再用旧的“命令点”推测代替。

原机案例是已披露的受控实验：导入自然母档，仅把目的城金从9999准备为9899，其余菜单与提交由原代码、普通手柄推进。本静态证据没有修改旧Native回执中的保守转写，也没有声称该画面捕获过第三数量非零转移。
