## 逻辑有效地址与总线虚读

本路线目标城市字节共有25次实际总线访问：22次 `10:BD97` 专用读取、1次 `13:D243` STA虚读、2次 `11:C73F` LDA跨页虚读，没有目标写入。原始事件逐条关联全部1526条指令位置与旧376条候选，没有删除看似冲突的命中，也没有用未命中增加排除。

新发现的C73F案例为：原指针63FC加Y5，真正有效地址为6401，即ID5武将记录的所在地；原CPU寻址时先读6301，恰好是城24的+1，然后才读6401。冻结官方 `Cpu::IndY_R` 明确包含这次跨页虚读。D243的 `STA ($00),Y` 同样具有原寻址虚读，观察ABI不记录00/01，因此没有为它虚构指针00数值。

所以，C73F/D243的**逻辑有效地址不相交**与实际**虚读总线命中**可以同时成立。新1526项逻辑／dummy合同分别列明这两种地址域；逻辑不交中有13个位置仍可能通过dummy命中目标。有限dummy公式检查不计作原CPU或Native执行。[25条原始解释](access-runtime/actual-city-bus-semantics.json) · [关联回执](access-runtime/verification.json) · [逻辑／dummy合同](fields-static/logical-vs-dummy-bus-contracts.json)
