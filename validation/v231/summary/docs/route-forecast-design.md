# 公开季节正常值和跨月路线预报

公开正常值来自游戏 V2.3 逐日天气模拟。每种寒潮设定各用 1,000 个独立训练种子，按区域、物理河段和 36 个旬段保存联合分布。分布记录雪强与道路积雪的共现，以及各河段冰情。每旬规模归一化成 10,000 个整数份额。保留的正常值样本使用不重叠种子。

额外严寒样本从 500000 起，覆盖最敏感的金城往朔方单向路线及辽东四月地表积雪。特意选取结冰时段，这组误差须和一般路线的保留样本分列。

从当前可见日期、雪深、冷度、降雪与河段冰情启动，短期影响衰减到公开正常值。4 月正常降雪概率为零的地区仍可能有前月积雪。每段的抵达日期接着用于下一段与返程。当前封冻仍由实际状态判断。预计解冻只影响未来报价。

时间拆成平时天数、可见天气增量、公开季节增量和预计冰封等待。口粮权重分为基础、可见天气、季节和等待。预计净到货取预测路线货损。保守报价和点估计分别计算，界面显示两项日数。AI 安全余量在各计划环节原有位置处理，实物发运依旧通过逐笔验证。

只读缓存以物理分段工作量、方向、日期、估计起点、当前区域可见状态、河段冰情及气候开关为键。实际天气改变后的新报价生成新键。预报不访问未来实际天气抽取。
