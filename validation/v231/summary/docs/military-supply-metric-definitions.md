# 冬季军粮口径

冬季为 11 月至翌年 3 月。需求发生日期、运队发运日期和实际回执日期分别归类。回执同时保留来源、入账日、实收量与计入该需求的粮量。

## 数量口径

按军队和顺序编号建立连续需求段。重复估算只补记超过未解决余额的新增粮。实收按需求余额入账，候选路线数量不会扩大分母。

数量及时率等于按当时需求期限计入的及时实收粮除以实际申请粮。报告对每局执行 V3.0.x 使用的原统计函数，核对申请、及时、迟到三项合计。V2.3 逐日天气会影响实际行军和预计缺口。首次需求期限、更新后的需求期限和首次实际断粮分别保留。报表另按首次期限审计。期末余额按未满足或目标变化取消归类，同时保留旧口径的合计。

## 运单口径

实际成功发运的军粮运输按运队 ID 去重。冬季发运并到原承诺期限的运队构成分母，在原期限收到正数军粮的运队构成分子。迟到、未收、在途、取消分别保留。新运单同时关联原需求 ID 和原需求截止日。

计划记录已知可靠在途粮与未覆盖粮。计划与报价的记录不累加到实际申请粮。没有需求和没有到期运单分别显示空比率。小样本保留实际分子和分母。
