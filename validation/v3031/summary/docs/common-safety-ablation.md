# 共通安全规则消融

D0 使用原默认运输规则，D1 在 303 下明确关闭物理容量、有限并发、同旬双发、AI 路线方针和周转排序。版本仍启用原有 303 共通保护，包括当旬发运计数、人员资格、留守判断和来源库存保护。D2 在 D1 上只开启有限并发，并启用按势力和来源城计数的语义。

D0 → D1 在相同固定期限的实收从 127,600 降至 126,600，足额目标仍为 33。长期差异随场景改变。黄巾策略 211 的累计缺口从 557,913 到 387,568；赤壁策略 211 从 392,075 到 780,525。D1 相对 D0 合计 16 个逐指标红线。共通规则本身就能改变长期轨迹。
