# 已知问题

## 调配竞争

长沙真实回放中，D2 原调度缺口 549 粮，30411 和 30412 均为 1,886 粮。原调度在第 269 旬前收到柴桑 2,564 粮、南郡 1,442 粮。柴桑的普通自动运输设置为关闭，粮仓报价是独立渠道。30412 在第 267 旬发现了南郡到长沙的合法报价，南郡同旬实际发运给武陵并在第 268 旬送达 5,350 粮。单旬一次实际发运的约束仍生效。第 269 旬零陵发运，粮食在第 271 旬入长沙仓库，晚于这次扣粮。

扶风新出现的较大需求伴随 10,000 现役兵进城。此处保留为战局分歧和欠粮实例，单独和 30411 对照。与 D0 原规则配对时，原归属已发生改变。

## 交通网络

巴东依然受实体距离限制。建安开局检查点的合法来源不足。增加独立交通节点、港口或渡口属于后续交通设施开发。

## 粮道安全

运输队所在地易主后，原有补给和城池接收许可可能同时失效。只有能合法到达、满足随行口粮并可接收人员的返程方案可以执行。3634 与 1860 的完整粮道安全问题继续列入下一阶段的专项。
