# V3.0.4.2 准入

运输调度已完成固定专项和 24 个月配对。正式经济候选的准入止于 24 个月。交通设施节点可以在独立实验中研究，基准须同时保留原调度及选用的候选配置。

## 运输和资源竞争

长期供养与军事补给仍有明显退化。玄菟首笔缺口的同状态对照确认市场库存为零、国内城没有合格押运人选。魏灭蜀 211 的多笔军粮没有合法会合路线或押运，实际补给有迟到和数量不足。柴桑的自动运输设置以及南郡的单旬发运冲突需要在继续分析中留作真实条件。

## 交通设施

巴东实体运输距离以及建安的现有合法来源不足属于交通网络限制。独立节点等设施可以单独实验，成效仍由实际消费、实际到货与来源安全证明。

## 粮道安全

真实易主后的 3634 和始终无合法退出的 1860 留给 V3.0.5。前者在候选自然战局中实际归队；在同一危险状态下仍受接收权限及随身粮限制。
