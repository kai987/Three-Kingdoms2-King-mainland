# 存档与实验开关

默认新战役使用既有调度规则。开启 30412 时，存档保存 `transport_coordination_rules_version = 30412`。三个实验版本在开局表单上互斥，运输容量、中转、市场和气候各自设置。旧档按自身规则号、保存的承诺、未完成运队和命令书记录继续运行。

30412 延续候选分页、来源多样性、合法报价重算、来源储备保护、军事准备分类、途中口粮协调、非紧急运输筛选及增量经济计划。另有 `meal_priority` 和 `route_reuse` 实验开关。路线缓存只保存在当次调度内，因此在回合阶段暂停、保存和恢复后必须由实际状态重新生成。

D2 精确回放的 `transport_capacity_rules_version` 为 303。仅开启 `concurrency`。实体容量、按模式调整 AI、吞吐排序和每旬双发均关闭。游戏中原来的 303 开局选项仍按其原设置运行。

Python 与 Rust 使用同一存档校验和游戏状态。专项测试覆盖普通与紧凑存档的跨后端读回、既有版本、可单独关闭的开关、真实补给和观测前后的存档一致性。浏览器同时验证繁体中文、日文、桌面及触控布局。
