# V3.0.5 粮道安全证据

旧检查点覆盖的 14 支运队为 126、1685、77、2、45、1706、1723、1902、2095、2170、1228、219、1860、3634。八支具有可重放存档，另外六支依照原始历史证据单列。

优先处理城市易主发生在两次运队检查之间的情况。专项应区分非法接收、能找到路线但尚欠实际返程口粮、没有合法救济会合点，以及没有可执行绕路。已有真实库存、人员和回程收据须保留。

1860 在已观察窗口长期找不到可执行的补粮及撤离。3634 需在同一真实的易主后状态继续核对返程短缺和合法救济。新验证继续用第 715 旬已抵达原城的危险状态以及自然战局的独立轨迹。
