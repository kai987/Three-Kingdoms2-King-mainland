# 押运人员资格

资格直接使用已有的战略调粮预筛选。按来源城看，先判断有无在途任务、同旬是否发运及政策上限。进一步核查真实驻城、最低留守人数、君主、任命、既定出征名单、体力、交接冷却和当旬行动。候选人员按现有带兵数及稳定 ID 排序。

`escort-eligibility-breakdown.csv` 分别统计来源城评估和被排除人员原因。一个来源评估可对应多个目标，走法也可能产生多条候选拒绝。`duplicate-candidate-analysis.csv` 的旧数据只有这些拒绝标记。`escort-source-turns.csv` 给出每旬去重来源数。`escort-persistence-by-city.csv` 按所属势力和城池统计连续观测到无合资格人员的旬数，缺采或出现其他结果会中断连续计数。正文用至少三旬表示持续缺人。

现有地方文吏在正常城池名册且符合权限时随相同代码检查。允许调动现有武将能实际缓解多少城市尚待另外做人员调动的成对验证。固定点有余粮和合格人员但被返程任务占用的情形见 `source-task-blockers.csv`。旧流水无法还原解除限制可多送达的实际粮量。
