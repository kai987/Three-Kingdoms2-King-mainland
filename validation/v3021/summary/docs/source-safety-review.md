# 来源城安全

发运失败可以来自来源无足够真实余粮、已在运输、保护用的兵粮、没有可用押运人员、退路不通或目标期限。九旬表维持历史口径，按缺粮城旬去重后核对黄巾 25 次、赤壁 28 次。另以单笔发运时间为锚，追踪权属相同的后续三个扣粮旬。一个事件可能有多个标记。

只有在发运时同一个已知的硬支出或承诺被漏掉并能复放时，才可确定为预算导致。条件性储备释放保留当地政策、固定应付粮、未来已知支出、防御和返程口粮。在途状态发生变化后再次验证。逐笔发运见 `source-shortage-causality.csv`。实际粮仓支出、兵力流动和归属变化见 `source-shortage-nine-turn-window.csv`。

九旬样本的 53 次均有兵力流水，其中黄巾 4 次、赤壁 7 次的账期还记录到归属变化。所有用途共用同一来源城任务限制。运队交付货物后仍需返程，直到真正接收才释放这一占用。
