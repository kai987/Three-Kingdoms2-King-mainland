# 验收结论与证据

## 原调度与需求竞用

原有普通调粮、战略粮仓、区域采购与军事筹粮在首次内政、城市行动及自动委任阶段竞争。影子组共有 176 条建议，其中 34 条在同势力同旬使用的来源上遇到旧任务。5 条的目标不同且押运者重合，其中紧急建议 0 条。这些记录确认共同资源被使用。是否因此错过实际期限还需在当时的状态比较替代来源。 [竞争记录](../data/transport-shadow-comparison.csv)

需求去重按同一城市九旬缺口回算，军队与运队采用独立目标。原调度缺少同口径需求段，因此仅对统一账内的重复凭证与真实交割做核对。

执行组观察到原期限已经经过的紧急需求段 4,357 个，其中 1,288 个有完整及时报价，45 个当时有报价但期限内未发运或购粮。按各需求段首次实际缺口折顶归属的及时粮为 1,357,894。各需求的报价共用资源，该统计以逐段实际回执为准。 [调度对账汇总](../data/coordination-safety-totals.csv)
