# V3.0.4 城池水陆接驳原型

V3.0.4-A 使用现有真实城池完成集货、入仓、合并水运和分批陆运。中转需在开局菜单主动选用。实验固定剧本、种子、开局状态及其余货运开关，E0 关闭中转，E1 启用中转。

| 项目 | E0 直运 | E1 城池中转 |
|---|---:|---:|
| 实际终点收粮 | 88,175 | 86,102 |
| 末批入账日 | 40 | 90 |
| 命令书 | 2 | 5 |
| 途中及等待口粮 | 2,965 | 2,621 |
| 路线及天气途耗 | 9,448 | 11,519 |
| 押运武将日（含行动冷却） | 180 | 280 |
| 每押运武将日净到粮 | 489.86 | 307.51 |
| 每本命令书净到粮 | 44,087.50 | 17,220.40 |

同一受控初态下，本例应继续选直运。城池接驳发挥了纯河运单次大容量，最终到货量、军官效率及命令书效率均低于直运。独立水陆接入点与 AI 中转的阶段结论见 [正式准入](v304-formal-readiness.md)。

将同一受控世界的目标提前到纯河运终点苍梧，两段中转实收 90,688 粮，较两队直运的 89,921 多 767 粮。末批从第 30 天延后到第 50 天，命令书从 2 本增至 3 本，单位武将和单位命令书效率仍低于直运。
