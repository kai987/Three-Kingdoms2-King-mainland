# 九旬預測與備糧

路線季節估計和實際降雪使用同一份區域月表與寒冷常態。W1 只更換月度事件機率並沿用 221 的季節權重方式。W2 起採用事件長度及各級分布估計實際日曝露，另估無雪日可能持續的地面積雪。短期冰情只讀已可見的物理河段狀態。不同季節估計與實際到達時間可以不同。

九旬收支沿用同一 `monthly_income` 日期。已凍結的月份進入基準收入。觀測中的月份仍按正常產量列在基準帳。W4 額外以已發生的厚雪與異常低溫，以及凍結後的地區門檻，估計一條較低的產糧路徑。只有這條路徑形成額外缺口時才列入備糧候選，最高為當地一個月既有固定費用。

正式缺口仍最先處理。備糧需滿足原有來源餘糧、守備、金錢、合法路線、現有命令書、押運和到達期限。既有戰略糧倉或地區市場可提交實際的調糧和購糧命令，事件記錄只計已實際簽發的運輸。此處讀取已發生的天氣及公開分布，沒有讀取未來日期的天氣樣本。
