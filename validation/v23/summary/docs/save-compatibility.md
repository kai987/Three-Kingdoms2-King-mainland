# 確定性與存讀

| 天氣版本 | 規則 |
|---|---|
| 0 或省略 | 當前正式預設 |
| 22 | 原版天氣 |
| 221 | 原修正版天氣與後勤應對 |
| 23 | V2.3 候選，另有各項實驗開關 |

共用降雪、強度、長度和開始日期的獨立雜湊欄位。原版保留種子與時間。V2.3 的春霜、晚雪、江南寒潮另有欄位。觀測器讀取日結提交後的值，重讀和重播已處理的日不會結算兩次。

V2.3 常規與緊湊存檔保留實驗設定、當前天氣與冰情、區域年度觀測、凍結狀態和已入帳月份。只在緊湊 V2.3 的復原頭列出 23，原版復原頭沒有新欄位。冰情與天氣的日鐘是戰役旬鐘的從屬值，讀檔會先依原有摘要和校驗碼規則驗證，再比對區域與年度範圍。

正式驗收以兩個執行版本在相同起始狀態下的普通及緊湊存檔、隨機狀態、天氣逐日指紋和真實行軍記錄核對。找不到或原本就不再符合目錄摘要的歷史檔案，須在報告按實際結果列示。
