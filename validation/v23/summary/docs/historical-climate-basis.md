# 歷史氣候依據

- 黃初六年（225），曹丕至廣陵故城臨江，載有嚴寒、水道結冰及船不能入江。這提供江淮偶發冰情的歷史例證。[《三國志》卷二〈文帝紀〉](https://zh.wikisource.org/wiki/三國志/卷02)
- 嘉禾三年（234）九月有霜害穀物。赤烏四年（241）正月又載有南方異常大雪。季節照原書紀年表述，未將其直接換作遊戲月曆中的概率。[《宋書》卷三十三〈五行四〉](https://www.shidianguji.com/zh/book/HY3001/chapter/1kr3pjref6jo3) · [《三國志》卷四十七〈吳主傳〉](https://zh.wikisource.org/wiki/三國志/卷47)
- 東晉咸康初的慕容皝記載涉及昌黎至平郭沿海冰況。其地點與活動晚於三國，是遼東附近冬季寒冷的補充例證。海冰行軍屬另一套機制。[《晉書》卷一百九〈慕容皝載記〉](https://zh.wikisource.org/wiki/晉書/卷109)
- 東部中國的冬半年溫度重建以數十年為解析度。古代災異記載和重建曲線可支持冷暖與風險差異，無法提供三國各郡每旬降雪實測值。[Ge 等人的冬半年溫度研究](https://journals.sagepub.com/doi/10.1191/0959683603hl680rr)

區域機率、積雪上限和農業乘數屬遊戲候選。遼東濕冷、西北乾冷、秦嶺高地及南方低地的差異在同一套抽象尺度上調校。冬季的溫度、降雪頻率與積雪持續時間分開計算。
