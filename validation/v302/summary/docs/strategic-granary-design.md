# 粮仓与九旬预测

## 粮食归属

官仓总粮包含战略储备。普通可动用粮等于官仓总粮减战略储备、尚未发运的调粮承诺和已锁定的行军粮。商品粮留在 V3.0.1 市场账。发运时来源城官仓支付货粮和独立口粮，部队到达后按可信接收凭证入账。预留、释放、城市易主和读档都按实际库存复核。

本地居民、驻军、已出发部队和当前紧急需求可以使用原有官仓资源。当实付导致储备超过剩余粮时，系统按实际差额释放储备，并登记原因。应急返程接济仍须保留本地下一旬应付粮及可兑现的行军承诺。贸易和战略调粮检查受保护的粮食。

## 九旬预测

沿用势力的九旬逐旬结算表。计算当前库存减未支付承诺、各旬预计粮食生产和固定支出，以及拥有可验证路径和到货时间的运队净货。月末仍按游戏顺序入账并消耗。相同旬的运队要在该旬口粮结算后才能提供存粮。未来日期超出九旬的货粮只保留在在途凭证中。

预测显示首次缺粮旬、九旬累计缺口、预计期末粮食、预计可靠入账和具有风险的货粮。订单仍在预留时，来源账锁定对应粮食。预测只考虑已发车队向目标城的实际路线和货量。读取时间表、重复取得报价和对比路网不推进战役日期及随机数。

前线依据当前连接、敌军来向和城池归属变化。农业城以当期产粮与固定开支的净额识别。后方输出、枢纽、冬季风险和紧急缺粮属于可重叠属性。储备目标取九旬内本地累计支出超过生产的最大差额与驻军／平民／薪粮的基础月数较大值，再计入已知的冬季压力和近期实际风险。

## 实验参数

参数集中在 `source/remake/strategic_granary.py` 的 `RULES`。默认均属于 302 实验。

| 项目 | 默认 | 作用与依据 |
| --- | ---: | --- |
| 后方基础储备月数 | 1 | 在保留当月自用的前提下外运后方余粮 |
| 前线基础储备月数 | 2 | 留出短期军调和临时供给压力的空间 |
| 预留的有效期 | 3 旬 | 防止未发运承诺长期占用实际官仓 |
| 最低主动货粮 | 150 | 减少只为填补小额缺口的命令和武将占用 |
| 最大备粮／预计净货比例 | 45% | 主动调拨的初始经济门槛，手动报价继续显示相应成本 |
| 冬季安全时间 | 5 日 | 提前调拨需留出一次短期道路延误余量 |
| 冬季附加储备上限 | 1 个月 | 按实际每月粮费及区域气候计算 |
| 寒冷地区启用积雪概率 | 20% | 使用公开气候常态，另考虑对应月份的结冰压力 |
| 中转枢纽／目标上限 | 3／3 | 限制单轮组合及参与报价的城市数 |
| 已结案历史 | 96 单 | 保存近期回执，所有活动订单继续持久化 |

逻辑仓容结合现有官仓物理上限、现有储粮预算、町等级、有效产粮和实际驻军需求。提升町等级仍走原有建设命令及费用。V3.0.2 保留独立仓房建设费、仓储损失和维护费供后续另行验证。
