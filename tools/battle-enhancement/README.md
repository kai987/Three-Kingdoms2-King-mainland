# 四倍戰鬥畫面與單挑裝束素材

畫布實際尺寸為1024×960，版面仍用原256×240的座標與顯示比例。原有背景、步兵、騎兵和單挑素材保持原檔，使用Scale2x兩次產生四倍像素邊緣版本；這不表示原圖中憑空出現新的寫實細節。字體、128×160肖像與新繪單挑騎將直接畫進四倍畫布。

普通攻擊的完整左右兵陣使用精確最近鄰4倍放大：原128×160透明層成為512×640，每個原像素對應同色同透明度的4×4方塊。兩個姿勢均直接取自原畫面，沒有新增AI繪製的士兵，也不套用單挑騎將的重繪方法。原始尺寸、來源圖、工具及像素雜湊在manifest中保留；`native_nearest4x`與原有的`native_scale4x`明確區分。

內置imagegen依原騎將製作9種兵器、各兩個完整騎乘姿勢的透明像素圖。生成圖與精確提示詞保存在`art/battle-enhancement-v1/studies`與`prompts`；每張兩姿勢原圖保留不覆寫。打包器以透明區隔的連通島辨認兩名騎將，即使長兵器與另一姿勢的馬尾在水平方向交錯，也保留完整人物、兵器和馬匹，等比例放入384×384，保留透明背景並量化為有限色階。下部暖棕色馬身區域以連通色塊遮罩製作棗紅、白、黑、赤兔、的盧等五款毛色；的盧的白色呈現屬於美術設定，並非小說對毛色的考證。

## 八動作圖集

第二版來源位於`art/battle-enhancement-v2/studies`與`prompts`，另外繪製12種兵器的八個動作：待機、突擊、防守、佯攻、撤離、捨命一擊姿勢、受擊與敗退。圖集提供演出素材，不代表遊戲規則已新增同名指令；真正播放的動作仍由已結算的命令與招式決定。

原有90張兩姿勢PNG與九張第一版來源均保留。新來源採兩欄四列的透明分格；工具亦能按橫向來源的四欄兩列版面處理。分格僅決定動作順序，實際以八個完整騎將的連通主島及最近的零碎附件分離人物，兵器、箭矢或馬尾即使跨過分格線也不會遭裁斷或混入旁邊人物。manifest逐張記錄來源分格與實際完整範圍。所有動作使用同一縮放比例，完整兵器與馬蹄必須位於來源圖內，不能以裁切後的片段冒充完整姿勢。每個動作等比例放入512×384，使用原版半屏128×96邏輯座標，底部錨點為`(64,96)`；較寬的畫布保留弓箭與衝鋒時的完整馬身，不以不等比例拉伸補尺寸。打包時另保留16像素底部透明餘量，並檢查每個實際動作格四邊至少8像素透明，避免兵器尖端與馬蹄貼住邊界而看似遭到裁切。

新來源刻意以青／藍綠色標示馬身毛色區域，騎手、兵器及韁繩不使用該色。打包器在量化前辨認此明確區域，再離線套用13種坐騎色階；不以騎手皮甲與馬身都可能使用的暖棕色猜測遮罩。各名馬色階是明列的美術設定，與文字出處證實的馬名分開看待。

每個兵器／坐騎組合只產生一張4096×384透明PNG，依序容納八個512×384動作。`action_atlases[weapon][horse]`保存圖片雜湊、共同錨點及每個動作的`source_rect`，`action_studies`保存來源圖與提示詞雜湊。12種兵器與13種坐騎共156張圖集、1248個動作格，遊戲只在需要時載入當前雙方的兩張圖集，不會在開局下載全部組合。

```sh
node tools/battle-enhancement/build.cjs
node tools/battle-enhancement/build.cjs --check
```

兩條指令只需Node標準函式庫，沒有網路、API、ROM或模擬器依賴。完整重建會先驗證全部第二版來源，缺少一張也不會先寫入部分新圖集。`--check`驗證全部來源、提示詞、工具雜湊、透明通道、尺寸、有限調色盤、八動作順序、完整素材清單，以及每張原版素材按記錄方法重建的4倍像素結果。最終PNG和來源清單位於`game/assets/battle-enhanced/`。

`game/config/duel-appearances.json`以穩定人物ID對應已查證的小說兵器與代表性坐騎；名稱相同不會套用另一人的配置。未明確記載的毛色、泛用兵器是美術選擇，與遊戲數值無關。出場年代不模擬小說中名馬的歷次易主。新增文吏與其他未配置人物以身分雜湊選取通用裝束，不使用戰役隨機數。詳見`docs/duel-appearances.md`。

畫面、裝束、毛色、切換語言和跳過演出全部是呈現層，不授予裝備、不改變傷害、存檔、招式判定或戰役亂數。素材載入失敗時仍使用原版騎將，戰鬥結果一律以伺服器結算為準。
