# 兵士の連続攻撃図集

原作の歩・弓・騎・将の姿、配色と二つの移動姿勢を参考に、攻撃の補完図を作成します。原ROMから四つの攻撃姿勢が復元できたという意味ではありません。元の立ち姿・移動画像と旧図集は変更しません。

- 歩兵・騎兵・主将は近接四姿勢。弓兵は遠射四姿勢と、弓を持った近接四姿勢。
- 全姿勢を64×64へ直接整理し、原作の三色と硬い透明境界を保ちます。素材の幅・高さは原作の16×16に対して4倍です。いったん16×16へ縮小する方法は弓弦や刃先を失うため使いません。ゲーム内の位置・大きさは16×16のままです。
- 四姿勢の1枚は256×64。味方の灰白と敵方の赤で計10枚、40姿勢です。肌・馬・黒・透明部分は両軍で同一で、灰色だけを原作の赤に置換します。
- 近接は`ready / windup / strike / recover`、遠射は`nock / draw / release / recover`。

画像生成は組み込みimagegenを使用し、元のPNG・プロンプト・参照画像を`art/soldier-combat-actions-v1/`へ保存します。通常のビルド・CIにはimagegen、ROM、エミュレーターや追加のライブラリーは必要ありません。

```sh
# 保存済みの参照原画から構築。原画像を上書きしない。
node tools/soldier-combat-actions/build.cjs --write
# 出典・全画素・三色・硬い透明境界・64px寸法・両軍の一致を検証。
node tools/soldier-combat-actions/build.cjs --check
node tests/test_remake_soldier_combat_assets.cjs
```

連結した大きな人物を左から右へ分離し、弓の原画は上段が遠射、下段が近接です。離れた矢先や弓弦は最も近い人物に結び付けます。兵器・蹄が原画の端で切れていたり、四姿勢の差が12画素未満になったりすると構築を拒否します。三色・硬い透明境界・切れていない余白に加え、各姿勢で96画素以上が見え、その70%以上が主連結図形に残ることを検証します。画面内では身体の灰色部分と足元を基準に全姿勢を同じ倍率で整列します。新しい姿勢をスクリプトが描くことはありません。

公開は`game/assets/soldier-combat-actions-v1/`の10PNG、`index.json`、`provenance.json`だけです。参考原画、プロンプト、個人のファイルや状態は公開しません。出典には原画像のハッシュ、原版移動二姿勢という参照の範囲、および補完原画であることを明記します。

## CIの範囲

`art/soldier-combat-actions-v1/`直下の`prompts/*.txt`、`references/*.png`、`studies/*.png`と、公開用の固定12ファイル、この`build.cjs`は`boot,battle,cloud`の関連検証を実行します。図集の再生成・ハッシュ・三色・透明境界・寸法・描画、静的ビルドと関連するデスクトップ／タッチ操作を残し、武将能力や戦役規則、長期回放の全件マトリックスは実行しません。

原画・プロンプトだけ、または説明Markdownと合わせた変更はゲームを公開しません。使用中の入力ファイルは`provenance.json`にハッシュを記録しているため、変更時は上記の`--write`で公開図集と指紋を同期し、`--check`を通してください。公開ファイルも変更すれば、mainの検証成功後に通常どおり公開します。このREADMEだけの変更は文書検査です。

未知の拡張子・下位フォルダー・別バージョンのディレクトリー、共通ルールとの同時変更は全件検証へ戻します。CI選別器そのものの変更も全件検証です。
