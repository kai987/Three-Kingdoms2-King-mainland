## 1. 調查結論與範圍

建議保留原版粉色底、黑色雙線框、有限色像素畫和「圖示選命令 → 選武將／物品 → 費用確認 → 圖文結果」的節奏。主要改動是減少本作側欄和彈窗同時展開的文字，讓設施、裝備與事件有清楚對應的圖像。

本次取得 **33 張原遊戲流程截圖、4 張目前 Web 版截圖、1 張原遊戲測試起點恢復憑證**，共 38 張。可辨識的素材包括四類設施圖示、四類都市命令圖示、兩個裝備分類圖示、武具店／商人交易／騎將出陣三種不同的大幅插圖，以及共用裝飾框。

來源為本機 OpenEmu 1.4.0／Nestopia 的「三国志2超级版」。標題畫面見截圖 24。它是本機的超级版，不能直接當作所有原版版本的唯一依據。全幅 PNG 包含模擬器標題列，通常為 1752×1504；這是視窗截圖尺寸，**不是已確認的原生素材尺寸**。目前使用 Pixellate 顯示，像素邊緣亦受視窗縮放影響。

Web 對照在獨立本機預覽埠 18925 進行，實際開始 217 年劉備戰役並打開設施與裝備介面；未在原有 8878 埠戰役中執行指令，未購買或變更 Web 裝備。

## 3. 主畫面與右側命令欄

依據截圖 13 與 35，建議使用「都市摘要 → 圖示分組 → 當前組命令 → 固定結束旬」的順序。

桌面版側欄先以 **320–360 CSS px** 作實施起點，剩餘寬度交給地圖。這是待驗收的設計尺寸，並非原遊戲規格。1280×720 下不再像截圖35一樣讓約474 px側欄和大量長文字同時佔畫面；有足夠空間時維持頂部報告置中。地圖仍遵守縮放、平移邊界，不能為填滿寬度裁掉城池。

| 分組 | 繁中／日文入口 | 保留的命令 |
|---|---|---|
| 城 | 城政／都市 | 都市情報、開發、防災、兩名勢力內政官及自動政策 |
| 軍 | 軍務／軍務 | 出陣、編兵、募兵訓練、武將移動 |
| 倉 | 倉庫／倉庫 | 運輸、補給、寶物、賞賜 |
| 町 | 設施／町 | 武器屋、醫館、學問所、市場 |

四個入口採原版圖示加本地化短標籤，以 2×2 排列；不只靠圖片猜用途。選中一組後顯示所屬命令，未選組時不把全部長按鈕展開。繁中用「倉庫」，日文用「倉庫」，說明文字另用「寶／タカラ」對應本作語言。

都市摘要保留城名、歸屬、都市級別、武將數／99、資金、兵糧、預備兵及訓練度。完整武將屬性和裝備移到「都市情報」，側欄只列可點擊的簡短名冊摘要。避免每名武將在窄欄反覆出現武器、防具、重量與攻防公式。

手機改為可收合的底部命令板，保持地圖上方可見；四組入口各自可觸控。鍵盤 Tab、Enter、Escape 與返回焦點需要實測，不照搬模擬器單純方向鍵流程。

## 4. 設施彈窗

依據 01、06、12、20、29、32 和本作36：

1. 上方顯示「城名 · 町」和四個服務圖示頁籤。沒有設施、敵城或不符合條件時顯示停用及原因，不讓玩家反覆進去才知道不能用。
2. 寬畫面左區放設施插圖或已核實的分類圖示，右區放人物選擇、當前值 → 操作後預覽、數量和費用。人物名字旁保留肖像，所有可操作欄位使用 HTML。
3. 醫館先列受傷者、體力與治療費；學問所先列可學習者、知與費用；市場先列買／賣、數量、庫存與金額；武器屋使用下一節的物品清單。
4. 開發、防災與內政自動政策不再和所有設施內容同時展開；由城政組入口進入，必要時在町面板提供短連結。政策細節預設收合。
5. 底部固定顯示總費用、行動消耗、確認及取消。超限數值自動收斂並回顯，缺額、到頂和對象不合條件的原因貼在輸入旁。執行中防止重複確認。

目前只確認醫館圖示與「無傷員」提示，不能用武器商人的插圖假充醫師內景。學問所亦先用書本入口與人物發言，待取得實際內景再替換。

## 5. 武器、防具與武將情報

依據 03、04、08–11、25、37：本次原遊戲看到的是 **裝備分類圖示＋名稱文字**，沒有取得每件武器、防具各自的商品圖。因此分兩層處理。

- 第一層沿用已確認的交叉兵器與甲冑分類圖示，搭配真實裝備名稱、攻／防、重與價格。不得把一個共用分類圖標註成「原版青龍偃月刀專圖」。
- 第二層才為本作新增、且找不到原圖的具體物品補畫同調色盤像素小圖。素材標記為本作補畫，保留原有圖示。不同兵器輪廓、同類防具輪廓須能辨識，不用模糊放大的照片或通用3D圖。

物品圖片以 **`slot:itemID`** 綁定，人物以 personID 顯示目前實際裝備；不以名字或武將知名度硬套圖片。未持有專武者不能只因為是名將就顯示專武。名將單挑外觀與實際裝備不一致的地方須由資料映射核對，不在 UI 內創造另一套規則。

武器屋桌面版左右分欄：左側武將肖像、兵／武／知／德／忠／經／體及當前兩件裝備；右側按剣／刀／矛／防具分類列物品。長清單保持分類與已選物品可見，手機上下排列。確認區直接展示攻、防、重的「現在 → 更換後」及費用；命中、迴避、先手、退卻消耗和來源說明放進「重量影響／詳細」收合區。

都市情報仍保留忠與君主「--」，物品小圖加名稱可點入詳情；數字使用引擎提供的比較值。基礎武、知、德、經不因 UI 改版而被寫回為裝備後數值。

## 7. 素材採集與檔案規格

本目錄 `screenshots/` 永久保留本次全幅來源；`reference-crops/` 只為查看方便，不直接當作上線素材。

1. 先補採沒有標題列、滑鼠游標、濾鏡與縮放干擾的乾淨原生畫面；測定實際畫面區和像素長寬比，不能直接把1752×1504縮成猜測尺寸。
2. 分開保存 `original/` 原尺寸、`display-4x/` 整數倍率衍生圖及 manifest；保留來源版本、場景、截圖編號、裁切矩形、雜湊、確認狀態與用途。
3. 4×指寬與高各4倍；原圖和衍生圖均保留。像素圖先採 nearest-neighbor、`image-rendering: pixelated`；插圖按原比例顯示，不做平滑模糊或AI重畫替換原有內容。
4. 圖示、場景內畫、裝飾框分開。裝飾框以角與邊拼接並檢查整數像素對齊，不能把整張框拉伸得粗細不均。
5. 所有素材註明 `original-reference`、`original-export-verified` 或 `remake-adaptation`。目前候選均是第一類，尚無完成的原生匯出。
6. 建議新增 `game/assets/original-ui/` 及 `game/config/original-ui-assets.json`；這兩個是未來實施位置，本次沒有新增執行時素材或載入器。

## 9. 實施順序與驗收

| 階段 | 工作與主要檔案 | 驗收 |
|---|---|---|
| 第一階段 | 原生圖示／插圖整理、來源manifest、事件對應。`game/events.js`、`game/events.css`及新素材表 | 購武具、市場、賣寶的圖與事件一致；缺圖可回退；已結算事件重播不再扣款或改亂數。 |
| 第二階段 | 右欄四組命令、設施頁籤、固定確認區。`game/app.js`、`game/facilities.js`、`game/style.css` | 所有既有命令可到達，非本方城與缺設施停用原因清楚；取消不扣費、不能連按重複付款；地圖選城與高亮不退化。 |
| 第三階段 | 裝備圖片、比較收合、特殊裝備說明與待補事件。`game/equipment.js`、`game/treasury.js`及素材映射 | 人物ID、裝備ID、實際攻防與圖片一致；玩家和AI結果不因顯示改動而不同；原圖保留。 |

每階段實作後驗收繁中和日文、1280×720與1920×1080桌面、390×844手機，並測鍵盤焦點、Escape、44px觸控區、長姓名及文字放大。圖示必須有可見文字與替代文字，不能只用顏色顯示停用／選取。

目前截圖能確認文字密度、構圖與部分操作流程，**不能證明完整可及性、手機行為、所有設施交易結果、所有29劇本和存讀檔均已通過**。那些是後續實施的驗收項，本次沒有宣稱已完成。
