# 陰平西側紅棕山腳與陰平—成都間綠峰

此版只將陰平西側殘留的小綠山融入相鄰紅棕山脈，並在陰平與成都之間加入一座同風格小綠峰。原 v1、v2 素材全部保留；城池、道路、河道與遊戲資料不重建。

內建 imagegen 的本次編輯要求：保留原版像素配色、尺度與整體地形；陰平左側小綠山改成連續的紅棕岩面及山腳，在陰平和成都之間補一座綠色小山；避開城市、道路、河流，不增加文字、道路或其他地形。完整原始生成提示見 [prompt.md](prompt.md)。

## 可重現合成

```sh
NODE_PATH=/path/to/node_modules node art/map-western-range-v3/build.cjs
node tests/test_remake_map_terrain.cjs
```

需要 `sharp` 與 `pngjs`。僅有兩個本版美術輸入：

- `before-map.png`：已發布 v2 原始成品，SHA256 固定為 `da66399bf99e50ebd9559957c686585292f3d974825004e14e60037257dafae2`。
- `generated-edit.png`：內建 imagegen 的 1122×1402 編輯結果；以最近鄰縮回 160×200，對應全圖 `(150,325)` 的同尺寸視窗。

`edit-reference.png` 是實際傳入圖像編輯工具的 800×1000 最近鄰放大裁片，供來源核對；不作合成輸入。

`build.cjs` 在完整 1352×1024 地圖上套用兩個緊密遮罩。紅棕山腳使用不規則多邊形，保留原本正確的亮綠草地及棕色山脊；需要清除舊山腳的生成草地，以原圖 `(268,353)` 的 16×21 草地紋理補齊，不複製生成圖的亮綠底色。

新增綠峰使用緊貼完整山形的不規則多邊形，保留左側亮綠岩面與其分離的深色山影，避免只留下狹窄的黑色主峰；再向右平移 4、向上平移 5 個原生像素。多邊形來源中若碰到藍色河道像素則拒絕複製，避免引入新的河流。其山腳不超過 `y441`，並檢查與原道路、河道至少相距 7 個像素，使兩者之間保留 6 個完整草地像素。只複製山體形狀，不貼整塊矩形草地。

道路和城標保護仍由 `map-road-centers.png` 與 `hydrology-ground.png` 的原始差異建立；原藍色河道另保護兩像素河岸。全部遮罩之外，以及所有保護像素，逐像素核對與 v2 完全相同。來源雜湊、兩處遮罩、山形逐列範圍和變動統計寫入 `manifest.json`。

成品為 `../../game/assets/map-western-range.png`；`before-detail.png`、`after-detail.png` 是同一 160×200 視窗最近鄰放大 5 倍的對照圖。
